# Тест-кейсы KATFIT Studio

Этот каталог — единая точка хранения ручных тест-кейсов CRM. Каждый документ
должен описывать предусловия, тестовые данные, шаги, ожидаемый результат и
очистку тестовых данных.

| Набор | Назначение | Статус |
| --- | --- | --- |
| [Оплата по факту](pay-as-you-go-booking-test-cases.ru.md) | Разовые и персональные занятия без пакета, ожидаемая и подтверждённая оплата | Актуален для ветки `codex/pay-as-you-go-scheduling` |
| [Сплит-блок](split-positive-test-case.ru.md) | Общий пакет пары, запись, проведение и списание | Актуален для текущего сплит-флоу |

Запускайте наборы в тестовом workspace после `twenty plan` и `twenty apply`.
Не удаляйте финансовые и журнальные записи после прогона: архивируйте тестовые
сущности, чтобы аудит оставался проверяемым.
