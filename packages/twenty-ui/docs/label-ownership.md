# Retained UI label ownership

This covers production exports under components, primitives, and icons, including the Dropdown compound API.

| Surface                                                                                                               | Text ownership                                                                                                                                                                                                                                                                                                               |
| --------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Callout                                                                                                               | `title`, `description`, `action.label`, and `closeLabel` (default `Close`).                                                                                                                                                                                                                                                  |
| ListItem and Menu item parts                                                                                          | Children, description, action slots, native accessible attributes, and `shortcutJoinLabel` (default `then`).                                                                                                                                                                                                                 |
| Dropdown                                                                                                              | Children name actions, options, titles, sections, empty states, and loading states. `Back` children default to `Back`. Search accepts native placeholder and accessible attributes. Close requires a caller-supplied accessible label and accepts native `aria-labelledby`. Item parts pass `shortcutJoinLabel` to ListItem. |
| Legacy menu compositions                                                                                              | MenuItem exposes `text`, contextual slots, and `shortcutJoinLabel` (default `then`). Avatar, draggable, suggestion, and picker presets receive their text from callers; they add no English fallback. Keep this additive option until their separate migration removes the exports.                                          |
| Button, MainButton, LightButton                                                                                       | Children and native accessible attributes. Applications compose upcoming-feature labels with Pill. Loading preserves the supplied name and marks the button busy; its spinner is decorative. Button hints use the shared Shortcut presentation and remain decorative. `shortcutJoinLabel` supplies the sequence join label.  |
| IconButton and LightIconButton                                                                                        | Caller-supplied accessible label and optional tooltip. Native `aria-labelledby` remains available and takes precedence.                                                                                                                                                                                                      |
| SearchInput                                                                                                           | Caller-owned placeholder and native accessible name; `filterButtonAriaLabel` defaults to `Filter`. Referenced labels take precedence over explicit labels and placeholder fallback.                                                                                                                                          |
| ImageInput | `uploadLabel`, `removeLabel`, and `abortLabel` default to `Upload`, `Remove`, and `Abort`. The upload label also names the preview button and file input. Applications supply `helperText` and `errorMessage`, including validation instructions and translated strings. |
| Toast and Toaster                                                                                                     | Children, description and action slots, `iconLabel`, `cancelLabel` (default `Cancel`), and `closeLabel` (default `Close`). Toaster accepts native accessible attributes over its `Notifications` region default.                                                                                                             |
| Chip and Avatar                                                                                                       | Chip `emptyLabel` defaults to `Untitled`. Avatar accepts native accessible names over its interactive fallback of the supplied name or `Avatar`. The visual initial or dash is hidden from assistive technology; the image has empty alternative text.                                                                       |
| JsonTree                                                                                                              | Callers supply empty string, array, and object labels and expanded/collapsed arrow names. JSON booleans, null, property names, and values are data.                                                                                                                                                                          |
| ResizeHandle and CodeEditor                                                                                           | ResizeHandle accepts native labels over `Resize`. CodeEditor exposes `resizeLabel` (default `Resize editor`) and Monaco `options`, including its editor accessible label. The loading indicator adds no text. Monaco owns its internal editor messages.                                                                      |
| Input, Textarea, Select, Field, Slider, Radio, RadioGroup, Checkbox, Switch, SegmentedControl                         | Native attributes, compound label/description/error parts, options, and children belong to the caller. Browser validation messages remain browser-owned; Field.Error children or render content can replace them.                                                                                                            |
| Dialog, AlertDialog, Popover, Tooltip, Tabs                                                                           | Text belongs to title, description, close, trigger, tab, and popup parts. No built-in English action or status strings.                                                                                                                                                                                                      |
| Banner, InlineBanner, SettingsRow, Section, CommandBlock                | Content and labels belong to supplied props or children.                                                                                                                                                                                                                                                                     |
| Tag, Status, Pill, AvatarGroup, NotificationCounter, ColorSample, TintedIconTile, typography, layout and icon exports | Caller content, data values, native accessible attributes where supported, or decorative output. Loader and progress graphics add no built-in English loading message.                                                                                                                                                       |

Shortcut owns symbol and separator formatting for visual hints and strings. Flat key arrays represent simultaneous combinations; nested key arrays represent ordered sequences of combinations. Hosts supply `sequenceJoinLabel` (default `then`), optional `combinationSeparator`, and native accessible labels. The `shortcutJoinLabel` props on host controls forward the sequence label.
