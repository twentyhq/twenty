# People Data Labs

**Turn a name into a full profile — enrich any Person or Company in one click.**

## ✨ What you get

- **+30 rich data fields** per Person and Company — seniority, skills, firmographics, funding, socials & more
- **Run it anywhere** — from the command menu, as a workflow step, or straight from AI chat
- **Smart matching** — finds the right profile from a LinkedIn, email, or domain, and only writes confident matches

## 💳 Billing

By default, you pay only for matches, in Twenty credits. **Not found and skipped records are free.**

- **Person match:** $0.336
- **Company match:** $0.12

To use your own People Data Labs account, fill in **Your People Data Labs API key** in Settings → Apps → People Data Labs → Variables. Enrichment then uses your key, and matches are billed by People Data Labs instead of in Twenty credits. Leave the field empty to use the default key.
