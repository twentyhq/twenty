# Claude

Connect Claude to Twenty to work with your records from a conversation.

- Each member connects their own Claude account.
- Claude acts with that member's permissions.
- Claude and Claude Code both connect through this app.

## How to connect

Open the app in the Twenty marketplace and select **Connect**. Claude opens with the Twenty connector prefilled; sign in to Twenty and approve the access it asks for.

This app installs nothing in your workspace.
