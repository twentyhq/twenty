# Changelog

All notable changes to this application are documented in this file.

## 1.1.0

- Sign in through a GitHub App instead of an OAuth App, so members grant
  fine-grained permissions on the repositories where the app is installed,
  with tokens that expire and refresh.

## 1.0.0

- Connect Twenty's AI to GitHub through GitHub's remote MCP server. Each member
  signs in with their own GitHub account.
