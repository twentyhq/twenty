# Каталог фич KATFIT Studio

Обновлено: 1 ноября 2026 года.

Единая точка входа в описание возможностей студийного приложения Twenty CRM.
Каталог описывает бизнес-сценарии KATFIT, а не все стандартные возможности Twenty.
Внешние UI, Telegram-бот и календарные интеграции отмечены только в пределах
контрактов и документов этого репозитория.

## Как читать статусы

- **В коде** — сценарий реализован в текущих исходниках приложения. Это не
  подтверждение доступности в рабочей CRM или внешнем UI.
- **В коде, частично** — реализована указанная часть сценария; ограничения
  приведены в описании.
- **Проект** — есть описание, но готовый сценарий в этом приложении не подтверждён.
- **Модель данных** — есть сущности, но полноценная бизнес-команда не подтверждена.

В колонке «Развёртывание» **не подтверждено** означает, что для этой фичи здесь
не приведён отдельный проверенный отчёт о выпуске. Это не означает, что её нет
на стенде. Записи о stage/production отражают даты сохранённых отчётов;
текущее состояние окружений при составлении каталога не проверялось.

## Как поддерживать каталог

При добавлении или изменении фичи обновлять строку здесь и подробное описание
по ссылке. Для новой фичи указывать пользовательский сценарий, правила и границы,
статус реализации и отдельно статус stage/production. После выпуска добавлять
дату и ссылку на отчёт проверки; название ветки само по себе выпуск не подтверждает.

Не копировать весь контракт в каталог: подробные API, инструкции и тест-кейсы
хранить в своих документах. Для старых проектных документов актуальное поведение
сверять с кодом: в частности, `past-training-deduction.feature.ru.md` содержит
исторический статус proposed, хотя команда внесения посещения уже реализована.

Обновлять дату каталога после сверки. Не переносить реальные данные клиентов,
ключи API и другие секреты в описания и отчёты.
