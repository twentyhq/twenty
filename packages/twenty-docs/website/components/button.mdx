### As a link

With `href`, the button renders a link. An internal path keeps the visitor's language, an external address opens a new tab, and a `#hash`or `mailto:`stays in place.

## Usage guidelines

<Check>Use `href`to navigate rather than wrapping a Button in a link: the component picks the anchor and keeps the visitor's language (Button.tsx, LocalizedLink).</Check>

<Warning>Do not restyle a Button for a dark background: dark surfaces restyle it through context, never through props (Button.tsx comment).</Warning>

<Check>`disabled`also sets `aria-busy`: it marks a pending action.</Check>

<Check>The uppercase is applied by the component's CSS: pass the label as written.</Check>

## Props

{/* Generated by scripts/docs/render-api-reference.mjs from component-docs.json. Do not edit by hand. */}

<ParamField body="label" type="string" required>
  The visible text. Pass it as written: the component's CSS sets the uppercase.
</ParamField>

<ParamField body="disabled" type="boolean" default="false">
  Blocks activation and sets `aria-busy`: it marks a pending action. Applies to the button form only, not to links.
</ParamField>

<ParamField body="href" type="string">
  Renders a link instead of a button. An internal path keeps the visitor's language, an external address opens a new tab, and a `#hash`, `mailto:` or `tel:` link stays in place.
</ParamField>

<ParamField body="leadingIcon" type="ReactNode">
  A mark from `@/icons`, placed before the label.
</ParamField>

<ParamField body="onClick" type="((event: MouseEvent&lt;HTMLElement, MouseEvent&gt;) =&gt; void)">
  Called on click, for the button and for every link form.
</ParamField>

<ParamField body="size" type="&quot;regular&quot; | &quot;small&quot;" default="regular">
  The button's height, from `BUTTON_HEIGHT_PX`.
</ParamField>

<ParamField body="type" type="&quot;button&quot; | &quot;submit&quot;" default="button">
  The HTML type of the button form. Use `submit` inside a form. Ignored when `href` is set.
</ParamField>

<ParamField body="variant" type="&quot;filled&quot; | &quot;outlined&quot;" default="filled">
  `filled` draws the solid notched shape, `outlined` only its stroke. Colors follow the scheme of the section the button sits in.
</ParamField>
