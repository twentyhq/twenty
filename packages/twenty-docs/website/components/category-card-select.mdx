## Props

{/* Generated by scripts/docs/render-api-reference.mjs from component-docs.json. Do not edit by hand. */}

<ParamField body="ariaLabel" type="string" required>
  Names the group of cards for screen readers (`role="group"`).
</ParamField>

<ParamField body="onToggle" type="(value: TValue) =&gt; void" required>
  Called with a card's value when it is clicked. The parent adds or removes it from `values`.
</ParamField>

<ParamField body="options" type="readonly CategoryOption&lt;TValue&gt;[]" required>
  The cards, in order: a `label`, a `description`, `examples` and a `value` each.
</ParamField>

<ParamField body="values" type="readonly TValue[]" required>
  The selected values. Each selected card is pressed (`aria-pressed`) and shows its indicator.
</ParamField>

<ParamField body="invalid" type="boolean" default="false">
  Paints the unselected cards red, so the missing choice shows. Unlike ChipMultiSelect, it does not set `aria-invalid`.
</ParamField>
