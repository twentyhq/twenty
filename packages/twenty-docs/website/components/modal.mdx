## Examples

### As the site uses it

The panel is dark but sets no scheme. Every consumer wraps its content in a dark scope (`buildSchemeContext('dark')`and `data-scheme="dark"`), so text and buttons turn light.

<SiteEmbed slug="modal" show="with-scope" title="As the site uses it" height={160}>

```tsx
const DarkScope = styled.div`${buildSchemeContext('dark')}`;

<Modal open={open} onClose={close} ariaLabel="Partner application">
  <DarkScope data-scheme="dark">…</DarkScope>
</Modal>
```

</SiteEmbed>

### Modal alone

Without that scope, the content keeps the page's light scheme: dark text on the dark panel. This is what the component does by itself.

<SiteEmbed slug="modal" show="alone" title="Modal alone" height={160}>

```tsx
<Modal open={open} onClose={close} ariaLabel="Example">…</Modal>
```

</SiteEmbed>

## Usage guidelines

<Check>The panel is scheme-agnostic: wrap the content in a dark scope, as the wizards do (ClientBriefModal.tsx:32-34)</Check>

<Check>It is the site's one dark dialog shell (Modal.tsx:60-62)</Check>

<Check>Pass `ariaLabel`when the content has no dialog title, omit it when it has one (Modal.tsx:51-52)</Check>

<Check>Override the width with `--modal-panel-width`through `className`(Modal.tsx:23-25,42)</Check>

## Props

{/* Generated by scripts/docs/render-api-reference.mjs from component-docs.json. Do not edit by hand. */}

<ParamField body="onClose" type="() =&gt; void" required>
  Called when the dialog asks to close (Escape, backdrop click). The parent owns `open`.
</ParamField>

<ParamField body="open" type="boolean" required>
  Whether the dialog is shown. Controlled by the parent.
</ParamField>

<ParamField body="ariaLabel" type="string">
  Names the dialog when its content has no Dialog.Title (the partner wizard); omit it when the content renders its own Dialog.Title (the Cal modal).
</ParamField>

<ParamField body="className" type="string">
  Class on the panel. Sets its width through `--modal-panel-width`.
</ParamField>
