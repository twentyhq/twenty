## Overview

Pair a duration with an easing curve. Every animated component also carries a `REDUCED_MOTION` block.

```tsx
import { DURATION, EASING, REDUCED_MOTION } from '@/tokens';

const Panel = styled.div`
  transition: transform ${DURATION.md} ${EASING.standard};

  ${REDUCED_MOTION} {
    transition: none;
  }
`;
```
