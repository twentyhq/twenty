## Добавить метаданные торговой площадки

[Конфигурация приложений](/l/ru/developers/extend/apps/config/application) имеет идентификацию
отображаемую на рынке: автор, категорию, логотип и поддержку
ссылок. Поместите логотип в `public/` и укажите его в `logo`.

```ts filename="src/application-config.ts"
import { defineApplication } from 'twenty-sdk/define';

export default defineApplication({
  universalIdentifier: APPLICATION_UNIVERSAL_IDENTIFIER,
  displayName: 'Document Generator',
  description:
    'Create reusable document templates and generate personalized documents from your CRM records.',
  logo: 'public/document-generator.svg',
  author: 'Twenty',
  category: 'Productivity',
  websiteUrl: 'https://docs.twenty.com/l/ru/developers/extend/apps',
  termsUrl: 'https://www.twenty.com/terms',
  emailSupport: 'contact@twenty.com',
  issueReportUrl: 'https://github.com/twentyhq/twenty/issues',
});
```

<Tip>
Роль по умолчанию объявлена `defineApplicationRole()` в своем собственном файле — вы
больше не передаете `defaultRoleUniversalIdentifier` здесь.
</Tip>

Также добавьте ключевое слово `twenty-app` в `package.json`, чтобы приложение было найдено:

```json filename="package.json"
{ "keywords": ["twenty-app"] }
```

## Добавить скриншоты галереи

Список торговых площадок продается со скриншотами. Поместите несколько PNG-файлов в
`public/gallery/` и укажите их в `galleryImages` — они будут отображаться как галерея
на странице каталога, в порядке следования в массиве.

```ts filename="src/application-config.ts"
export default defineApplication({
  // ...identity from above
  galleryImages: [
    'public/gallery/01-generated-document.png',
    'public/gallery/02-command-menu.png',
    'public/gallery/03-template-editor.png',
    'public/gallery/04-documents.png',
  ],
});
```

<Tip>
Возглавие с выплатом: сделайте первый скриншот завершённый результат (сгенерированный
документ), затем покажите как он срабатывает и аутентифицирует. Используйте четкие, высококачественные
скриншоты — это первое, что видит пользователь.
</Tip>

Дайте `README.md` ту же обработку — это главная страница npm и GitHub.
Начните с описания ценностного предложения и скриншота, перечислите ключевые функции,
а затем поместите технические детали ниже основной части страницы.

## Проверить перед отправкой

Выполнить те же ворота CI делает:

```bash filename="Terminal"
yarn lint          # oxlint
yarn typecheck     # tsgo
yarn test:unit     # unit tests
yarn twenty plan   # preview the metadata diff
```

План точно показывает, что изменится на сервере, не применяя эти изменения —
хорошая финальная проверка. См.
[Testing](/l/ru/developers/extend/apps/operations/testing) и
[Синхронизация и восстановление](/l/ru/developers/extend/apps/operations/sync-and-recovery).

## Публикация

```bash filename="Terminal"
# Public app → npm (default)
yarn twenty app:publish

# Or deploy privately to a specific server's registry
yarn twenty app:publish --private -r <remote>
```

`app:publish` строит и публикует в npm по умолчанию; `--private` загружает
tarball в частный реестр Twenty сервера. Для постройки опубликованного приложения
в магазине экземпляра, запустите синхронизацию каталога:

```bash filename="Terminal"
yarn twenty dev:catalog-sync -r <remote>
```

Подробности и контрольный список для выпуска:
[Публикация](/l/ru/developers/extend/apps/operations/publishing).

В шести главах вы использовали большую часть поверхности SDK:

* **Объекты, поля и отношение** для моделирования данных

[`packages/twenty-apps/examples/document-generator`](https://github.com/twentyhq/twenty/tree/main/packages/twenty-apps/examples/document-generator).
