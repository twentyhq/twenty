## Текущий статус

Интеграция календаря Twenty предназначена для того, чтобы **синхронизировать и отображать** ваши существующие события календаря.

## Планирование встреч через рабочие процессы

Хотя планировать встречи невозможно вручную, вы можете планировать их в двадцати используя рабочие процессы.

1. Создайте новый рабочий процесс
2. Выберите любой триггер в зависимости от ваших потребностей
3. Добавьте узел **Create Calendar Event**
4. Настройте все необходимые данные
5. Активируйте рабочий процесс

## Что вы можете сделать

* **Просматривать историю встреч** в записях Людей, Компаний и Возможностей
* **Просматривать предстоящие встречи** с контактами в вашей CRM
* **Отслеживать контекст встреч** наряду с электронной перепиской
* **Автоматически создавать контакты** из участников встреч
