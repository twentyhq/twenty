title: Настройки доменов

---

Настройки доменов находятся в трёх местах, в зависимости от того, что вы настраиваете.

## Домен рабочей области

Настройте в разделе **Settings → General**.

Измените имя своего субдомена или установите собственный домен для вашего рабочего пространства.

### Настроить домен

1. Нажмите на **Subdomain** для редактирования поддомена (например, `yourcompany.twenty.com`)
2. Или нажмите на **Пользовательский домен** для настройки пользовательского домена (например, `crm.yourcompany.com`)

Для собственных доменов вам потребуется настроить параметры DNS у вашего провайдера домена.

## Утвержденные домены

Настройте в **Настройки → Участники → Пригласить**.

Добавьте домен вашей компании, чтобы члены команды могли автоматически зарегистрироваться на этот проект.

### Добавить утвержденный домен доступа

1. Нажмите **Добавить утверждённый домен доступа**
2. Введите домен вашей компании (например, `yourcompany.com`)
3. Сохранить

После настройки любой пользователь с адресом электронной почты в этом домене сможет присоединиться к вашему рабочему пространству без прямого приглашения.

<Note>
Это удобно: вся ваша команда сможет самостоятельно зарегистрироваться, при этом рабочее пространство останется доступным только для вашей организации.
</Note>

## Собственные домены приложения

Настройте в **Настройки → Приложения → ваше приложение → Настройки → App URL**.

Приложения, предоставляющие маршруты в Интернете, обслуживаются по отдельному URL-адресу, указанному в разделе **App URL**. Вместо этого вы можете обслуживать приложение на принадлежащем вам домене.

### Добавить собственный домен

1. Нажмите на **Пользовательский домен**
2. Введите домен, который вы хотите использовать (например, `app.yourcompany.com`)
3. Настройте параметры DNS согласно инструкциям
4. Подтвердите домен

Только маршруты этого приложения будут доступны на этом домене. SSL-сертификаты выдаются автоматически.
