## コミュニティ設定について

「コミュニティ」セクションでは、一般提供前の早期アクセス機能を有効化できるほか、Twenty パートナーを検索できます。

## 早期アクセス機能

早期アクセス機能は、一般提供に先立って検証中の機能です。

**現在早期アクセス中:**

* **ジャンクションリレーション** — 多対多リレーション

### 早期アクセス機能を有効にする方法

1. **設定 → コミュニティ** に移動します
2. **Features** セクションに移動します
3. 有効にしたい機能を見つけます
4. オンに切り替えます
5. 機能はすぐに利用可能になります

<Note>
早期アクセス機能は、ユーザーからのフィードバックに基づいて変更される場合があります。 皆さまのフィードバックは Twenty の改善に役立ちます!
</Note>
