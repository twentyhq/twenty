## 关于社区设置

“社区”部分允许您在功能普遍可用之前启用早期访问功能，并搜索 Twenty 合作伙伴。

## 早期访问功能

早期访问功能是在全面可用之前仍在测试的功能。

**当前处于早期访问阶段：**

* **连接关系** — 多对多关系

### 如何启用早期访问功能

1. 转到 **设置 → 社区**
2. 转到 **功能** 部分
3. 找到您想要启用的功能
4. 将其切换为开启
5. 该功能将立即可用

<Note>
早期访问功能可能会根据用户反馈而改变。 您的反馈有助于我们改进 Twenty！
</Note>
