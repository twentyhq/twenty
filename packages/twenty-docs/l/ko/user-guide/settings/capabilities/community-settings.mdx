## 커뮤니티 설정 정보

커뮤니티 섹션에서는 일반 제공되기 전에 얼리 액세스 기능을 활성화할 수 있으며 Twenty 파트너를 검색할 수도 있습니다.

## 얼리 액세스 기능

얼리 액세스 기능은 일반 제공 전에 아직 테스트 중인 기능입니다.

**현재 얼리 액세스:**

* **정션 관계** — 다대다 관계

### 얼리 액세스 기능 활성화 방법

1. **설정 → 커뮤니티**로 이동하세요
2. **기능** 섹션으로 이동합니다
3. 활성화하려는 기능을 찾으세요
4. 토글하여 활성화하세요
5. 해당 기능이 즉시 사용 가능해집니다

<Note>
얼리 액세스 기능은 사용자 피드백에 따라 변경될 수 있습니다. 여러분의 피드백은 Twenty를 개선하는 데 도움이 됩니다!
</Note>

## 기능 피드백

여러분의 피드백은 Twenty를 개선하는 데 도움이 됩니다:
