## Informações Pessoais

### Nome e E-mail

* **Nome de Exibição**: Atualize como seu nome aparece para outros membros do workspace
* **Endereço de E-mail**: Altere seu e-mail de login (requer verificação)
* **Foto do Perfil**: Carregue um avatar personalizado ou use suas iniciais

## Configurações de Segurança

### Autenticação de Dois Fatores (2FA)

Ative o 2FA para adicionar uma camada extra de segurança à sua conta:

1. Vá para **Configurações → Perfil**
2. Clique em **Aplicativo de Autenticação**
3. Escaneie o código QR com seu aplicativo autenticador
4. Digite o código de verificação para confirmar

### Gerenciamento de Senhas

* **Alterar Senha**: Atualize sua senha atual
* **Requisitos de Senha**: Deve ter pelo menos 8 caracteres

## Gerenciamento de Perfil

### Excluir Conta

<Warning>
Excluir sua conta removerá permanentemente seu acesso a todos os workspaces. Esta ação não pode ser desfeita. Você perderá o acesso a todos os espaços de trabalho dos quais é membro. Se você deseja apenas sair de equipes específicas, considere sair de espaços de trabalho individuais em vez disso.
</Warning>

Para excluir sua conta:

1. Vá para **Configurações → Perfil**
2. Role até **Zona de Perigo**
3. Clique em **Excluir Conta**
4. Confirme digitando seu endereço de e-mail
