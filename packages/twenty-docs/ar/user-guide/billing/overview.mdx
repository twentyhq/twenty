## نظرة سريعة

| الخطة                       | الميزات الرئيسية                                                                                                                                                    |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **مجانًا (مستضاف ذاتيًا)**  | جميع ميزات Pro، ودعم المجتمع                                                                                                                                        |
| **Pro (سحابي)**             | كل شيء باستثناء ميزات Premium ‏(SSO، أذونات على مستوى الصف والمزيد)، دعم قياسي                                                                                      |
| **المؤسسة (سحابي)**         | كل ما في Pro + ميزات Premium ‏(SSO، أذونات على مستوى الصف والمزيد)، دعم بأولوية                                                                                     |
| **المؤسسة (مستضاف ذاتيًا)** | كل ما في Pro + ميزات Premium ‏(SSO، أذونات على مستوى الصف والمزيد)، دعم فريق Twenty، غير مطلوب منك نشر التعليمات البرمجية المخصصة الخاصة بك كمصدر مفتوح قبل توزيعها |

## إجابات سريعة

**أين أدير الفوترة؟**
انتقل إلى **Settings → Billing** لعرض خطتك، وتحديث طرق الدفع، والوصول إلى الفواتير.

**هل يمكنني استخدام Twenty مجانًا؟**
نعم! استضف Twenty ذاتيًا واحصل على جميع ميزات Pro دون تكلفة.

**كيف أقوم بالترقية؟**
انتقل إلى **Settings → Billing** ثم انقر **Switch to Organization** أو **Switch to Yearly**.

لمزيد من الأسئلة، راجع [الأسئلة الشائعة حول الفوترة](/ar/user-guide/billing/how-tos/billing-faq).
