## نظرة سريعة

| الخطة                       | الميزات الرئيسية                                                                                                                                                                                      |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **مجانًا (مستضاف ذاتيًا)**  | جميع ميزات CRM في Pro، بالإضافة إلى أدوار مخصصة، وذكاء اصطناعي باستخدام مفاتيح موفر الخدمة الخاصة بك، ودعم المجتمع                                                                                    |
| **Pro (سحابي)**             | كل شيء باستثناء ميزات Premium (الأدوار المخصصة، وأذونات على مستوى الصف، وSSO والمزيد)، واستخدام شخصي للذكاء الاصطناعي، ورصيد واحد لمساحة العمل لكل مستخدم شهريًا، ودعم عبر البريد الإلكتروني والدردشة |
| **المؤسسة (سحابي)**         | كل ما في Pro + ميزات Premium، واستخدام شخصي للذكاء الاصطناعي أكثر بـ5 مرات، و4 أرصدة لمساحة العمل لكل مستخدم شهريًا، ودعم بأولوية                                                                     |
| **المؤسسة (مستضاف ذاتيًا)** | كل ما في Free + ميزات Premium (أذونات على مستوى الصف، وSSO والمزيد)، ودعم فريق Twenty، ولا يُطلب منك نشر التعليمات البرمجية المخصصة الخاصة بك كمصدر مفتوح قبل توزيعها                                 |

## إجابات سريعة

**أين أدير الفوترة؟**
انتقل إلى **Settings → Billing** لعرض خطتك، وتحديث طرق الدفع، والوصول إلى الفواتير.

**هل يمكنني استخدام Twenty مجانًا؟**
نعم! استضف Twenty ذاتيًا واحصل على جميع ميزات Pro دون تكلفة.

**كيف أقوم بالترقية؟**
انتقل إلى **Settings → Billing** ثم انقر **Switch to Organization** أو **Switch to Yearly**.

لمزيد من الأسئلة، راجع [الأسئلة الشائعة حول الفوترة](/ar/user-guide/billing/how-tos/billing-faq).
