## أسئلة شائعة

<AccordionGroup>

  <Accordion title="ما هي قدرات الذكاء الاصطناعي المتاحة؟">
    القدرتان الرئيسيتان للذكاء الاصطناعي هما:

    1. **روبوت دردشة بالذكاء الاصطناعي**: مساعد مدرك للسياق يمكنه الوصول إلى بياناتك في Twenty ومساعدتك في الاستفسارات
    2. **وكلاء الذكاء الاصطناعي في سير العمل**: أتمتة ذكية يمكنها معالجة البيانات واتخاذ القرارات وتنفيذ المهام ضمن سير عملك
  </Accordion>

  <Accordion title="هل لوكلاء الذكاء الاصطناعي حق الوصول إلى جميع بياناتي؟">
    ويعمل وكلاء الذكاء الاصطناعي بموجب نظام التصريح. يمكنك تعيين أدوار محددة لوكلاء الذكاء الاصطناعي ضمن **الإعدادات → الأعضاء → الأدوار**، مما يمنحك سيطرة كاملة على البيانات التي يمكنهم الوصول إليها والإجراءات التي يمكنهم القيام بها.
  </Accordion>

  <Accordion title="كيف تعمل أرصدة الذكاء الاصطناعي؟">
    تستهلك إجراءات الذكاء الاصطناعي أرصدة سير العمل بناءً على تعقيد المهمة ونموذج الذكاء الاصطناعي المستخدم.
  </Accordion>

  <Accordion title="هل يمكنني استخدام نماذج الذكاء الاصطناعي الخاصة بي؟">
    في السحابة، تعمل النماذج على حسابات المزوّد الخاصة بـ Twenty: يمكنك اختيار الحسابات التي تستخدمها مساحة العمل ضمن **الإعدادات → الذكاء الاصطناعي**، ولا توجد طريقة لإضافة مفتاح API خاص بك.

    في مثيل مستضاف ذاتيًا، يعمل المزوّدون المدمجون (OpenAI وAnthropic وGoogle وMistral وxAI) مع كل الخطط، بما في ذلك المجانية. عيّن مفتاح API المطابق (`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GOOGLE_API_KEY`, `MISTRAL_API_KEY`, `XAI_API_KEY`) في **الإعدادات → لوحة الإدارة → متغيرات التكوين**، أو في ملف `.env` ثم أعد تشغيل الخادم. تظهر النماذج بعد ذلك ضمن **الإعدادات → لوحة الإدارة → الذكاء الاصطناعي**.

    موفرو الخدمات المخصصون (نقاط النهاية المخصصة، والبوابات الخاصة، والنماذج المتوافقة مع OpenAI أو المحلية، والمناطق الإضافية)، المُضافون ضمن **الإعدادات → لوحة الإدارة → الذكاء الاصطناعي → موفرو الخدمات المخصصون**، متاحون مجانًا حاليًا لما يصل إلى 25 مقعدًا. بعد ذلك، يلزم استخدام خطة المؤسسات. يوضح قسم الذكاء الاصطناعي في لوحة الإدارة حالة مثيلك.
  </Accordion>

  <Accordion title="لا أرى الدور الذي أسنده لوكيل الذكاء الاصطناعي، أين هي؟">
    افتراضيًا، تتم تصفية قائمة الأدوار لتشمل الأدوار القابلة للإسناد لأعضاء مساحة العمل. إذا كان الدور يمكن تعيينه فقط لوكلاء الذكاء الاصطناعي، تحتاج إلى تغيير الفلتر ليشمل أدوار وكيل AI.
  </Accordion>

</AccordionGroup>
