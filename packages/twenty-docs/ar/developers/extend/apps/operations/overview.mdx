**طبقة العمليات** هي كل ما تفعله *على* تطبيقك بدلًا من *به*: استدعاء أوامر CLI، وتشغيل اختبارات التكامل على خادم Twenty حقيقي، وإعداد CI، وترجمة سلاسله النصية، وإصدار الإصدارات — إما كملف tarball يُنشر على خادم واحد أو كحزمة npm مُدرجة في المتجر.

| الخطوة              | أمر                            |
| ------------------- | ------------------------------ |
| التطوير             | `twenty app dev`               |
| تجربة               | `yarn test`                    |
| البناء              | `twenty app build`             |
| النشر إلى خادم واحد | `twenty app publish --private` |
| النشر على npm       | `twenty app publish`           |
