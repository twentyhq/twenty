## نظرة عامة

بمجرد تثبيت تطبيقك في مساحات عمل أخرى، تحتاج إلى معرفة وقت تعطّله. يسجل Twenty ما يحدث لتطبيقك على المنصة ويعرضه في موضعين:

* **صفحة المراقبة** الخاصة بتسجيل تطبيقك، لك بصفتك مالك التطبيق، مجمّعة عبر كل عمليات التثبيت.
* **سجلات مساحة العمل**، للمسؤولين عن كل مساحة عمل ثبّتت تطبيقك، ومقتصرة على مساحة عملهم فقط.

```text
   your app runs in workspace A, B, C …
              │
              ▼
   platform events (function runs, installs, rate limits, route failures)
              │
      ┌───────┴────────────────────────┐
      ▼                                ▼
   Monitoring page (app owner)      Logs (each workspace admin)
   all installs, aggregated         one workspace, row by row
```

## افتح صفحة المراقبة

انتقل إلى **الإعدادات ← المطورون ← التطبيقات**، وافتح تطبيقك، ثم انقر **عرض المراقبة** في علامة التبويب **عام**. تحتاج إلى إذن **مفاتيح API وخطافات الويب** في مساحة العمل التي تملك تسجيل التطبيق.

اختر فترة في الرأس: آخر ساعتين، أو 24 ساعة، أو 7 أيام، أو 30 يومًا، أو 90 يومًا. يتم الاحتفاظ بالبيانات لمدة **90 يومًا**. من دون استحقاق **سجلات التدقيق**، لا تظهر سوى آخر ساعتين.

## ما تعرضه الصفحة

| قسم                                         | ما الذي تخبرك به                                                                                            |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **الصحة**                                   | الأرقام الرئيسية للفترة ومخطط للأخطاء بمرور الوقت.                                                          |
| **حدود المعدل**                             | طلبات API التي أرسلها تطبيقك ورُفضت، ووظائف المشغّل التي تم تخطيها بسبب بلوغ حد الإضافة إلى قائمة الانتظار. |
| **أرصدة مستخدمة**                           | الأرصدة التي استهلكها تطبيقك بمرور الوقت. تُعرض فقط على الخوادم التي تم تفعيل الفوترة فيها.                 |
| **أهم الأخطاء والتحذيرات**                  | المشكلات الأكثر تكرارًا، مجمّعة حسب رمز الخطأ والوظيفة، مع عدد عمليات التثبيت المتأثرة.                     |
| **عمليات التثبيت والترقيات وإلغاء التثبيت** | تشغيلات دورة الحياة بمرور الوقت وعدد ما فشل منها.                                                           |
| **النسخ**                                   | التشغيلات والإخفاقات لكل نسخة من التطبيق، لاكتشاف إصدار سيئ.                                                |
| **الوظائف**                                 | عمليات التشغيل والإخفاقات ومدة الشريحة المئوية الخامسة والتسعين لكل وظيفة منطقية.                           |

الأعداد دقيقة: يُحتسب كل طلب مرفوض وكل وظيفة تم تخطيها، حتى عندما تحتفظ السجلات أدناه بصف واحد فقط لكل دقيقة.

## ما الذي يتم تسجيله

يُحتسب كل حدث أدناه في صفحة المراقبة. يكتب كل منها أيضًا سجلات التطبيق في مساحة العمل التي حدث فيها، مع **مصدر** يوضح من أين أتى:

| المصدر           | يُسجّل عندما                                                                                                                                                                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LOGIC_FUNCTION` | تكتب وظيفة منطقية سطر سجل أو تفشل، من أي مشغّل. يتم احتساب التشغيلات التي لا تسجل شيئًا وتنجح في صفحة المراقبة، لكنها لا تترك صف سجل.                                                                                                             |
| `INSTALL`        | يتم تثبيت تطبيقك، مع نتيجة خطافات التثبيت.                                                                                                                                                                                                        |
| `UPGRADE`        | تتم ترقية تطبيقك إلى نسخة جديدة.                                                                                                                                                                                                                  |
| `UNINSTALL`      | يتم إلغاء تثبيت تطبيقك.                                                                                                                                                                                                                           |
| `API_RATE_LIMIT` | يُرفض طلب من تطبيقك إلى API بسبب تحديد المعدل.                                                                                                                                                                                                    |
| `JOB_RATE_LIMIT` | يتم تخطي وظائف المشغّل لوظائفك المنطقية بسبب بلوغ حد إضافة الوظائف إلى قائمة الانتظار.                                                                                                                                                            |
| `SERVER_ROUTE`   | يُرفض طلب إلى أحد [مسارات HTTP](/ar/developers/extend/apps/tutorials/document-generator/http-routes) الخاصة بك أو يفشل خارج وظيفتك، مثلًا بسبب طريقة خاطئة أو فشل المصادقة أو خطأ في المنصة. تُسجّل الأخطاء التي تطرحها وظيفتك ضمن `LOGIC_FUNCTION`. |

يمكن أن تتكرر إخفاقات حدود المعدل ومسار الخادم مرات عديدة في الثانية، لذلك تحتفظ السجلات بـ **صف واحد لكل دقيقة** لكل عملية تثبيت ووظيفة ورمز خطأ. تظل صفحة المراقبة تحتسب كل حدوث.

## سجلات مساحة العمل

يرى مسؤولو مساحة العمل التي ثبّتت تطبيقك الأحداث نفسها، لمساحة عملهم فقط، في **الإعدادات ← عام ← السجلات**. يمكنهم التصفية حسب المصدر، مثلًا لإدراج إخفاقات `INSTALL` أو حدود المعدل فقط. وجّه مستخدميك إلى هناك عندما يبلغون عن مشكلة: يخبرانك رمز الخطأ والرسالة بمكان البحث.

بالنسبة إلى خادم التطوير الخاص بك، يبث `twenty app logs` سجلات الوظائف مباشرةً في الطرفية. راجع [CLI](/ar/developers/extend/apps/operations/cli#watching-function-logs).

## قراءة الإشارات

* **تتصاعد الأخطاء مباشرة بعد الإصدار**: قارن النسخ في جدول **النسخ**، ثم أصلح المشكلة وانشر نسخة أعلى. راجع [النشر](/ar/developers/extend/apps/operations/publishing).
* **طلبات API مقيّدة بالمعدل**: يستدعي تطبيقك API بوتيرة متكررة جدًا. جمّع عمليات القراءة والكتابة، وتجنب استدعاء API في حلقات متقاربة.
* **الوظائف مقيّدة بالمعدل**: تُطلق مشغلات أحداث قاعدة البيانات أو cron بسرعة أكبر من إمكانية إضافة الوظائف إلى قائمة الانتظار. ضيّق نطاق المشغّل، مثلًا باستخدام `updatedFields` في مشغّل `databaseEvent`، أو نفّذ العمل في تشغيلات أقل وأكبر. راجع [الوظائف المنطقية](/ar/developers/extend/apps/logic/logic-functions).
* **إخفاقات التثبيت أو الترقية**: تحقّق من [خطافات التثبيت](/ar/developers/extend/apps/config/install-hooks) الخاصة بك. تُسجّل رسالة الخطأ مع الإخفاق.
* **الوظائف البطيئة**: تشير مدة مرتفعة للشريحة المئوية الخامسة والتسعين إلى وظيفة تستحق التحليل أو التقسيم.
