## نظرة عامة

يعرض `CommandBlock` كل أمر مُقدَّم مع علامة موجّه. لا ينفّذ الأوامر ولا يوفّر النسخ تلقائيًا. زوّد `actions` بأي عقدة React، مثل [زر](/ar/ui/primitives/input/button) أو رابط أو حالة. يستخدم نص الأمر دلالات `pre` و`code`، ويحافظ على فواصل الأسطر، ويلتف ضمن العرض المتاح. علامات الموجّه زخرفية.

## استخدام

```tsx
import { useState } from 'react';
import { CommandBlock } from 'twenty-ui/components/data-display';
import { Button } from 'twenty-ui/primitives/input';

export const InstallCommand = () => {
  const [copyLabel, setCopyLabel] = useState('Copy command');

  return (
    <CommandBlock
      commands={['yarn add twenty-ui']}
      actions={
        <Button
          onClick={async () => {
            try {
              await navigator.clipboard.writeText('yarn add twenty-ui');
              setCopyLabel('Copied');
            } catch {
              setCopyLabel('Select and copy the command');
            }
          }}
        >
          {copyLabel}
        </Button>
      }
    />
  );
};
```

تستهدف السمات الأصلية، ومعالجات الأحداث، والفئات، والأنماط، والمراجع عنصر `div` الخارجي. استخدم `render` لتكوين جذر آخر، على سبيل المثال `render={<section aria-label="Installation commands" />}`. يتم تصدير `CommandBlockProps` من `twenty-ui/components/data-display`.

عند الترحيل، استبدل `button` بـ `actions`.
