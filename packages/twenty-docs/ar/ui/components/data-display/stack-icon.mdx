## نظرة عامة

مرر الأيقونة الرئيسية عبر فتحة العقدة `icon` والعنصر المكدس عبر `stackedIcon`. يبلغ عرض الحاوية وارتفاعها 16px؛ ويوضع العنصر المكدس بوضع مطلق على مسافة 8px من اليسار و7px من الأعلى، بحيث يتجاوز الزاوية السفلية اليمنى. الصورة الرمزية المربعة بحجم 12px هي الحجم المقصود لشعار التطبيق. كلتا العقدتين للزينة، لذا أبقِ تسمية مرئية بجانب الأيقونة.

اترك مساحة لتجاوز العنصر المكدس عند وضع المحتوى المجاور. يستخدم المثال فجوة بمقدار 12px بين حاوية الأيقونة وتسميتها.

## استخدام

```tsx
import { StackIcon } from 'twenty-ui/components/data-display';
import { IconBuildingSkyscraper } from 'twenty-ui/icon';
import { Avatar } from 'twenty-ui/primitives/data-display';
import { Text } from 'twenty-ui/primitives/typography';

export const CompanyFieldLabel = () => (
  <Text style={{ display: 'flex', alignItems: 'center', gap: 12 }}>
    <StackIcon
      icon={<IconBuildingSkyscraper size={16} />}
      stackedIcon={
        <Avatar size="xs" shape="square" variant="outline" name="Stripe" />
      }
    />
    <Text>Companies</Text>
  </Text>
);
```

تستهدف السمات والأحداث الأصلية و`className` و`style` و`ref` عنصر div الخارجي. يستبدل `render` ذلك الهدف عبر تركيب Base UI مع الحفاظ على عقدتي الأيقونة كلتيهما.
