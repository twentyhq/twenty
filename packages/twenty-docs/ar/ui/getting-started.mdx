## نظرة عامة

Twenty UI هي مكتبة واجهة مستخدم React مفتوحة المصدر الخاصة بـ Twenty. توفر عناصر أساسية ومكونات مشتركة وأيقونات ورموز مميزة للسمة مع CSS مُعد مسبقًا، لذلك لا يحتاج تطبيقك إلى مترجم CSS-in-JS.

## تثبيت

بالنسبة إلى تطبيق React موجود، ثبّت المكتبة. React 19 مطلوب.

```bash
yarn add twenty-ui
```

يحتوي [محرر التعليمات البرمجية](/ar/ui/components/code-editor/code-editor) على نقطة إدخال منفصلة، `twenty-ui/components/code-editor`. لا تتطلب المكونات الأخرى Monaco. لاستخدام محرر التعليمات البرمجية، ثبّت تبعيات النظير الاختيارية الخاصة به واضبط عمال Monaco لحزمتك قبل تركيبه:

```bash
yarn add @monaco-editor/react monaco-editor
```

إذا كنت تبني تطبيق Twenty، فاتبع [استخدام مكونات Twenty UI](/ar/developers/extend/apps/layout/front-components#using-twenty-ui-components). يوفر عارض المكونات الأمامية سمة مساحة العمل، ويختلف إعداده عن تطبيق متصفح مستقل. أبقِ `twenty-ui` و`twenty-sdk` و`twenty-client-sdk` على الإصدار نفسه.

## حمّل الأنماط ووفّر سمة

استورد ورقة أنماط المكونات وورقة أنماط سمة مرة واحدة عند نقطة دخول تطبيقك. يطبّق `ThemeProvider` فئة السمة النشطة ويجعل قيم السمة متاحة للمكونات.

```tsx
import { Field, Input } from 'twenty-ui/primitives/input';
import { ThemeProvider } from 'twenty-ui/theme';

import 'twenty-ui/style.css';
import 'twenty-ui/theme-light.css';

export const App = () => (
  <ThemeProvider colorScheme="light">
    <Field.Root>
      <Field.Label>Email</Field.Label>
      <Input name="email" type="email" placeholder="you@example.com" />
      <Field.Description>Use your work email address.</Field.Description>
    </Field.Root>
  </ThemeProvider>
);
```

تتضمن ورقة أنماط المكونات إعادة تعيين عامة. راجع تأثيرها عند إضافة Twenty UI إلى تطبيق موجود.

## تجاوز الأنماط

تضع Twenty UI أنماط المكونات وإعادة الضبط في طبقة التسلسل `twenty-ui`. تتجاوز الأنماط التي تكتبها خارج طبقة، مثل `className` أو وحدة CSS أو قاعدة CSS-in-JS، تلك القواعد ذات الطبقات بغض النظر عن خصوصية المحدد أو ترتيب الاستيراد. تظل أوراق أنماط السمة وقواعد Monaco العامة للمحرر الاختيارية دون طبقات.

إعادات ضبط العناصر العامة في تطبيقك دون طبقات أيضًا، لذا ستتجاوز مكونات Twenty UI. أعلن طبقة لها قبل تحميل ورقة أنماط Twenty UI:

```css
@layer reset, twenty-ui;

@layer reset {
  button {
    font: inherit;
  }
}
```

مع Tailwind CSS v4، ضع Twenty UI بين طبقتي الأساس والأدوات المساعدة في Tailwind:

```css
@layer theme, base, twenty-ui, components, utilities;
```

## اختر نقطة إدخال

استورد المكونات من مسارها الفرعي العام للحفاظ على تركيز الاستيرادات:

العناصر الأساسية هي عناصر تحكم تأسيسية، بما في ذلك عناصر التحكم المركبة مثل Select،
Popover، وAlertDialog. تجمع المكونات المشتركة العناصر الأساسية في إعدادات
تصميم متكررة ولبنات بناء تطبيقات قابلة لإعادة الاستخدام. يتلقى كلاهما البيانات واستدعاءات الرجوع
من التطبيق.

استخدم [MainButton](/ar/ui/components/input/main-button) للإجراءات البارزة و
[LightButton](/ar/ui/components/input/light-button) للإجراءات البسيطة. كلاهما
يأتي من `twenty-ui/components/input` ويتشاركان عقد تفاعل
[Button](/ar/ui/primitives/input/button) الأساسي. يبقى التوجيه وتخطيط
الصفحة في التطبيق.

لكل عائلة من العناصر الأساسية والمكونات المشتركة نقطة إدخال عامة مطابقة، مثل
`twenty-ui/primitives/input` و`twenty-ui/components/settings`. تصدّر إدخالات
`twenty-ui/primitives` و`twenty-ui/components` المجمّعة عائلاتها المعنية.
تعيد نقطة الإدخال الجذرية `twenty-ui` تصدير العناصر الأساسية والمكونات المشتركة والأيقونات ورموز السمة المميزة
والأدوات المساعدة. للأصول ومساعدات الاختبار ومحرر التعليمات البرمجية الاختياري نقاط إدخال منفصلة.

| استيراد                              | المحتويات                                                                          |
| ------------------------------------ | ---------------------------------------------------------------------------------- |
| `twenty-ui/assets`                   | الشعارات والأصول الثابتة                                                           |
| `twenty-ui/components`               | جميع مجموعات المكونات المشتركة باستثناء المحرر الاختياري                           |
| `twenty-ui/components/data-display`  | مجموعات الصور الرمزية، وكتل الأوامر، وأشجار JSON، والمقاييس، ومربعات الأيقونات     |
| `twenty-ui/components/feedback`      | وسائل الشرح، واللافتات المضمنة، والإشعارات                                         |
| `twenty-ui/components/input`         | إعدادات الأزرار المسبقة، وحقول الإدخال المتخصصة، والمنتقيات، وعناصر التحكم المجزأة |
| `twenty-ui/components/layout`        | الأقسام، والقوائم المتجاوزة، وانتقالات الأيقونات                                   |
| `twenty-ui/components/navigation`    | القوائم المنسدلة، وتركيبات القوائم، وإجراءات علامات التبويب                        |
| `twenty-ui/components/settings`      | صفوف الإعدادات مع عناصر تحكم مُسمّاة                                               |
| `twenty-ui/components/code-editor`   | محرر التعليمات البرمجية، ورأس المحرر، ومساعدات سمة المحرر                          |
| `twenty-ui/primitives`               | جميع عائلات العناصر الأساسية                                                       |
| `twenty-ui/primitives/accessibility` | العناصر المخفية ومساعدات التفاعل بلوحة المفاتيح                                    |
| `twenty-ui/primitives/data-display`  | الصور الرمزية والشارات والرقائق والوسوم وعينات الألوان ومؤشرات الحالة              |
| `twenty-ui/primitives/feedback`      | اللافتات ومؤشرات التقدم وأدوات التحميل والعناصر النائبة                            |
| `twenty-ui/primitives/input`         | الأزرار وعناصر التحكم في النماذج                                                   |
| `twenty-ui/primitives/layout`        | التوسيع، والفواصل، والاتجاه، وتغيير الحجم                                          |
| `twenty-ui/primitives/navigation`    | مسارات التنقل وعناصر القوائم وعلامات التبويب                                       |
| `twenty-ui/primitives/surfaces`      | البطاقات ومربعات الحوار والنوافذ المنبثقة وتلميحات الأدوات                         |
| `twenty-ui/primitives/typography`    | النصوص والعناوين والاختصارات والنصوص المتجاوزة                                     |
| `twenty-ui/icon`                     | [الأيقونات والبحث الديناميكي](/ar/ui/icons)                                           |
| `twenty-ui/testing`                  | [مُزيّنات وتخطيطات Storybook](/ar/ui/testing)                                         |
| `twenty-ui/theme`                    | موفر السمة والخطافات ومراجع متغيرات CSS                                            |
| `twenty-ui/utilities`                | الخطافات والأدوات المساعدة المشتركة                                                |

استورد الأيقونات الفردية، مثل `IconCheck`، من `twenty-ui/icon`. يتضمن موفر الأيقونات الديناميكي كتالوج الأيقونات الكامل، لذا خصصه للواجهات التي تحتاج إلى البحث عن الأيقونات في وقت التشغيل.

## خطافات الاستجابة

استورد `useIsMobile` و`useIsTouchDevice` و`useMediaQuery` من `twenty-ui/utilities`.

| الخطّاف                | الاستعلام                                                         | استخدام                                       |
| ---------------------- | ----------------------------------------------------------------- | --------------------------------------------- |
| `useIsMobile()`        | `MOBILE_MEDIA_QUERY`، حتى `MOBILE_VIEWPORT` وبما في ذلك           | اختر تخطيطًا مضغوطًا.                         |
| `useIsTouchDevice()`   | `TOUCH_DEVICE_MEDIA_QUERY`، `(hover: none) and (pointer: coarse)` | اختر سلوك التفاعل باللمس بشكل مستقل عن العرض. |
| `useMediaQuery(query)` | أي استعلام وسائط يدعمه `window.matchMedia`                        | اشترك في استعلام وسائط مخصص.                  |

تأتي ثوابت الاستعلام من `twenty-ui/utilities`؛ ويأتي `MOBILE_VIEWPORT` من `twenty-ui/theme`. تتشارك الاشتراكات قائمة `MediaQueryList` واحدة لكل استعلام، وتُحدَّث عند تغير تطابقها. تعيد الخطافات `false` أثناء العرض على الخادم، وأول عرض للترطيب، وعندما يكون `window.matchMedia` غير متاح.

في [مكون واجهة أمامية لـ Twenty](/ar/developers/extend/apps/layout/front-components#current-limitations)، تتبع استعلامات العرض مربع الأداة. لذلك يتبع `useIsMobile` عرض الأداة، بينما يتبع `useIsTouchDevice` الإدخال الأساسي للجهاز. استخدم [تجاوزات القصص](/ar/ui/testing#media-query-overrides) لاختبار هذه الحالات في Storybook.
