## نظرة عامة

يعرض `Loader` نقطة متحركة داخل كبسولة صغيرة ذات حدود. استخدمه أثناء تنفيذ عملية وعندما تكون النسبة المئوية غير معروفة. للتقدم الرقمي، استخدم [شريط التقدم](/ar/ui/primitives/feedback/progress-bar).

## استخدام

```tsx
import { Loader } from 'twenty-ui/primitives/feedback';
import { Text } from 'twenty-ui/primitives/typography';

type SaveFeedbackProps = { isSaving: boolean };

export const SaveFeedback = ({ isSaving }: SaveFeedbackProps) => (
  <Text
    render={<div />}
    role="status"
    style={{ display: 'flex', alignItems: 'center', gap: 8 }}
  >
    {isSaving && <Loader color="blue" aria-hidden="true" render={<span />} />}
    {isSaving ? 'Saving changes' : 'Changes saved'}
  </Text>
);
```

ضع نص حالة مرئيًا بجانب أداة التحميل ضمن غلاف. أداة التحميل مؤشر مرئي ثابت الحجم ولا تقبل عناصر فرعية.

يمتلك التطبيق حالة التحميل. أبقِ غلاف الحالة مركّبًا لكي يمكن الإعلان عن تحديثات النص. لا يعيّن المُحمِّل تسمية أو دور منطقة حية افتراضيًا. استخدم `aria-hidden="true"` عندما يوفّر النص المحيط أو الزر ملاحظات التحميل بالفعل.

## التركيب والتسمية الأصليان

تستهدف الخصائص الأصلية و`className` و`style` و`ref` عنصر div الحاوية. يقبل `render` عنصرًا أو دالة رد نداء عبر تركيب Base UI. تتجاوز الأنماط إعدادات اللون الافتراضية. يتم تصدير `LoaderProps` من عائلة الملاحظات.

للحصول على مؤشر مستقل، وفّر دور حالة صريحًا واسمًا متاحًا. تظل النقطة المتحركة زخرفية.

```tsx
import { Loader, type LoaderProps } from 'twenty-ui/primitives/feedback';

const loadingProps: LoaderProps = {
  role: 'status',
  'aria-label': 'Loading results',
  color: 'blue',
};

export const LoadingResults = () => (
  <Loader {...loadingProps} render={<span />} />
);
```

استخدم `aria-labelledby` بدلًا من ذلك عندما يحدد النص المرئي اسم الحالة. أبقِ مالك المنطقة الحية مُثبّتًا عندما يحتاج إلى الإعلان عن نص متغير. يتحكم التطبيق في وقت ظهور الملاحظات وما تقوله.

## اللون

مرّر لونًا من لوحة ألوان النسق لتعيين كلٍّ من الحد والنقطة. من دون لون، يرث المحمّل لون الزر المحيط عند توفره، وإلا فيستخدم لون النص الثالثي. لإجراء زر، يُفضّل استخدام [حالة تحميل الزر](/ar/ui/primitives/input/button#state-ownership)، التي تُبقي الملاحظات داخل عنصر التحكم.
