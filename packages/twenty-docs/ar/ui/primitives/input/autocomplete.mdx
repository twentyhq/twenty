## نظرة عامة

استخدم `Autocomplete` للاقتراحات المرتبطة بحقل إدخال نصي. يحافظ حقل الإدخال على مؤشر الكتابة وتركيز لوحة المفاتيح بينما تبرز مفاتيح الأسهم الاقتراحات. استخدم [تحديد](/ar/ui/primitives/input/select) عندما يجب على المستخدم اختيار قيمة من قائمة ثابتة. يبقى [Dropdown](/ar/ui/components/navigation/dropdown) المكوّن الأعلى مستوىً للقوائم والمنتقيات.

## استخدام

مرر `items` إلى `Root` واعرضها عبر `List` لكي تؤدي التصفية إلى تحديث الاقتراحات المرئية. يُميّز `autoHighlight="always"` النتيجة الأولى كلما فُتحت القائمة.

```tsx
import { Autocomplete } from 'twenty-ui/primitives/input';

const FRUITS = ['Apple', 'Banana', 'Cherry'];

export const FruitInput = () => (
  <Autocomplete.Root items={FRUITS} autoHighlight="always">
    <Autocomplete.InputGroup>
      <Autocomplete.Input aria-label="Fruit" placeholder="Search fruits" />
    </Autocomplete.InputGroup>
    <Autocomplete.Portal>
      <Autocomplete.Positioner>
        <Autocomplete.Popup>
          <Autocomplete.Empty>No fruits found</Autocomplete.Empty>
          <Autocomplete.List>
            {(fruit: string) => (
              <Autocomplete.Item key={fruit} value={fruit}>
                {fruit}
              </Autocomplete.Item>
            )}
          </Autocomplete.List>
        </Autocomplete.Popup>
      </Autocomplete.Positioner>
    </Autocomplete.Portal>
  </Autocomplete.Root>
);
```

يتحكم `value` و`onValueChange` في نص الإدخال. استخدم `defaultValue` لقيمة أولية غير متحكم بها. حالة الفتح مستقلة: استخدم `open` و`onOpenChange`، أو `defaultOpen`. يتعامل `Item.onClick` مع كل من التحديد بالمؤشر ومفتاح Enter من حقل الإدخال.

يقوم `mode="list"` بالتصفية دون تغيير نص الإدخال عند الإبراز. يوفر `mode="both"` أيضًا إكمالًا مضمنًا. يبقي `mode="inline"` كل العناصر ويوفر إكمالًا مضمنًا؛ ويبقي `mode="none"` كل العناصر دون إكمال مضمن. يمنع `readOnly` الإكمال المضمن من تغيير الإدخال.

## البنية

أبقِ الأجزاء ذات الصلة داخل `Autocomplete.Root` مُثبَّت. ركّب وجهة البوابة وغلاف التموضع والمحتوى كلًّا على حدة. يجمع `InputGroup` اختياريًا الإدخال مع عناصر التحكم المجاورة ويربط النافذة المنبثقة بتلك المجموعة.

```text
Autocomplete.Root
├── Autocomplete.InputGroup (optional)
│   ├── Autocomplete.Input
│   ├── Autocomplete.Clear (optional)
│   └── Autocomplete.Trigger (optional)
│       └── Autocomplete.Icon (optional)
├── Autocomplete.Portal
│   ├── Autocomplete.Backdrop (optional)
│   └── Autocomplete.Positioner
│       └── Autocomplete.Popup
│           ├── Autocomplete.Arrow (optional)
│           ├── Autocomplete.Empty
│           └── Autocomplete.List
│               ├── Autocomplete.Item
│               ├── Autocomplete.Group (optional)
│               │   ├── Autocomplete.GroupLabel
│               │   └── Autocomplete.Collection
│               │       └── Autocomplete.Item
│               ├── Autocomplete.Row (optional, with Root.grid)
│               │   └── Autocomplete.Item
│               └── Autocomplete.Separator (optional)
├── Autocomplete.Status (optional)
└── Autocomplete.Value (optional)
```

| الجزء        | الغرض والهدف الأصلي                                                             |
| ------------ | ------------------------------------------------------------------------------- |
| `Root`       | يدير قيمة الإدخال والتصفية والإبرازات وحالة الفتح. لا يعرض أي عنصر.             |
| `القيمة`     | يقرأ نص الإدخال عبر العناصر الأبناء أو دالة عرض. لا يعرض أي عنصر.               |
| `InputGroup` | يجمع الإدخال وعناصر التحكم المجاورة. يستهدف عنصر div.                           |
| `إدخال`      | يعرض حقل إدخال المربع المركب ويحافظ على تركيز لوحة المفاتيح. يستهدف عنصر إدخال. |
| `المشغّل`    | يفتح الاقتراحات أو يغلقها. يستهدف زرًا.                                         |
| `Icon`       | يحتوي على مؤشر مشغّل. يستهدف عنصر span.                                         |
| `مسح`        | يمسح قيمة الإدخال. يستهدف زرًا.                                                 |
| `Portal`     | يختار الوجهة وسياسة التثبيت. يستهدف عنصر div الخاص ببوابته.                     |
| `Backdrop`   | يوفر تراكبًا اختياريًا أسفل النافذة المنبثقة. يستهدف عنصر div.                  |
| `Positioner` | يدير المرساة والمحاذاة والإزاحات ومعالجة التصادم. يستهدف عنصر div الخاص به.     |
| `Popup`      | يعرض محتوى الاقتراح وسلوك التركيز الاختياري. يستهدف عنصر div الخاص به.          |
| `Arrow`      | يوفر سهمًا اختياريًا مموضعًا داخل Popup. يستهدف عنصر div.                       |
| `قائمة`      | يعرض العناصر المُصفّاة. يستهدف عنصر div بدور مربع قائمة أو شبكة.                |
| `Item`       | يعرض اقتراحًا ويتعامل مع التحديد بالمؤشر أو بلوحة المفاتيح. يستهدف عنصر div.    |
| `مجموعة`     | يجمع العناصر ذات الصلة. يستهدف عنصر div.                                        |
| `GroupLabel` | يضع تسمية على مجموعته الأصلية. يستهدف عنصر div.                                 |
| `Row`        | يجمع صفًا من العناصر عند تمكين `Root.grid`. يستهدف عنصر div.                    |
| `Collection` | يعرض العناصر المُصفّاة عبر عنصر ابن دالة. لا يعرض أي عنصر.                      |
| `Separator`  | يفصل العناصر أو المجموعات بصريًا. يستهدف عنصر div.                              |
| `فارغ`       | يُعلن عند عدم توفر عناصر مطابقة. يستهدف عنصر div.                               |
| `الحالة`     | يعلن عن التغييرات، مثل حالة التحميل غير المتزامن. يستهدف عنصر div.              |

تحتفظ الأجزاء المعروضة بالسمات الأصلية والمعالجات والمراجع و`className` و`style` المستندين إلى الحالة، وتركيب `render` للعنصر/الدالة من واجهة Base UI API المثبتة. تستهدف الخصائص والمراجع الأصلية عنصر الجزء نفسه. يجب أن تمرر المكونات المخصصة الخصائص والمراجع المتوفرة. تُصدَّر خصائص الأجزاء العامة وأنواع الحالة من `twenty-ui/primitives/input`، إلى جانب إجراءات Root وأنواع تفاصيل أحداث التغيير/الإبراز.

يوفر `Autocomplete.useFilter()` المطابقة المراعية للغة لـ `contains` و`startsWith` و`endsWith`. يقرأ `Autocomplete.useFilteredItems\<TItem>()` المجموعة المُصفّاة داخليًا ضمن Root. اعتبر تلك النتيجة للقراءة فقط.

## عناصر الكائنات والعناصر المجمّعة

يمكن أن تكون العناصر سلاسل نصية أو كائنات عشوائية. استخدم `itemToStringValue` لتوفير النص المستخدم للتصفية والإكمال وإرسال النموذج. تستخدم الكائنات التي على هيئة `{ value, label }` تسميتها تلقائيًا. اعرض قيمة العنصر نفسها المتوفرة عبر Root؛ لا يلزم شكل عنصر خاص بـ Twenty أو خاصية لمساواة التحديد. يدير Autocomplete إدخال النص بدلًا من قيمة كائن محدد منفصلة.

للبيانات المجمّعة، مرر مجموعات تتضمن مصفوفة `items`. يحافظ Root على نوع العنصر لـ `itemToStringValue` و`onItemHighlighted`. اعرض العناصر الأبناء المُصفّاة لكل مجموعة عبر `Group` و`Collection`:

```tsx
import { Autocomplete } from 'twenty-ui/primitives/input';
import { Text } from 'twenty-ui/primitives/typography';

type City = { id: number; name: string; country: string };
type CityGroup = { label: string; items: City[] };

const CITY_GROUPS: CityGroup[] = [
  {
    label: 'Europe',
    items: [
      { id: 1, name: 'Paris', country: 'France' },
      { id: 2, name: 'Lisbon', country: 'Portugal' },
    ],
  },
];

export const GroupedCityInput = () => (
  <Text
    style={{ display: 'grid', alignContent: 'start', gap: 8, width: '100%' }}
  >
    <label htmlFor="grouped-city">
      <Text render={<span />}>City</Text>
    </label>
    <Autocomplete.Root
      items={CITY_GROUPS}
      itemToStringValue={(city) => city.name}
      autoHighlight="always"
    >
      <Autocomplete.Input id="grouped-city" placeholder="Search cities" />
      <Autocomplete.Portal>
        <Autocomplete.Positioner>
          <Autocomplete.Popup>
            <Autocomplete.Empty>No matching cities</Autocomplete.Empty>
            <Autocomplete.List>
              {(group: CityGroup) => (
                <Autocomplete.Group key={group.label} items={group.items}>
                  <Autocomplete.GroupLabel>
                    {group.label}
                  </Autocomplete.GroupLabel>
                  <Autocomplete.Collection>
                    {(city: City) => (
                      <Autocomplete.Item
                        key={city.id}
                        value={city}
                        description={city.country}
                      >
                        {city.name}
                      </Autocomplete.Item>
                    )}
                  </Autocomplete.Collection>
                </Autocomplete.Group>
              )}
            </Autocomplete.List>
          </Autocomplete.Popup>
        </Autocomplete.Positioner>
      </Autocomplete.Portal>
    </Autocomplete.Root>
  </Text>
);
```

يوفر `Item.startIcon` و`Item.endIcon` و`Item.description` محتوى داعمًا. ركّب `Trigger` و`Clear` مع [Button](/ar/ui/primitives/input/button) من Twenty UI عبر `render`. يمكن أن يحتوي `Icon` على أيقونة من `twenty-ui/icon`. أبقِ `Status` و`Empty` مُثبَّتين أثناء تحديث العناصر الأبناء حتى تتمكن قارئات الشاشة من الإعلان عن التغييرات.

## التصفية الخارجية واقتراحات الخادم

استخدم `filteredItems` عندما يدير تطبيقك التصفية. يجب أن يحافظ على البنية المسطحة أو المجمّعة لـ `items`. يقبل `filter` دالة مطابقة مخصصة؛ ويعطّل `filter={null}` التصفية الداخلية للنتائج التي صفّاها خادم مسبقًا.

```tsx
import { useState } from 'react';
import { Autocomplete } from 'twenty-ui/primitives/input';

const CITIES = ['Paris', 'London', 'Lisbon'];

export const CityPrefixInput = () => {
  const [value, setValue] = useState('');
  const { startsWith } = Autocomplete.useFilter();
  const filteredItems = CITIES.filter((city) => startsWith(city, value));

  return (
    <Autocomplete.Root
      items={CITIES}
      filteredItems={filteredItems}
      value={value}
      onValueChange={setValue}
      autoHighlight="always"
    >
      <Autocomplete.Input aria-label="City prefix" />
      <Autocomplete.Portal>
        <Autocomplete.Positioner>
          <Autocomplete.Popup>
            <Autocomplete.Empty>No matching cities</Autocomplete.Empty>
            <Autocomplete.List>
              {(city: string) => (
                <Autocomplete.Item key={city} value={city}>
                  {city}
                </Autocomplete.Item>
              )}
            </Autocomplete.List>
          </Autocomplete.Popup>
        </Autocomplete.Positioner>
      </Autocomplete.Portal>
    </Autocomplete.Root>
  );
};
```

أبقِ Root مُثبَّتًا عند وصول النتائج بشكل غير متزامن. تحكم في `open` بشكل مستقل كي تتمكن الاستجابة من فتح الاقتراحات مع بقاء التركيز في الإدخال. يمكن لـ `Status` مُثبَّت أن يعلن عن التحميل؛ حدّث `Empty` عندما لا تحتوي الاستجابة المكتملة على نتائج. يتولى المكوّن الأب إزالة الارتداد وإلغاء الطلبات والحماية من الاستجابات القديمة.

يتلقى `onValueChange` و`onOpenChange` تفاصيل الحدث المصدر، بما فيها `reason` و`event` الأصلي و`trigger` و`cancel()` و`allowPropagation()`. يقرر المستدعون المتحكمون أي التحديثات المطلوبة ينبغي اعتمادها. على سبيل المثال، تجاهل تغيير قيمة `escape-key` للاحتفاظ باستعلام خادم، أو تجاهل الفتح بـ `input-change` حتى وصول النتائج. يتلقى `onItemHighlighted` العنصر المكتوب الأصلي وسبب إبرازِه. يحافظ الإلغاء على دلالات Base UI المثبتة؛ ولا يستبدل سياسة الحالة المتحكم بها للتطبيق.

## تركيب الإدخال والنماذج الأصلية

يقبل `Input` ‎`size="sm"` أو `size="md"` ويستخدم الأنماط نفسها المستخدمة في [Input](/ar/ui/primitives/input/input). ركّبه مع إدخال موجود باستخدام `render`. يصبح التحكم المُركّب بعد ذلك مسؤولًا عن مظهره: لا يضيف `Input` أي أنماط لـ Input ويتجاهل `size`، لكنه يمرّر `className` والسمات الأصلية والمعالجات والمرجع وسمات الحالة الخاصة بك. مرّرها إلى عنصر الإدخال الفعلي. اعرض `Input` الخاص بـ Twenty للحفاظ على المظهر القياسي.

يوفر `InputGroup` تخطيطًا ومرساة من دون إضافة حدود لحقل الإدخال. يمكن أن يحتوي على شرائح أو يعرض غلافًا موجودًا. استخدم [InputGroup](/ar/ui/primitives/input/input-group) عبر الخاصية `render` الخاصة به عندما تحتاج المجموعة كاملةً إلى تنسيق الإدخال، كما في مثال اقتراحات الكائنات المجمّعة. يفقد `Input` بدون `render` داخله حدوده الخاصة. امنح حقل الإدخال تسمية متاحة أو ركّبه مع [Field](/ar/ui/primitives/input/field).

يحافظ Root على `name` و`form` و`disabled` و`readOnly` وسلوك النموذج الأصلي المصدر. تستهدف السمات الأصلية والمرجع الخاصان بـ Input عنصر الإدخال الخاص به. يتيح `submitOnItemClick` إرسال النموذج عند تحديد اقتراح؛ ولا يرسل الإعداد الافتراضي النموذج.

يحافظ Input على معالجة IME الأصلية في Base UI، بما في ذلك أحداث التركيب وحارس التأكيد بلوحة المفاتيح.

يحتفظ إصدار Base UI المثبت باستعلام غير متحكم به عند إعادة تعيين النموذج الأصلي. لاستعلام متحكم به، عالج `onReset` الخاص بالنموذج واستعد القيمة الأولية للتطبيق.

## الموضع ووجهة البوابة والرفض

تكون القيم الافتراضية لـ `Positioner` هي `side="bottom"` و`align="start"` و`sideOffset={8}`. يحتفظ بعقد المرساة والتموضع في Base UI المثبت، بما في ذلك مراسي العناصر/المراجع/الدوال/الافتراضية، والإزاحات الوظيفية، و`positionMethod` و`collisionBoundary` و`collisionPadding` و`collisionAvoidance` و`arrowPadding` و`sticky` و`disableAnchorTracking`. اضبط هذه الإعدادات على Positioner. يتحكم DirectionProvider في الموضع المنطقي واتجاه DOM.

يستخدم `Popup` عرض المرساة كحد أدنى لعرضه. اضبط `width` الخاص به لتوفير عرض محتوى ثابت. تستهدف خصائصه الأصلية وأنماطه وتركيب العرض والمرجع عنصر المحتوى بشكل مستقل عن Positioner وPortal. يحتفظ `initialFocus` و`finalFocus` الخاصان بـ Popup بخيارات التركيز المصدر. افتراضيًا، تبقي الاقتراحات التركيز في الإدخال.

اضبط `container` و`keepMounted` على `Portal`. يؤدي حذف الحاوية إلى استخدام وجهة ThemeProvider المقيّدة الأقرب، ثم بوابة Base UI الأصلية أو جسم المستند. تنتظر قيمة `null` صريحة دون عرض حتى يتم توفير حاوية. تمر وجهات العنصر وShadowRoot والمرجع إلى Base UI. يحتفظ مرجع غير محلول بالرجوع إلى بوابة Base UI الأصلية/الجسم.

تحافظ الوجهة المقيّدة الافتراضية على رموز CSS ونظام الألوان الخاصين بها. ترث الوجهة الصريحة CSS من نطاق DOM الفعلي الخاص بها، لذا ضعها داخل نطاق السمة المقصود أو وفر تلك الأنماط هناك. يبقى سياق React والاتجاه متاحين عبر البوابات. تحتاج أهداف ShadowRoot إلى CSS وأنماط السمة الخاصة بالمكتبة في شجرة الظل تلك.

تغيّر مفاتيح الأسهم العنصر المبرز بينما يحتفظ الإدخال بالتركيز. يحدد Enter العنصر؛ ويطلب Escape والتفاعل الخارجي الرفض باستخدام الدلالات المصدر. يمكن لضغطة خارجية تنشيط عنصر التحكم الوجهة. يمكن للمنتقيات الأعلى مستوىً أن تدير سياسة تنشيط مختلفة في محولها. استدعِ `event.preventBaseUIHandler()` في `onKeyDown` الخاص بـ Input لتجاوز المعالج المضمّن لمفتاح تتولى معالجته بنفسك. استخدم `event.preventDefault()` أيضًا عند منع الإجراء الأصلي للمتصفح.

يعرض `Root.inline` مع `open` الاقتراحات دون تجميع النافذة المنبثقة. تحتفظ العناصر المضمنة باستدعاءات تحديد `onClick` الخاصة بها، لكن المكوّن المصدر المثبت يملأ الإدخال تلقائيًا فقط عند وجود Popup الخاص به. عالج `Item.onClick` عندما ينبغي أن يحدّث التحديد المضمن النص المتحكم به. يدعم `Root.grid` و`Row` التنقل في الشبكة. تحتفظ هذه الأوضاع بواجهات API للمجموعة والعرض المصدر.

## الترحيل

غلّف Popup بـ `Autocomplete.Positioner` و`Autocomplete.Portal`. يتطلب Positioner سياق Portal؛ وتتجاهل الاقتراحات المضمنة تجميع النافذة المنبثقة بالكامل. انقل خصائص الموضع والمرساة والتصادم من Popup إلى Positioner. انقل إعدادات `container` والتثبيت إلى Portal. أبقِ العرض وأنماط المحتوى والخصائص الأصلية والمعالجات والمراجع على Popup. استخدم عنصرًا ابنًا صريحًا `Arrow` لسهم.

داخل مكونات الواجهة، أبقِ سياسة البوابة المقيّدة الحالية. لا توسع واجهة API هذه وجهات بوابة العارض أو إمكانات الهندسة والتمرير والرفض؛ إذ إن تلك الإمكانات الخاصة بالعارض لها ملكية منفصلة. تحتفظ محولات المنتقيات الإنتاجية بسير عمل التنشيط المتعمد الخاص بها.
