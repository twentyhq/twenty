## نظرة عامة

يكشف `NumberField` عن الأجزاء السبعة كافةً لحقل الأرقام Base UI المثبّت: `Root` و`Group` و`Input` و`Decrement` و`Increment` و`ScrubArea` و`ScrubAreaCursor`. استورده من `twenty-ui/primitives/input`. يحتفظ بالحالة الرقمية والتنسيق والتدرّج وتفاصيل الأحداث والتكامل مع النماذج الأصلية في Base UI، مع تنسيق Twenty UI للإدخال والمجموعة وعناصر التحكم في الضبط.

للاستخدام مع الإعداد المسبق المضغوط ذي التنسيق الثابت والإعدادات الافتراضية لخطوة المعدِّل، استخدم [NumberStepper](/ar/ui/components/input/number-stepper) من `twenty-ui/components/input`.

## استخدام

`Root` يمتلك الحالة الرقمية. `Input` هو إدخال النص المرئي. استخدم `Group` لترتيب عنصري التحكم الاختياريين للإنقاص والزيادة حوله. وفّر المحتوى والأسماء المتاحة لعناصر التحكم؛ فلا يضيف البدائي أيقونات أو تسميات.

```tsx
import { IconMinus, IconPlus } from 'twenty-ui/icon';
import { Field, NumberField } from 'twenty-ui/primitives/input';

export const QuantityInput = () => (
  <Field.Root>
    <Field.Label>Quantity</Field.Label>
    <NumberField.Root name="quantity" defaultValue={3} min={0} max={10}>
      <NumberField.Group>
        <NumberField.Decrement aria-label="Decrease quantity">
          <IconMinus size={16} />
        </NumberField.Decrement>
        <NumberField.Input />
        <NumberField.Increment aria-label="Increase quantity">
          <IconPlus size={16} />
        </NumberField.Increment>
      </NumberField.Group>
    </NumberField.Root>
    <Field.Description>Choose up to ten items.</Field.Description>
  </Field.Root>
);
```

ترتبط `Field.Label` و`Field.Description` و`Field.Error` بالإدخال المرئي. بدلًا من ذلك، مرّر `aria-label` أو `aria-labelledby` إلى `Input`. القيمة الافتراضية لـ `aria-roledescription` هي `Number field`؛ وهي لا توفّر اسمًا متاحًا.

## القيم ودوال الاستدعاء

احذف `value` لحقل غير متحكَّم فيه، ووفّر `defaultValue` رقميًا عند الحاجة إلى قيمة أولية. يبدأ فارغًا عند حذف `defaultValue`. لحقل متحكَّم فيه، مرّر رقمًا أو `null` عبر `value` وحدّثه من `onValueChange`.

```tsx
import { useState } from 'react';
import { Field, NumberField } from 'twenty-ui/primitives/input';

export const PriceInput = () => {
  const [price, setPrice] = useState<number | null>(null);
  const [savedPrice, setSavedPrice] = useState<number | null>(null);

  return (
    <Field.Root>
      <Field.Label>Price</Field.Label>
      <NumberField.Root
        value={price}
        onValueChange={setPrice}
        onValueCommitted={setSavedPrice}
      >
        <NumberField.Input placeholder="Enter a price" />
      </NumberField.Root>
      <Field.Description>
        Last committed price: {savedPrice ?? 'empty'}
      </Field.Description>
    </Field.Root>
  );
};
```

ينتج عن المسح `null`، بما في ذلك عند ضبط `min`. تظل المسودات غير المكتملة مثل `-` قابلة للتحرير من دون الإبلاغ عن رقم غير صالح. تؤدي الكتابة القابلة للتحليل إلى تحديث القيمة الرقمية قبل تثبيت التحرير. تبدأ الخطوة الأولى من قيمة فارغة من الصفر المقيَّد بالحدود؛ وتستخدم الخطوات اللاحقة مقدار الخطوة النشط.

يحتفظ `onValueChange(value, details)` بـ `event` و`reason` و`cancel` و`allowPropagation` و`isCanceled` و`isPropagationAllowed` و`trigger` و`direction` الاختياري. تميّز الأسباب بين الكتابة (`input-change`) والمسح (`input-clear`) والتسوية عند فقدان التركيز (`input-blur`) واللصق (`input-paste`) ولوحة المفاتيح وضغوط الزيادة أو الإنقاص والعجلة والسحب والتعبئة التلقائية الأصلية (`none`). يمنع استدعاء `cancel()` تحديث الحالة الرقمية؛ لكن المتحكّمين يختارون قيمتهم المقبولة مع ذلك.

يُشغَّل `onValueCommitted(value, details)` عند فقدان التركيز بعد التحرير، وعند تحرير المؤشر بعد التخطي أو السحب، وفورًا لتعديلات لوحة المفاتيح والعجلة. يثبّت المسح `null` عند فقدان التركيز. تحتوي تفاصيل التثبيت على `event` و`reason`؛ وهي تفاصيل عامة بلا أساليب لإلغاء التغيير. لا يؤدي التركيز على حقل لم يُلمس ثم فقدان التركيز عنه إلى تثبيت قيمة بحد ذاته عندما لا تكون هناك حاجة إلى تسوية رقمية. يمكن لخيارات التقريب الصريحة تسوية قيمة لم تُلمس وتثبيتها.

## الإعدادات المحلية والتنسيق

اضبط `locale` و`format` على `Root`. يحتفظان بعقد Base UI المثبّت: يقبل `locale` ‏`Intl.LocalesArgument`، ويقبل `format` ‏`Intl.NumberFormatOptions`. تنسيق العرض منفصل عن القيمة الرقمية الأولية التي يرسلها النموذج. لا يفرض البدائي أرقامًا لاتينية أو تجميعًا أو دقة أو خطوات معدِّل.

<StoryEmbed storyId="ui-input-numberfield--locale-currency" title="تنسيق الإعدادات المحلية والعملة" height={140} />

```tsx
import { Field, NumberField } from 'twenty-ui/primitives/input';

export const AmountInput = () => (
  <Field.Root>
    <Field.Label>Amount in euros</Field.Label>
    <NumberField.Root
      name="amount"
      defaultValue={1234.5}
      locale="de-DE"
      format={{ style: 'currency', currency: 'EUR' }}
      step={0.5}
      smallStep={0.01}
      largeStep={10}
    >
      <NumberField.Input />
    </NumberField.Root>
  </Field.Root>
);
```

تستخدم الكتابة واللصق الإعدادات المحلية المضبوطة ورموز التنسيق المدعومة. يُسوّي فقدان التركيز النص المعروض. يمكن لخيارات الدقة أو التقريب الصريحة أيضًا تسوية الرقم المثبّت؛ ومن دون تلك الخيارات، لا يستبدل التنسيق وحده قيمة رقمية لم تُلمس بنص عرض مقرّب.

## التخطي والحدود

القيمة الافتراضية لـ `step` هي `1`، ولـ `smallStep` هي `0.1` أثناء الضغط على Alt، ولـ `largeStep` هي `10` أثناء الضغط على Shift. تنطبق الخطوة النشطة على الأزرار والسهم للأعلى والسهم للأسفل والعجلة وحركة منطقة السحب. القيمة الافتراضية لـ `snapOnStep` هي `false`؛ فعّله لمحاذاة التعديلات مع الخطوة النشطة. يحدّد Home وEnd الحد الصريح المقابل. يمكن لمعالجات المفاتيح الأصلية استدعاء `event.preventBaseUIHandler()` عندما يحتاج المالك إلى تجاوز سلوك لوحة مفاتيح Base UI.

`min` و`max` شاملان. تظل تفاعلات التخطي ضمن الحدود. افتراضيًا، تُقيَّد القيم المكتوبة والملصقة رقميًا أيضًا، مع تسوية المسودة عند فقدان التركيز. اضبط `allowOutOfRange` لقبول التعديلات المباشرة خارج تلك الحدود، والسماح للتحقق الأصلي من النطاق أو تحقق التطبيق بالإبلاغ عن المشكلة.

يعطّل `step="any"` التحقق الأصلي من الخطوة، بينما يستخدم التخطي التفاعلي `1` وخطوات المعدِّل المضبوطة. مع خطوة رقمية، وفّر `min` صراحةً عندما يجب أن يتحقق الإرسال الأصلي من محاذاة الخطوة. لا تقرّب الخطوة الرقمية كل قيمة مكتوبة إلى خطوة.

## السحب

يغيّر `ScrubArea` القيمة الرقمية أثناء تحرك المؤشر. وهو يدعم الحركة الأفقية أو العمودية، و`pixelSensitivity`، و`teleportDistance` الاختياري. تنطبق الخطوة النشطة والحدود أيضًا على السحب. استخدم تسمية مرئية كهدف للسحب مع إبقاء الإدخال متاحًا للتحرير بلوحة المفاتيح.

<StoryEmbed storyId="ui-input-numberfield--with-scrubbing" title="اسحب تسمية العرض" height={150} />

أنشئ `ScrubAreaCursor` داخل `ScrubArea` للحصول على مؤشر مخصص أثناء السحب مع قفل المؤشر. يُنقل إلى نص المستند أثناء نشاطه. يعود Base UI إلى المؤشر العادي لإدخال اللمس، وقفل المؤشر المرفوض، وWebKit. اضبط `allowWheelScrub` على `Root` للسماح بالضبط بالعجلة أثناء تركيز الإدخال والتمرير فوقه؛ وقيمته الافتراضية هي `false`.

## النماذج وحالة التعطيل

يعرض `Root` عنصر `input type="number"` أصليًا مخفيًا لإرسال القيمة الرقمية الأولية والتحقق الأصلي. اضبط `name` و`form` و`required` و`min` و`max` و`step` على `Root`. يمكن أن يربط `form` الحقل بنموذج في موضع آخر من المستند. تستخدم عناصر تحكم الضبط الافتراضية `type="button"`، لذلك لا يؤدي التخطي إلى إرسال النموذج.

يمنع `disabled` التفاعل ويستثني القيمة من الإرسال. يمنع `readOnly` التغييرات مع إبقاء الإدخال المرئي قابلاً للتركيز وقيمة نموذجه متاحة. استخدم قيمة متحكَّمًا فيها عندما يجب على التطبيق إعادة تعيين الحالة الرقمية؛ إذ إن إعادة تعيين النموذج الأصلية لا تعيد تعيينها.

## أهداف DOM والتخصيص

| الجزء أو الخاصية          | هدف DOM وref الافتراضي                                                                |
| ------------------------- | ------------------------------------------------------------------------------------- |
| `Root` / `Root.ref`       | عنصر `div` الخارجي                                                                    |
| `Root.inputRef`           | إدخال الرقم الأصلي المخفي                                                             |
| `Root.id`                 | يربط معرّف إدخال النص المرئي                                                          |
| `Group` / `Group.ref`     | عنصر `div` للمجموعة                                                                   |
| `Input` / `Input.ref`     | عنصر `input type="text"` المرئي                                                       |
| `Decrement` / `Increment` | أزرار أصلية                                                                           |
| `ScrubArea`               | عنصر `span`                                                                           |
| `ScrubAreaCursor`         | عنصر `span` يُنقل إلى نص المستند أثناء نشاطه؛ وتكون قيمة ref الخاصة به null بخلاف ذلك |

تستهدف السمات الأصلية و`className` و`style` و`render` الجزء الذي يتلقاها. ينطبق تخصيص الإدخال على عنصر التحكم المرئي؛ أما تخصيص الغلاف فيوضع على `Root` أو `Group`. لتركيز عنصر التحكم، استخدم `Input.ref` بدلًا من `Root.inputRef`.

يقبل كل جزء عنصرًا أو دالة استدعاء عبر `render`، مع نوع الحالة العامة المقابل. مرّر الخصائص وref المقدمة إلى عنصر DOM المناسب لكي يستمر عمل التحرير والتركيز والتسميات والتحقق. عندما يعرض عنصر تحكم التخطي عنصرًا ليس زرًا، اضبط `nativeButton={false}`. يقبل `className` و`style` أيضًا دوال استدعاء للحالة. تتضمن الحالة `value` الرقمي و`inputValue` المنسق و`required` و`disabled` و`readOnly` و`scrubbing` وحالة Field الموروثة.

تصدّر نقاط الإدخال العامة الخصائص ونوع الحالة لكل جزء، بالإضافة إلى `NumberFieldRootChangeEventDetails` و`NumberFieldRootChangeEventReason` و`NumberFieldRootCommitEventDetails` و`NumberFieldRootCommitEventReason`.

## عارض مكوّن الواجهة الأمامية

تتحقق تجهيزات صندوق الحماية لـ React وPreact من تنسيق الإعدادات المحلية الأولي، واللصق المترجم محليًا، وقيم النموذج الرقمية الأولية، والتسميات المتاحة، وrefs، وتركيب العرض، والتثبيت عند فقدان التركيز، وتفاصيل التغيير والتثبيت بلوحة المفاتيح، وتفاصيل التغيير بالمؤشر.

تؤدي الكتابة المتتابعة بعد مسح حقل محلي متحكَّم فيه حاليًا إلى إعادة تعيين موضع المؤشر في العارض: إذ يمكن أن تؤدي كتابة `2` ثم `3` إلى إنتاج `32`. يمكن أن يتسابق ضبط مؤشر منسق أيضًا مع فقدان التركيز ويترك الإدخال المرئي يعرض القيمة السابقة. تبلغ تعديلات المؤشر عن التغييرات، لكن تحرير المؤشر لا يقدّم دالة استدعاء التثبيت المقابلة؛ وقد يثبّت فقدان التركيز اللاحق باستخدام `input-blur` بدلًا من ذلك. لا يتوفر أيضًا في صندوق الحماية سحب منطقة السحب واستخدام مؤشرها المخصص. لا تؤثر هذه القيود في مضيفات React العادية.
