## Личная информация

### Имя и электронная почта

* **Отображаемое имя**: Обновите, как ваше имя будет отображаться другим участникам рабочего пространства
* **Адрес электронной почты**: Измените ваш логин (требуется подтверждение)
* **Изображение профиля**: Загрузите пользовательский аватар или используйте свои инициалы

## Настройки безопасности

### Двухфакторная аутентификация (2FA)

Включите 2FA, чтобы добавить дополнительный уровень безопасности к вашему аккаунту:

1. Перейдите в **Настройки → Профиль**
2. Нажмите **Приложение-аутентификатор**
3. Сканируйте QR-код с помощью вашего приложения аутентификатора
4. Введите код подтверждения, чтобы подтвердить

### Потеряли доступ к аутентификатору

Если вы не можете получить доступ к приложению для аутентификации, попросите администратора рабочего пространства предоставить код восстановления. Код можно использовать один раз, и по умолчанию его срок действия истекает через 1 час. Затем:

1. Войдите, используя адрес электронной почты и пароль
2. На экране проверки нажмите **Потеряли аутентификатор? Использовать код восстановления**
3. Введите код восстановления и нажмите **Продолжить**

Ваш текущий аутентификатор для этого рабочего пространства будет удален, а выход из других сеансов будет выполнен. Снова настройте двухфакторную аутентификацию в разделе **Настройки → Профиль**.

### Управление паролями

* **Изменить пароль**: Обновите ваш текущий пароль
* **Требования к паролю**: Должен содержать не менее 8 символов

## Управление профилем

### Удаление аккаунта

<Warning>
Удаление вашего аккаунта навсегда лишит вас доступа ко всем рабочим пространствам. Это действие нельзя отменить. Вы потеряете доступ ко всем рабочим пространствам, в которых вы являетесь участником. Если вы хотите выйти только из определённых команд, рассмотрите возможность покинуть отдельные рабочие пространства вместо этого.
</Warning>

Чтобы удалить ваш аккаунт:

1. Перейдите в **Настройки → Профиль**
2. Прокрутите до **Опасной зоны**
3. Нажмите **Удалить аккаунт**
4. Подтвердите, введя свой адрес электронной почты
