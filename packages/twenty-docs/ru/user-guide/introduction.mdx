## Сделайте двадцать подходящий для вашей команды

Двадцать построено для изменения с вашим бизнесом. В этом руководстве показано, как настроить рабочую область и формировать ее по мере вашего ухода, от данных, которые вы отслеживаете до экранов, ваша команда работает каждый день.

* **Настройте ваши данные.** Объекты и поля моделирования вокруг вашего бизнеса, затем приведите ваши записи из CSV файлов или другой CRM.
* **Подпишитесь на разговоры.** Синхронизируйте электронную почту и календарь так, чтобы все обменные участки в правильной карте и связывались с вашими контактами с почтовыми кампаниями.
* **Организуйте работу.** Стройте виды, трубопроводы и страницы записей, которые использует ваша команда ежедневно.
* **Автоматизируйте процесс работы.** Рука повторяющихся шагов для рабочих процессов и многошаговых задач для ИИ агентов.
* **Оставайтесь в управлении.** Следите за своими номерами на панели инструментов, решайте, кто видит какие роли и управляет счетами и настройками.
