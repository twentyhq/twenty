## Кампании для команд продаж

<Warning>
**Бета-функция**: кампании по электронной почте находятся в бета-версии. Свяжитесь с нами в чате, чтобы включить их для вашего рабочего пространства.
</Warning>

Ваша команда продаж уже работает в Twenty. Здесь находятся ваши аккаунты, люди, воронка продаж, активности и пользовательские данные. Кампании позволяют работать с этими данными без экспорта в отдельный маркетинговый инструмент.

Кампании поддерживают связь «один ко многим». Вы создаёте одно письмо для целевого списка, а не отдельный черновик для каждого лида. Такие поля, как имя человека, всё ещё можно заполнить при отправке кампании.

<img src="/images/user-guide/email-campaigns/campaigns-list.png" style={{ width: '100%' }} />

Используйте кампании для проведения сценариев продаж, которыми было бы трудно управлять, отправляя письма по одному:

* **Работайте с целевыми аккаунтами.** Связывайтесь с нужными людьми в компаниях определённой отрасли, региона, размера или уровня аккаунта.
* **Продвигайте зависшие сделки.** Отправляйте полезные последующие сообщения людям, связанным со сделками, которые слишком долго не продвигаются.
* **Проводите мероприятия и исходящие кампании.** Приглашайте людей, соответствующих профилю вашего идеального клиента, а не каждый контакт из вашей базы данных.
* **Развивайте существующие аккаунты.** Связывайтесь с клиентами на основе их тарифа, использования, даты продления или любого пользовательского поля, которое отслеживает ваша команда.

## Используйте уже выполненную работу в CRM

### Создавайте более качественные сегменты

Создайте список на основе данных, которые уже поддерживает ваша команда: владелец аккаунта, этап сделки, отрасль, последняя активность, тариф продукта, оценка лида или ваши пользовательские поля. Без экспорта CSV. Без загрузки. Без второй базы данных контактов, которую нужно синхронизировать.

### Замечайте сигнал и действуйте

Используйте пользовательские панели мониторинга, диаграммы и воронки, чтобы определить, где застревает выручка. Затем создайте целевую кампанию на основе этого сигнала. Кампании превращают отчёт, который видит ваша команда, в следующий шаг, который она может предпринять.

### Поддерживайте работу с помощью рабочих процессов

Рабочие процессы могут создавать и обновлять списки и участников списков при изменении записей. Например, добавляйте новых людей, соответствующих профилю вашего идеального клиента, в список для исходящих кампаний или перемещайте контакты в список для последующих сообщений, когда сделка достигает определённого этапа. Аудитория вашей кампании может соответствовать тому, как работает ваша команда продаж.

См. [Рабочие процессы](/ru/user-guide/workflows/overview), чтобы создавать автоматизации для вашего процесса продаж.

### Используйте ИИ, когда это экономит время

Попросите ИИ Twenty найти нужных людей, создать список или подготовить черновик кампании для списка. Он использует доступные ему данные CRM и соблюдает разрешения вашего рабочего пространства. Он подготавливает работу; ваша команда проверяет её и решает, отправлять ли её.

Полный рабочий процесс см. в разделе [Создание кампании с помощью ИИ](/ru/user-guide/email-campaigns/how-tos/create-a-campaign-with-ai).

### Держите результаты рядом с работой

После отправки кампания показывает, кто её получил, какие письма не были доставлены, какие были пропущены и отметил ли кто-нибудь их как спам. Используйте эту информацию при планировании следующего сценария.

## Отправляйте со своего домена

Кампании отправляются с адреса на вашем домене, поэтому люди знают, кто их отправил. Twenty проведёт вас через проверку домена и также разместит страницу отписки на вашем домене.

Ваше рабочее пространство может отправлять до 1 000 писем кампаний в день. Нужен более высокий лимит? Свяжитесь с нами в чате. Мы рассматриваем каждый запрос и повышаем лимиты в индивидуальном порядке.
