## Обзор

ИИ полезен, когда у вас есть цель продаж, но вы не хотите начинать с пустого списка или пустого письма. Сообщите ему, что вы пытаетесь сделать. Он может просмотреть вашу CRM, создать целевой список и подготовить одну кампанию для этого списка. Вы проверяете работу, отправляете тестовое письмо, а затем решаете, отправлять ли его.

<Note>
  ИИ может подготовить кампанию, но не может её отправить. Отправка всегда остаётся вашим
  решением.
</Note>

<Note>
  Кампании предназначены для массовой рассылки. ИИ создаёт один черновик с одной темой и одним текстом
  письма для выбранного списка; он не создаёт отдельный черновик для каждого лида.
</Note>

## Чем может помочь ИИ

| Задача                   | Пример                                                                                                                   |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| **Найти людей**          | "Найди лиц, принимающих решения, в компаниях-разработчиках ПО в Германии с должностью руководителя или вице-президента." |
| **Создать список**       | "Создай список открытых возможностей в сфере здравоохранения."                                                           |
| **Подготовить кампанию** | Напишите тему, текст, призыв к действию и персонализацию для сценария продаж.                                            |
| **Персонализировать**    | Добавьте переменные, например `{{name.firstName}}`, чтобы при отправке кампания включала это значение.                   |
| **Улучшить черновик**    | "Сделай текст более прямым", "Добавь CTA для демо" или "Предложи три варианта темы."                                     |

ИИ действует в рамках ваших разрешений. Он может просматривать и изменять только записи, к которым у вашей роли есть доступ.

## Сочетайте ИИ с рабочими процессами

ИИ помогает решить, что сказать и кому это сказать. Рабочие процессы поддерживают данные и списки в готовности для следующей кампании.

Списки и участники списков — это записи в Twenty. Рабочий процесс может создавать или обновлять их по мере изменения вашей CRM. Это позволяет повторяемо создавать сегменты для продаж вместо того, чтобы каждый раз начинать с нуля.

| Сценарий продаж            | Что делает рабочий процесс                                                                                          | Где помогает ИИ                                                      |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **Новые лиды ICP**         | Когда новый лид соответствует вашим критериям, добавьте его в список для исходящих рассылок.                        | Подготовьте одну кампанию для этого сегмента.                        |
| **Застрявшие возможности** | Найдите сделки, которые бездействовали заданное время, и создайте список для повторного контакта.                   | Подготовьте одну кампанию для выбранного списка повторного контакта. |
| **Расширение аккаунта**    | Добавляйте контакты, когда у аккаунта наступает дата продления, меняется план или происходит другое важное событие. | Подготовьте одну кампанию для списка продлений или расширений.       |

Рабочие процессы подготавливают или обновляют список. ИИ может изучить данные CRM и подготовить одну кампанию для этого списка. Вы по-прежнему проверяете аудиторию и выбираете время отправки.

См. [Рабочие процессы](/ru/user-guide/workflows/overview), чтобы создать автоматизацию для сценария продаж.

## Часть 1: Откройте ИИ

Нажмите `@` в любом месте Twenty или `Cmd+K` (`Ctrl+K` в Windows) и выберите **Спросить ИИ**.

## Часть 2: Создайте аудиторию

Сообщите ИИ, кто должен получить письмо. Используйте поля в своём рабочем пространстве, как если бы вы разговаривали с коллегой.

> Создай список под названием "Обновление продукта за 4 квартал" со всеми сотрудниками компаний из сферы здравоохранения, в которых работает более 50 человек.

ИИ ищет в ваших записях, создаёт список и добавляет найденных людей. Откройте список и проверьте участников перед отправкой.

<Warning>
  Добавляйте только людей, согласившихся получать ваши письма. Ваша CRM может включать людей,
  с которыми вы только обменивались письмами. См.
  [Рекомендации по email-кампаниям](/ru/user-guide/email-campaigns/how-tos/email-campaign-best-practices).
</Warning>

## Часть 3: Напишите кампанию

Сообщите ИИ цель, ключевые моменты, тон и необходимый призыв к действию.

> Напиши повторное письмо для людей из открытых возможностей в сфере здравоохранения. Тема должна содержать не более 50 символов. Начни с короткого дружелюбного вступления, обращаясь к каждому человеку по имени, назови три причины, почему панель отчётности может помочь их команде, и закончи кнопкой "Записаться на демо" со ссылкой на https://example.com/demo.

ИИ создаёт черновик с названием, темой и текстом письма. Откройте его в разделе **Кампании**, чтобы просмотреть в редакторе.

<img src="/images/user-guide/email-campaigns/ai-chat-campaign.png" style={{ width: '50%' }} />

Чтобы внести изменения, продолжайте общение. Сначала откройте кампанию, чтобы ИИ понял, какую из них вы имеете в виду:

* "Сделай тон более прямым."
* "Сократи вступление до двух предложений."
* "Замени текст кнопки на «Записаться на демо»."
* "Предложи ещё три варианта темы."

Вы можете в любой момент отредактировать черновик самостоятельно.

## Часть 4: Проверьте и отправьте

<img src="/images/user-guide/email-campaigns/campaign-composer.png" style={{ width: '100%' }} />

ИИ пишет черновик. Вы выбираете отправителя, аудиторию и время отправки:

1. Откройте вкладку кампании **Электронная почта**.
2. Выберите адрес **От**, список в поле **Кому** и, при необходимости, **Тему отписки**.
3. Прочитайте письмо. Проверьте факты, ссылки и цены.
4. Нажмите **Тест** и отправьте себе копию.
5. Нажмите **Отправить**, затем выберите **Отправить сейчас** или **Отправить позже**.

Каждый шаг подробно описан в разделе [Отправка первой кампании](/ru/user-guide/email-campaigns/how-tos/send-your-first-campaign).

## Советы по составлению хороших запросов

* **Используйте название поля.** «Люди из компаний в сфере здравоохранения» понятнее, чем «лиды в сфере здравоохранения».
* **Сообщайте факты.** ИИ не знает ваше предложение, цену или процесс продаж, если вы не сообщите ему об этом или если этой информации нет в вашей CRM.
* **Ставьте задачу.** Укажите, для кого это, что вы хотите, чтобы они сделали, и почему это важно для них.
* **Запрашивайте варианты.** Попробуйте три варианта темы или две версии одного сообщения для разных сегментов.
* **Проверяйте размер списка.** Перед отправкой спросите: «Сколько людей в списке «Обновление продукта за 4 квартал»?»

## Ограничения

* ИИ может редактировать только кампании, которые всё ещё находятся в статусе **Черновик**.
* Темы отписки и список отписки управляются в разделе **Настройки**, а не через ИИ. См. [Управление отписками и темами](/ru/user-guide/email-campaigns/how-tos/manage-unsubscribes-and-topics).
* ИИ может ошибаться в фактах. Всегда читайте письмо перед отправкой.

См. [Чат-бот с ИИ](/ru/user-guide/ai/capabilities/ai-chatbot), чтобы узнать больше о возможностях ИИ в вашем рабочем пространстве.
