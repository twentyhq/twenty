<AccordionGroup>
<Accordion title="Можем ли мы экспортировать все данные рабочей области до отмены, включая пользовательские объекты, пользовательские поля, отношения, заметки, задачи, вложения, потоки, права доступа и историю аудита?">
Данные проекта могут быть экспортированы перед отменой за некоторыми исключениями: панели управления, процессы и разрешения должны быть переданы вручную; журналы аудита не могут быть переданы.
</Accordion>
<Accordion title="Какие элементы не могут быть экспортированы или перенесены?">
Большинство элементов можно экспортировать или мигрировать за некоторыми исключениями:
* рабочие процессы, панели инструментов и все настройки (ключи API, вебхуки, журналы аудита, пользовательские настройки и т.д.) должно быть перенесено вручную
* Объекты и поля приложения, созданные приложением, могут быть перенесены путем установки указанного приложения в другом проекте. Они не должны быть перенесены вручную
* некоторые записи, такие как версии рабочего процесса и рабочий процесс, не передаются вообще, и ожидается потеря
* некоторые объекты, такие как сообщения и связанные с календарем объекты, не должны экспортироваться, так как они создаются, когда аккаунт подключен и периодически синхронизируется. Они будут синхронизированы снова, как только вы подключите свою учетную запись (пока у вас есть доступ к указанной учетной записи) если это аккаунт члена команды, который покинул вашу компанию, то эти сообщения должны быть экспортированы, в противном случае они будут утеряны)
</Accordion>
<Accordion title="Есть ли официальное облако для самостоятельной процедуры миграции или для службы миграции?">
На данный момент отсутствует официальная процедура миграции с использованием облака на самообслуживание. Общая идея заключается в следующем:
* сначала установите приложения для создания объектов и полей
* репликация пользовательских объектов и полей, добавленных пользователями
* использовать скрипт с клавишами API или инструменты ИИ для переноса всех данных из одной рабочей области в другую
* все непередаваемые объекты должны быть перенесены вручную

Пожалуйста, имейте в виду:
* Вы можете отправить до 50 запросов в минуту на план Pro или 100 запросов в минуту на план организации перед тем, как попасть в запрос / мин. лимит
* каждый запрос API может иметь до 200 записей
* некоторые данные в таких полях, как Created by Timeline активностей и Updated by будут потеряны во время импорта и перезаписаны системой
</Accordion>
<Accordion title="Экспортируются ли файлы в открытых и документированных форматах?">
Экспортированные файлы в интерфейсе находятся в формате Excel, все API запросы могут быть сохранены в формате JSON.
</Accordion>
