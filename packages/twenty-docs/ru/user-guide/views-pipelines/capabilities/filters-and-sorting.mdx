## Фильтрация данных

Фильтры помогают сосредоточиться на конкретных записях, показывая только те, которые соответствуют вашим критериям.

### Добавление фильтра

1. Нажмите **Фильтр** на панели инструментов
2. Выберите поле для фильтрации
3. Выберите оператор
4. Введите или выберите значение

Фильтр применяется сразу после ввода или выбора значения. Такие операторы, как **Пусто** или **В прошлом**, применяются сразу.

### Операторы фильтра

| Тип поля                                                                               | Операторы                                                                                      |
| -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Текст**, **Электронные адреса**, **Телефоны**, **Ссылки**, **Адрес**, **Полное имя** | Содержит, Не содержит, Пусто, Не пусто                                                         |
| **Число**, **Валюта**, **Рейтинг**                                                     | Равно, Не равно, Больше или равно, Меньше или равно, Пусто, Не пусто                           |
| **Дата**, **Дата и время**                                                             | Равно, Относительная дата, В прошлом, В будущем, Сегодня, До, После или равно, Пусто, Не пусто |
| **Выбор**                                                                              | Равно, Не равно, Пусто, Не пусто                                                               |
| **Множественный выбор**                                                                | Содержит, Не содержит, Пусто, Не пусто                                                         |
| **Истина/Ложь**                                                                        | Является                                                                                       |
| **Связь**                                                                              | Равно, Не равно, Пусто, Не пусто                                                               |
| **Участник** (например, Создано пользователем)                                         | Содержит, Не содержит, Пусто, Не пусто                                                         |
| **Массив**, **JSON**, **Файлы**                                                        | Содержит, Не содержит, Пусто, Не пусто                                                         |

<Tip>
**Содержит** соответствует части текста независимо от регистра. Используйте его, чтобы найти значение в текстовом поле, например название города.
</Tip>

* Фильтры **Выбор**, **Множественный выбор** и **Связь** принимают несколько значений и показывают записи, соответствующие любому из них
* Фильтры по связям работают с полями, которые указывают на одну запись, например с полем **Компания** человека

### Объединение фильтров

Фильтры, добавленные через **Фильтр**, объединяются с помощью И: записи должны соответствовать всем им. При выборе поля, для которого уже есть фильтр, этот фильтр открывается для редактирования.

### Расширенный фильтр

Используйте расширенный фильтр, чтобы показывать записи, соответствующие одному или другому условию (логика ИЛИ):

1. Нажмите **Фильтр → Расширенный фильтр**
2. Настройте первое правило: поле, оператор и значение
3. Нажмите **Добавить правило фильтра → Добавить правило** и настройте второе правило
4. Во втором правиле переключите **И** на **Или**

**Пример:** люди из Парижа или Лондона

* **Город** Содержит "Париж"
* **Или** **Город** Содержит "Лондон"

Вы также можете:

* Сочетайте **И** и **Или** с помощью **Добавить правило фильтра → Добавить группу правил**. У каждой группы есть собственный соединитель
* Фильтровать по полю связанной записи, например по полю **Имя** компании **Компания** человека
* Фильтровать по одной части составного поля, например по городу в адресе

Расширенный фильтр отображается на панели представления в виде чипа, например **2 расширенных правила**. Нажмите его, чтобы отредактировать правила. Он объединяется с другими вашими фильтрами с помощью И.

### Удаление фильтров

* Нажмите **X** на чипе фильтра
* Нажмите **X** на чипе расширенных правил, чтобы удалить расширенный фильтр
* Чтобы удалить одно правило, нажмите меню **⋮** в конце его строки и выберите **Удалить правило** (или **Удалить группу правил**)
* Нажмите **Сбросить**, чтобы вернуться к сохраненным в представлении фильтрам и сортировкам

## Сортировка данных

Сортировка определяет порядок отображения записей.

### Добавление сортировки

1. Нажмите **Сортировка** на панели инструментов
2. Выберите **По возрастанию** или **По убыванию** в верхней части меню
3. Выберите поле для сортировки

Сортировка применяется сразу после выбора поля.

### Несколько сортировок

Добавьте несколько уровней сортировки:

* Первая сортировка — основная
* Последующие сортировки применяются внутри групп равных значений

### Сортировка из заголовка столбца

1. Нажмите заголовок столбца
2. Выберите **Сортировка**

Первая сортировка выполняется по возрастанию. Снова выберите **Сортировка**, чтобы переключаться между сортировкой по возрастанию и по убыванию.

Чтобы удалить сортировку, нажмите **X** на ее чипе на панели представления.

## Сохранение настроек фильтров и сортировки

Сохраните фильтры и сортировки в представлении:

1. Настройте фильтры и сортировки
2. Нажмите **Обновить представление**, чтобы сохранить их в текущем представлении
3. Или нажмите стрелку рядом с **Обновить представление** и выберите **Создать представление**, чтобы сохранить их как новое представление

В представлениях по умолчанию, например **Все компании**, нажмите **Сохранить как новое представление**.
