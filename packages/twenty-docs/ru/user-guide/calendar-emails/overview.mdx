## Параметры подключения

### Учетная запись Google (Gmail и Календарь Google)

1. Перейдите в **Настройки → Аккаунты**
2. Нажмите **Добавить аккаунт**
3. Выберите **Продолжить с Google**
4. Авторизуйте Twenty на доступ к вашим Gmail и Google Календарю
5. Настройте параметры синхронизации электронной почты (видимость, автоматическое создание) → нажмите **Далее**
6. Настройте параметры синхронизации календаря (видимость, автоматическое создание) → нажмите **Добавить учетную запись**
7. Ваши электронные письма и события календаря начнут автоматически синхронизироваться

### Учетная запись Microsoft (Outlook и Календарь Microsoft)

1. Перейдите в **Настройки → Аккаунты**
2. Нажмите **Добавить аккаунт**
3. Выберите **Продолжить с Microsoft**
4. Авторизуйте Twenty на доступ к вашим Outlook и Microsoft Календарю
5. Настройте параметры синхронизации электронной почты (видимость, автоматическое создание) → нажмите **Далее**
6. Настройте параметры синхронизации календаря (видимость, автоматическое создание) → нажмите **Добавить учетную запись**
7. Ваши электронные письма и события календаря начнут автоматически синхронизироваться

### Настройка IMAP/SMTP/CalDAV (другие провайдеры)

Для других провайдеров электронной почты и календаря:

1. Перейдите в **Настройки → Аккаунты**
2. Настройте параметры IMAP для синхронизации входящей почты и параметры SMTP для отправки электронной почты
3. Настройте параметры CalDAV для календаря
4. Проверьте соединение

<Note>
**Самостоятельный хостинг во внутренней сети**: По умолчанию Twenty отклоняет исходящие подключения к частным/внутренним IP-адресам (защита от SSRF). Если ваш сервер поставщика услуг почты, календаря или удостоверений работает на локальном/частном IP (например, локальный сервер в сети LAN), подключения к нему будут заблокированы. Чтобы разрешить их, укажите имена хостов или IP-литералы в следующей переменной окружения на сервере:

```
OUTBOUND_HTTP_ALLOWED_INTERNAL_HOSTS=mail.internal,keycloak,192.168.1.10
```

Записи сопоставляются только по имени хоста (`keycloak`, а не `http://keycloak:8080/realms/…`), без подстановочных знаков. Все остальные исходящие запросы (действия HTTP рабочих процессов, вебхуки, подключения SSO и IMAP/SMTP/CalDAV) остаются защищёнными, и даже разрешённый хост никогда не сможет получить доступ к диапазону адресов метаданных облака. Установите значение `*`, чтобы полностью отключить защиту, что допустимо только в доверенных изолированных сетях. Если ранее вы установили `OUTBOUND_HTTP_SAFE_MODE_ENABLED=false`, удалите его: пока он задан, защита остаётся полностью отключённой, а список игнорируется.
</Note>

### Несколько почтовых ящиков

* **Неограниченное количество аккаунтов**: Подключайте несколько учетных записей электронной почты для каждого пользователя
* **Выбор отправителя**: выберите, какая учетная запись будет отправлять каждое электронное письмо, которое вы пишете в Twenty
* **Настройки синхронизации**: Настройте различные параметры для каждого почтового ящика

<Warning>
Можно подключить только настоящие почтовые ящики (например, support@domain.com с собственным инбоксом). Электронные алиасы, которые перенаправляют на другой ящик, не могут быть подключены к Twenty.
</Warning>

## Конфигурация электронной почты

### Видимость сообщений

Выберите различные уровни видимости для ваших электронных писем:

* **Только метаданные**: Делитесь только базовой информацией (отправитель, получатель, дата, время)
* **Тема и метаданные**: Делитесь строкой темы и метаданными
* **Всё содержание письма**: Делитесь полным содержимым электронного письма, включая вложения

### Автоматическое создание контактов

* **Отключено**: Автоматическое создание контактов не производится
* **Для отправленных и полученных сообщений**: создание контактов для всех внешних взаимодействия по электронной почте
* **Только для отправленных сообщений**: Создайте контакты только для отправленных вами писем
* **Примечание**: по умолчанию внутренние письма (где все участники используют ваш домен) не синхронизируются для защиты конфиденциальности

<Note>Когда эта опция включена, контакты автоматически связываются с записями компании на основе их домена электронной почты. Если компании еще не существует, Twenty создаст ее для вас.</Note>

<Note>
**Синхронизация внутренних писем**: поведение «внутренние письма не синхронизируются» установлено по умолчанию, но его можно отключить:
1. Перейдите в **Настройки → Коммуникация**
2. Включите переключатель **Синхронизировать внутренние письма**, чтобы включить письма, в которых все участники используют один и тот же домен

Это настройка для всего рабочего пространства (полезно для университетов или организаций с общим доменом).
</Note>

### Управляйте, какие электронные письма будут синхронизированы с выбором папок сообщений

Управляйте, какие папки электронной почты синхронизируются с Twenty:

1. Перейдите в **Настройки → Аккаунты** и выберите подключённый аккаунт электронной почты
2. Выберите папки для синхронизации:
   * **Входящие**: Основные входящие письма
   * **Отправленные**: Исходящие письма, которые вы отправили
   * **Пользовательские папки**: Любые определенные папки, которые вы хотите включить
   * **Исключение папок**: Пропускайте папки, такие как Спам, Корзина либо личные папки

Это позволяет вам тщательно управлять, какие письма появятся в вашей CRM без синхронизации всего.

**Что синхронизируется:**

* **Внешние письма**: Все письма с внешними контактами из выбранных папок
* **Внутренние письма**: по умолчанию не синхронизируются (письма с тем же доменом остаются приватными). Включите **Синхронизация внутренних писем** в разделе **Настройки → Коммуникация**, чтобы включить их для всей рабочей области.
* **Вложения**: Будет доступно в H1 2026

**Примечание**: Мы не предоставляем адрес электронной почты CC для выборочной синхронизации. Вместо этого используйте функцию папки сообщений выше для получения такого же уровня контроля над тем, какие письма синхронизируются с Twenty.

## Конфигурация календаря

### Видимость событий

Выберите, что будет видно другим пользователям в вашем рабочем пространстве:

* **Всего**: вся информация о событии будет передана вашей команде
* **Метаданные**: Только дата и участники будут переданы вашей команде

### Авто создание контактов для встреч

* **Да**: Автоматически создавайте контакты для участников встречи, не находящихся в вашем CRM
* **Нет**: Связывайте встречи только с существующими контактами

<Note>Когда эта опция включена, контакты автоматически связываются с записями компании на основе их домена электронной почты. Если компании еще не существует, Twenty создаст ее для вас.</Note>

### Контролировать, какие события синхронизируются

* **Импорт встреч**: Автоматически импортируйте события в календаре
* **Связь с контактами**: Связывайте встречи с записями о людях и компаниях

**Что синхронизируется:**

* **Встречи**: События в календаре с внешними участниками
* **Связь с контактами**: События автоматически связаны с записями CRM
* **Командные события**: Видимость общего календаря

## Частота синхронизации

**Обновления каждые 5 минут**: Данные по электронной почте и календарю синхронизируются автоматически каждые 5 минут после начального импорта.

<Note>
**Сроки начальной синхронизации**: Синхронизация календаря завершается быстро (обычно в течение нескольких минут), а синхронизация почты занимает больше времени для больших почтовых ящиков. Twenty импортирует письма примерно со скоростью **400 сообщений в минуту** (ограничено лимитами частоты Gmail API), поэтому импорт почтового ящика с 10 000 письмами занимает около 25 минут. Не беспокойтесь, если вы видите, что контакты из событий календаря появляются раньше ваших контактов из электронной почты; это нормальное поведение.
</Note>
