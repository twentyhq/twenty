## Обзор

Twenty получает почту общего почтового ящика, когда ваш поставщик отправляет копию каждого входящего сообщения на частный адрес, который Twenty создаёт для вас. После настройки почтовый ящик появится в вашем рабочем пространстве.

Пересылка — это первая часть канала электронной почты. Чтобы также отвечать или отправлять кампании через него, см. [Каналы электронной почты](/ru/user-guide/calendar-emails/capabilities/email-channels).

У Microsoft 365 и Google Workspace есть собственные руководства:

* [Microsoft 365](/ru/user-guide/calendar-emails/how-tos/forward-a-shared-inbox-from-microsoft-365)
* [Google Workspace](/ru/user-guide/calendar-emails/how-tos/forward-a-shared-inbox-from-google-workspace)

Эта страница посвящена всем остальным провайдерам.

## Часть 1: Создайте канал в Twenty

1. Перейдите в **Настройки → Коммуникация**.
2. Нажмите **Добавить email-канал**.

<img src="/images/user-guide/emails/inbound-channels/03-twenty-add-email-channel.png" style={{ width: '100%' }} />

3. В поле **Исходный адрес электронной почты** введите общий адрес, на который вы хотите получать почту, например `contact@yourcompany.com`.
4. В поле **Отображаемое имя** введите имя, которое видят получатели.
5. Нажмите **Сохранить**.

<img src="/images/user-guide/emails/inbound-channels/04-twenty-new-channel-form.png" style={{ width: '100%' }} />

6. Теперь Twenty отображает **Адрес для пересылки**. Он заканчивается на `@inbound.twenty.com`. Нажмите **Копировать**.

<img src="/images/user-guide/emails/inbound-channels/05-twenty-forwarding-address.png" style={{ width: '100%' }} />

<Note>
  У каждого канала есть собственный адрес для пересылки. Никогда не указывайте для двух почтовых ящиков
  один и тот же адрес, иначе их почта будет попадать в одно место.
</Note>

## Часть 2: Выберите подходящий тип пересылки

Большинство провайдеров предлагают несколько способов пересылки почты, и здесь подходит только один из них.

Twenty считывает заголовок `From` каждого полученного сообщения, чтобы определить его отправителя. Так сообщение связывается с нужным человеком и компанией.

* **Автоматическая пересылка на почтовом сервере** сохраняет исходного отправителя. Ваш клиент остаётся отправителем, сообщение связывается с его записью, а ответы отправляются ему. Некоторые провайдеры называют это **Перенаправлением**, другие — **Пересылкой**. Используйте этот вариант.
* **Пересылка в виде вложения** или любое правило, создающее новое сообщение, заменяет отправителя вашим собственным адресом. Тогда каждый разговор выглядит так, будто он пришёл от вас, и ни одно сообщение не сопоставляется с контактом.

Используйте настройку автоматической пересылки в своей учётной записи почты или на почтовом сервере. Не используйте правило, которое повторно отправляет сообщение как новое email-сообщение.

<Warning>
  Также избегайте правил, которые удаляют вложения или преобразуют сообщения в обычный текст.
  Twenty хранит каждое сообщение в точности в том виде, в котором оно поступило.
</Warning>

Если доступна такая возможность, выберите вариант, который **сохраняет копию** в исходном почтовом ящике, чтобы ваша команда могла и дальше пользоваться входящими как раньше.

## Часть 4: Проверьте

Отправьте email-сообщение с внешнего адреса (подойдёт личный Gmail) на `contact@yourcompany.com`. Оно должно появиться в Twenty в течение одной-двух минут.

## Устранение неполадок

<Accordion title="Ничего не приходит">
  Сравните адрес для пересылки посимвольно с адресом в Twenty.
  Один неверный символ означает, что почта никуда не попадёт и будет молча отброшена.
</Accordion>

<Accordion title="Почта приходит, но в каждом сообщении в качестве отправителя указан ваш собственный адрес">
  Правило заново создаёт сообщение, а не пересылает его, поэтому ваш
  адрес оказывается в заголовке `From`. Переключитесь на обычную
  пересылку или перенаправление у вашего провайдера и отключите любой вариант,
  пересылающий сообщение в виде вложения.
</Accordion>

<Accordion title="Отправитель получает уведомление о недоставке: пересылка не разрешена">
  Ваш провайдер блокирует автоматическую пересылку на внешние домены. Найдите настройку
  безопасности или защиты от спама, разрешающую внешнюю пересылку, и включите её
  только для этого почтового ящика.
</Accordion>

<Accordion title="Почта больше не появляется в исходных входящих">
  Правило перемещает сообщения, а не копирует их. Измените его, чтобы сохранялась копия,
  или добавьте второе правило, которое доставляет сообщения во входящие.
</Accordion>

<Accordion title="Канал получает почту, но не может отправлять сообщения">
  Получение и отправка выполняются отдельно. Для отправки требуется, чтобы ваш домен был
  подтверждён в разделе канала **Домен отправки**, что означает добавление
  записей **Аутентификация домена**, перечисленных Twenty. См. Почтовые
  каналы, чтобы узнать, какие
  записи нужны для каждого случая использования.
</Accordion>
