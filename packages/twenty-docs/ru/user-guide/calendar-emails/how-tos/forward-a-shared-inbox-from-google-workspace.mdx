## Обзор

Почтовый канал предоставляет вашему рабочему пространству общий адрес, например `sales@yourcompany.com`. Письма, отправленные на этот адрес, должны каким-то образом попадать в Twenty.

В Google Workspace этот адрес почти всегда является **Группой Google**. Подключите его, добавив частный адрес пересылки Twenty в качестве участника группы. Каждое сообщение, полученное группой, затем копируется в Twenty, а ваша команда продолжает получать его, как и раньше.

<Note>
  Это относится только к новым письмам. Twenty не увидит сообщения, полученные группой
  до выполнения этой настройки.
</Note>

## Перед началом

Вам понадобятся две вещи:

* **Доступ**: вы должны быть владельцем группы, суперадминистратором или администратором групп в Google Workspace.
* **Группа, принимающая внешние адреса**: адрес пересылки Twenty является внешним, поэтому группа должна принимать внешних участников и почту извне вашей компании. В части 2 рассматриваются оба пункта.

## Часть 1. Создайте канал в Twenty

1. Перейдите в **Настройки → Коммуникация**.
2. Нажмите **Добавить почтовый канал**.

<img src="/images/user-guide/emails/inbound-channels/03-twenty-add-email-channel.png" style={{ width: '100%' }} />

3. В поле **Исходный адрес электронной почты** введите адрес группы, например `sales@yourcompany.com`.
4. В поле **Отображаемое имя** введите имя, которое увидят получатели.
5. Нажмите **Сохранить**.

<img src="/images/user-guide/emails/inbound-channels/04-twenty-new-channel-form.png" style={{ width: '100%' }} />

6. Теперь Twenty отображает **адрес пересылки**. Он выглядит так: `ch_2cd282d193b5@inbound.twenty.com`. Нажмите **Копировать**.

<img src="/images/user-guide/emails/inbound-channels/05-twenty-forwarding-address.png" style={{ width: '100%' }} />

<Note>
  Каждый канал получает собственный адрес пересылки. Никогда не указывайте для двух групп
  один и тот же адрес, иначе их почта будет попадать в одно место.
</Note>

## Часть 2. Проверьте настройки группы

Работоспособность этой настройки определяют два параметра. Правильно настройте их, прежде чем продолжить.

1. Откройте [Google Группы](https://groups.google.com) и выберите свою группу.
2. Нажмите **Настройки группы** на левой боковой панели.
3. Найдите **Внешние участники** и включите **Разрешить внешних участников**.

<img src="/images/user-guide/emails/inbound-channels/google-03-allow-external-members.png" style={{ width: '100%' }} />

По умолчанию Google отключает эту настройку для всей организации, поэтому при первой попытке она, скорее всего, будет заблокирована. Если вы видите уведомление выше, разблокировать её может только администратор Workspace, разрешив владельцам групп добавлять внешних участников во всей организации. Обратитесь к нему, затем вернитесь сюда.

4. Прокрутите до **Кто может публиковать** и перетащите ползунок до упора вправо, на значок глобуса. Это **Все пользователи в интернете**.

<img src="/images/user-guide/emails/inbound-channels/google-04-who-can-post.png" style={{ width: '100%' }} />

Без этого почта извне вашей компании никогда не попадёт в группу, а значит, и в Twenty. По умолчанию это также заблокировано для всей организации, и изменить настройку снова может только администратор.

5. Нажмите **Сохранить изменения**.

<Warning>
  Если группа имеет метку Google **Безопасность**, остановитесь здесь. Google не
  разрешает использовать аккаунты не Google в группе безопасности, а эту метку невозможно удалить после
  применения. Создайте новую группу без неё.
</Warning>

## Часть 3. Добавьте Twenty в группу

1. Нажмите **Участники** на левой боковой панели.
2. Нажмите **Добавить участников**.

<img src="/images/user-guide/emails/inbound-channels/google-02-members-add-button.png" style={{ width: '100%' }} />

3. Вставьте адрес пересылки, скопированный из Twenty, в поле **Участники группы**.
4. Оставьте для **Подписка** значение **Каждое письмо**. Это позволит Google пересылать каждое сообщение.
5. Оставьте флажок **Добавлять участников напрямую** установленным, чтобы Google добавил адрес, а не отправил приглашение, которое нельзя принять.
6. Нажмите **Добавить участников**.

<img src="/images/user-guide/emails/inbound-channels/google-05-add-forwarding-address.png" style={{ width: '100%' }} />

Настройка завершена. Теперь Twenty является участником группы, как и любой другой.

## Если у вас ещё нет группы

1. В [Google Группах](https://groups.google.com) нажмите **Создать группу**.
2. Заполните поля **Название группы** и префикс **Адрес электронной почты группы**.

<img src="/images/user-guide/emails/inbound-channels/google-01-create-group.png" style={{ width: '100%' }} />

3. Дважды нажмите **Далее**, затем — **Создать группу**.
4. Теперь выполните части 2 и 3.

## Часть 4. Проверьте настройку

Отправьте письмо с внешнего адреса (подойдёт личный Gmail) на `sales@yourcompany.com`. Оно должно появиться в Twenty через одну-две минуты.

## Устранение неполадок

<Accordion title="Произошла ошибка: 1 пользователь находится за пределами вашей организации">
  Группа не принимает внешних участников. Вернитесь к шагу 3 части 2. Если
  настройка заблокирована, разблокировать её может только администратор Workspace.

  <img src="/images/user-guide/emails/inbound-channels/google-06-external-member-error.png" style={{ width: '100%' }} />
</Accordion>

<Accordion title="Группа получает почту, но Twenty — нет">
  Откройте участника в группе и проверьте, что для его подписки выбрано **Каждое письмо**, а не
  **Без писем**, **Дайджест** или **Сокращённо**.
</Accordion>

<Accordion title="Письма коллег приходят, а письма клиентов — нет">
  Для параметра **Кто может публиковать** не выбрано значение **Все пользователи в интернете**. См. шаг 4 части 2.
</Accordion>

<Accordion title="Канал получает почту, но не может отправлять">
  Получение и отправка — это отдельные процессы. Отправка требует, чтобы ваш домен был
  верифицирован под секцией **Отправка домена** канала, что означает добавление
  **аутентификации домена** записей Двадцать списков там. См. Email
  Channels, для которых
  записывает каждый потребности.
</Accordion>

Используете другого провайдера? См. [Microsoft 365](/ru/user-guide/calendar-emails/how-tos/forward-a-shared-inbox-from-microsoft-365) или [любого другого почтового провайдера](/ru/user-guide/calendar-emails/how-tos/forward-a-shared-inbox-from-any-mail-provider).
