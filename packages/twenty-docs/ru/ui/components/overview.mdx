## Обзор

Компоненты объединяют [примитивы](/ru/ui/primitives/overview) в повторяющиеся предустановки дизайна и повторно используемые строительные блоки приложений. Как и примитивы, они получают данные и функции обратного вызова из вашего приложения.

Используйте соответствующий импорт семейства, указанный ниже. Агрегированная точка входа `twenty-ui/components` также остаётся доступной. У редактора кода есть собственная точка входа, `twenty-ui/components/code-editor`, поскольку для него требуется Monaco. Сведения об установке и настройке темы см. в разделе [Начало работы](/ru/ui/getting-started).
