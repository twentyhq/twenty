## Обзор

`CurrencyPicker` объединяет компактный триггер валюты, доступные для поиска параметры и [Dropdown](/ru/ui/components/navigation/dropdown). Предоставьте каталог валют и используйте один компонент для обычного выбора. Скомпонуйте `Root`, `Trigger` и `Options` с Dropdown, когда во всплывающем окне требуется другое содержимое или страницы.

## Использование

Каждая валюта имеет уникальный `code`, `name` и необязательные свойства `symbol` и `disabled`. Код является стабильным идентификатором выбора. Средство выбора не поставляется с каталогом валют и не выбирает значение приложения по умолчанию.

```tsx
import { CurrencyPicker } from 'twenty-ui/components/input';

const CURRENCIES = [
  { code: 'EUR', name: 'Euro', symbol: '€' },
  { code: 'USD', name: 'US Dollar', symbol: '$' },
];

export const InvoiceCurrency = () => (
  <CurrencyPicker
    currencies={CURRENCIES}
    defaultValue="USD"
    aria-label="Invoice currency"
    optionsProps={{
      searchLabel: 'Search currencies',
      emptyLabel: 'No currencies found',
    }}
    contentProps={{ width: 280 }}
  />
);
```

Используйте `defaultValue` для неконтролируемого выбора. Для контролируемого выбора передайте `value` и обновляйте его из `onValueChange`. Колбэк получает следующий код или `null`, а также сведения о выборе Dropdown, содержащие `event`, `reason`, `trigger`, `cancel` и `isCanceled`. Вызовите `details.cancel()`, чтобы сохранить текущий выбор и оставить всплывающее окно открытым. Выбор текущего кода не вызывает ещё одного изменения.

`null` очищает выбор. Пустая строка остаётся допустимым кодом и не очищает его. Неизвестное значение остаётся неизменным и отображается в триггере как необработанный код; оно не добавляет параметр в каталог. Последующее контролируемое обновление или изменение каталога обновляет триггер и выбранную строку.

```tsx
import { useState } from 'react';
import { CurrencyPicker } from 'twenty-ui/components/input';
import { Button } from 'twenty-ui/primitives/input';

const CURRENCIES = [
  { code: 'EUR', name: 'Euro' },
  { code: 'USD', name: 'US Dollar' },
];

export const ClearableCurrency = () => {
  const [value, setValue] = useState<string | null>('USD');

  return (
    <>
      <CurrencyPicker
        currencies={CURRENCIES}
        value={value}
        onValueChange={setValue}
        aria-label="Invoice currency"
        triggerProps={{ placeholder: 'Choose a currency' }}
      />
      <Button onClick={() => setValue(null)}>Clear currency</Button>
    </>
  );
};
```

## Расширенная композиция

`CurrencyPicker.Root` подготавливает каталог и управляет выбором для обеих частей. Он не добавляет элемент DOM и должен находиться внутри `Dropdown.Root`. Размещайте `Trigger` и `Options` под одним корнем средства выбора, в том числе когда параметры находятся на другой странице раскрывающегося списка. Дочерние элементы корня в виде функции рендеринга предоставляют `value`, `selectedCurrency` и `disabled` для меток и вспомогательного содержимого, управляемых вызывающей стороной.

```tsx
import { CurrencyPicker } from 'twenty-ui/components/input';
import { Dropdown } from 'twenty-ui/components/navigation';

const CURRENCIES = [
  { code: 'EUR', name: 'Euro' },
  { code: 'USD', name: 'US Dollar' },
];

export const ComposedCurrency = () => (
  <Dropdown.Root type="picker">
    <CurrencyPicker.Root
      currencies={CURRENCIES}
      defaultValue="USD"
      closeOnSelect={false}
    >
      {({ value }) => (
        <>
          <CurrencyPicker.Trigger
            aria-label={`Invoice currency: ${value ?? 'none'}`}
            placeholder="Choose a currency"
          />
          <Dropdown.Content aria-label="Invoice currency" width={280}>
            <Dropdown.Title>Invoice currency</Dropdown.Title>
            <CurrencyPicker.Options
              searchLabel="Search currencies"
              emptyLabel="No currencies found"
            />
          </Dropdown.Content>
        </>
      )}
    </CurrencyPicker.Root>
  </Dropdown.Root>
);
```

Dropdown управляет открытием, размещением всплывающего окна, страницами, навигацией поиска и фокусом. Средство выбора использует группу выбора Dropdown для сохранения выбранных значений и политики закрытия. `Root.closeOnSelect` по умолчанию имеет значение `true`; используйте `false`, чтобы оставить всплывающее окно открытым после выбора валюты. Клавиши со стрелками, Home и End перемещают фокус без изменения значения. Enter, Space или активация указателем выбирают включённый параметр. Отключённые валюты остаются видимыми, и их нельзя выбрать.

## Поиск и сортировка

Поиск по параметрам включён по умолчанию. Поиск игнорирует окружающие пробелы и без учёта регистра сопоставляет коды, названия, символы и метку по умолчанию `Name (CODE)`, используя одинаковые правила для всех локалей браузера. `getSearchText` в корне заменяет текст, доступный для поиска, для каждой валюты. Настройка отображения и текст поиска независимы друг от друга.

Результаты сохраняют порядок каталога. Установите `selectedFirst` для сокращённого варианта или корня, чтобы переместить выбранную валюту перед остальными совпадениями. Запрос, исключающий её, также удаляет её строку. Неизвестное значение не создаёт выбранный результат. Пустые результаты отображают `emptyLabel` в области состояния.

Установите `Options.searchable={false}`, чтобы не отображать поле поиска. `Options.searchProps` нацелен на нативное поле ввода поиска, включая его `ref`, `render`, доступные атрибуты и контролируемое `value` или неконтролируемое `defaultValue`. `searchProps.onValueChange` получает запрос. При использовании сокращённого варианта передавайте эти параметры через `optionsProps`.

Поле поиска получает фокус при открытии средства выбора с возможностью поиска. Enter при непустом запросе активирует первый включённый результат. При пустом запросе перед выбором переместите фокус на параметр. Активация поиска во время составления IME и новый поиск при повторном открытии по-прежнему подчиняются общим контрактам поиска Dropdown и сеанса страницы.

## Представление и нативные цели

По умолчанию триггер показывает выбранный код. `renderValue` получает `{ value, selectedCurrency, disabled }` для настройки этого отображения без повторного поиска валюты. `Trigger.children` переопределяет отображение значения, а `Trigger.placeholder` задаёт пустое отображение. `getOptionLabel` настраивает содержимое каждого параметра с меткой по умолчанию `Name (CODE)`. Названия валют, символы, метки и содержимое параметров определяются вызывающей стороной.

Нативные атрибуты кнопки сокращённого варианта, обработчики событий, `className`, `style`, `ref` и `render` нацелены на его триггер. `triggerProps` настраивает эту же кнопку. Используйте `optionsProps` для обёртки div параметров и его вложенный `searchProps` для поля ввода. `contentProps` настраивает всплывающее окно Dropdown. `open`, `defaultOpen` и `onOpenChange` координируют открытое состояние сокращённого варианта.

При составном использовании нативные атрибуты, `ref` и `render` в `Trigger` нацелены на его кнопку, а в `Options` — на его обёртку div. `Options.listLabel` задаёт имя только внутреннему списку выбора. Передавайте предоставленные props и ref из пользовательского компонента `render`. Стилизация обёртки не изменяет нативную цель поля ввода.

Установите `disabled` для сокращённого варианта или корня, чтобы отключить открытие, поиск и выбор. Свойство `disabled` части может дополнительно отключить эту часть. Выбор является значением средства выбора; нативная отправка формы, сброс, обязательная проверка и интеграция с Field остаются вне этого API.

## Метки и интеграция с приложением

`searchLabel` по умолчанию имеет значение `Search` и задаёт заполнитель поиска и доступное имя. `emptyLabel` по умолчанию имеет значение `No results` и принимает содержимое. Предоставьте из приложения локализованные исходные метки, доступное имя триггера и любой заполнитель. Содержимое Dropdown получает имя триггера, если только его не задаёт `Dropdown.Title` или явная метка содержимого. Список выбора по умолчанию получает зарегистрированный заголовок Dropdown или имя триггера. Установите `Options.listLabel`, чтобы дать только этому списку собственное доступное имя, или передайте `optionsProps.listLabel` при использовании сокращённого варианта. Нативные `aria-label` и `aria-labelledby` в `Options` задают метку только для его обёртки. Триггер сохраняет собственное доступное имя.

Приложение управляет редактированием суммы, хранением валюты, форматированием, загрузкой каталога и его начальным значением. Адаптер должен сопоставлять сохранённые коды валют и поведение очистки с `value` и `onValueChange`, сохраняя правила форматирования и резервных значений приложения. Храните переведённые названия валют и метки в приложении.

## Рендерер Front-компонента

Тестовые сценарии песочницы React и Preact охватывают сокращённый и составной поиск и выбор, отключённые элементы управления и параметры, ссылки на триггеры, очистку с null, внешние контролируемые обновления, повторное открытие и восстановление фокуса по Escape. Они также проверяют, что очистка предыдущего запроса и ввод `$` сохраняют запрос по символу.

Видимость всплывающего окна, геометрия, прокрутка и закрытие зависят от поддержки Dropdown и портала общим средством рендеринга. Средство выбора использует эту общую реализацию.
