## Обзор

`PhoneCountryPicker` объединяет триггер с флагом страны, всплывающее окно, поиск и варианты кода вызова. Используйте полный компонент для обычного выбора или скомпонуйте `Root`, `Trigger` и `Options` с [Dropdown](/ru/ui/components/navigation/dropdown), если вам нужно пользовательское всплывающее окно. Обе формы используют одни и те же подготовленные страны и выбор.

## Использование

Предоставьте собственные данные о странах и доступное имя триггера. Используйте `value` с `onValueChange` для контролируемого выбора или `defaultValue` для неконтролируемого выбора. `null` означает, что страна не выбрана.

```tsx
import { useState } from 'react';
import {
  PhoneCountryPicker,
  type PhoneCountryOption,
} from 'twenty-ui/components/input';

const COUNTRIES: PhoneCountryOption[] = [
  { value: 'FR', label: 'France', callingCode: '33', flag: '🇫🇷' },
  { value: 'GB', label: 'United Kingdom', callingCode: '44', flag: '🇬🇧' },
  { value: 'US', label: 'United States', callingCode: '1', flag: '🇺🇸' },
];

export const PhoneCountryExample = () => {
  const [value, setValue] = useState<string | null>('FR');

  return (
    <PhoneCountryPicker
      aria-label="Phone country"
      countries={COUNTRIES}
      value={value}
      onValueChange={setValue}
      contentProps={{ width: 280 }}
      optionsProps={{
        searchLabel: 'Search countries',
        listLabel: 'Phone countries',
        emptyLabel: 'No countries found',
      }}
    />
  );
};
```

Каждый `PhoneCountryOption` имеет уникальное стабильное значение `value`, локализованную метку страны `label`, состоящий только из цифр `callingCode` без начального знака «плюс» и декоративный узел `flag`. Он также может быть `disabled`. Значения являются идентификаторами, принадлежащими вызывающей стороне, например кодами стран ISO, и возвращаются без изменений. Метки, флаги и коды вызова являются данными представления и не становятся выбранным идентификатором.

Селектор добавляет знак «плюс» и изолирует коды вызова слева направо в строках вариантов и всплывающих подсказках при переполнении, в том числе в интерфейсах справа налево. Указывайте страны в том порядке, в котором они должны отображаться. Выбранная страна отображается первой, пока она соответствует запросу; остальные совпадения сохраняют заданный порядок.

## Составная композиция

Это критическое изменение API для существующих составных вызывающих сторон. Добавьте `PhoneCountryPicker.Root` вокруг `Dropdown.Root`, переместите `countries`, `value` и `onValueChange` из `Options` в `Root` и удалите `Trigger.country`. Теперь обе части требуют `Root` и получают из него выбранную страну.

`Root` управляет странами и контролируемым или неконтролируемым выбором. Поместите общий `Dropdown.Root` внутрь него и скомпонуйте триггер, содержимое и варианты. `Trigger` получает выбранный флаг и доступное описание из `Root`; `Options` считывает те же данные и выбор. Не передавайте этим частям другую страну или выбранное значение.

```tsx
import {
  PhoneCountryPicker,
  type PhoneCountryOption,
} from 'twenty-ui/components/input';
import { Dropdown } from 'twenty-ui/components/navigation';
import { Button } from 'twenty-ui/primitives/input';

const COUNTRIES: PhoneCountryOption[] = [
  { value: 'FR', label: 'France', callingCode: '33', flag: '🇫🇷' },
  { value: 'GB', label: 'United Kingdom', callingCode: '44', flag: '🇬🇧' },
];

<PhoneCountryPicker.Root countries={COUNTRIES} defaultValue="FR">
  <Dropdown.Root type="picker">
    <PhoneCountryPicker.Trigger
      aria-label="Phone country"
      render={<Button variant="outline" />}
    />
    <Dropdown.Content width={320}>
      <PhoneCountryPicker.Options
        searchLabel="Search countries"
        listLabel="Phone countries"
        emptyLabel="No countries found"
      />
    </Dropdown.Content>
  </Dropdown.Root>
</PhoneCountryPicker.Root>;
```

Используйте один корневой компонент для каждого селектора. Общий Dropdown управляет открытием, размещением всплывающего окна, страницами, фокусом и навигацией поиска. Используйте `dropdownProps` и `contentProps` в полном селекторе или настраивайте части Dropdown напрямую при составном использовании.

## Поиск и выбор

Поиск находит подстроки в заданных метках стран, стабильных идентификаторах и кодах вызова. Метки и идентификаторы используют общую нормализацию `normalizeSearchText`: текст в нижнем регистре, декомпозицию Unicode NFD и обработку акцентов с учетом системы письма. Например, `reunion` соответствует `Réunion`, а `gb` соответствует идентификатору `GB`. Значимые различия в системах письма сохраняются согласно этой функции-помощнику. Пробелы вокруг запроса удаляются; внутренние пробелы сохраняются. При поиске по коду вызова один начальный знак «плюс» необязателен, поэтому `44`, `+44` и `" +44 "` соответствуют заданному коду вызова `44`. Поиск не анализирует полный номер телефона и не определяет по нему страну.

`onValueChange(value, eventDetails)` получает запрошенный идентификатор и общие сведения `Dropdown.SelectionGroup`: `reason`, нативный `event`, `trigger` выбранного варианта, `cancel()` и `isCanceled`. Вызовите `cancel()` перед обновлением контролируемого состояния, чтобы отклонить запрос. Отмененный запрос сохраняет неконтролируемый выбор и оставляет всплывающее окно открытым. Установите `closeOnSelect={false}`, чтобы оно оставалось открытым после принятого выбора. Изменения выбора не изменяют значение какого-либо поля ввода телефона.

Установите `disabled` для полного селектора или `Root`, чтобы отключить его триггер, поиск и выбор. Отключенная страна остается видимой, и ее нельзя выбрать. `Trigger.disabled` и `Options.disabled` могут дополнительно отключать эти отдельные части.

## Нативные цели и метки

Нативные атрибуты полного селектора, обработчики событий, `className`, `style`, `ref`, `render` и необязательный `children` применяются к его триггеру. `children` заменяет флаг или значок мира и шеврон по умолчанию. `contentProps` применяется к `Dropdown.Content`; `optionsProps` применяется к корневому div вариантов и предоставляет `searchLabel`, `listLabel` и `emptyLabel`. При составном использовании нативные свойства, ссылки и композиция рендеринга применяются к соответствующей кнопке `Trigger` или div `Options`. `Root` не рендерит узел DOM.

Предоставьте локализованные метки стран и обязательный `aria-label` триггера. Метка выбранной страны описывает триггер, а ее флаг и шеврон являются декоративными. При пустом выборе отображается значок мира. Всплывающее окно получает имя триггера, если только его не задает `Dropdown.Title` или явная метка содержимого. `searchLabel` по умолчанию имеет значение `Search` и задаёт имя как поля поиска, так и его заполнителя. По умолчанию `listLabel` имеет значение `Countries` и независимо именует список. `emptyLabel` по умолчанию имеет значение `No results`.

## Интеграция поля ввода телефона

Селектор поставляется без каталога стран, пакета ресурсов флагов или среды выполнения поля ввода телефона. Адаптер фронтенда управляет разбором, проверкой, форматированием телефонов, черновиками редактирования и сохранением. Сопоставьте выбранную страну библиотеки телефона с `Root.value` или `value` полного селектора и сопоставьте изменения страны обратно через один обратный вызов. Сохраняйте текст телефона в его текущем владельце при изменении или очистке страны либо при применении внешнего обновления выбранной страны.

Нативная отправка формы, сброс, обязательность, режим только для чтения и интеграция Field для этого пользовательского селектора отложены. Полный селектор передает нативные атрибуты триггера согласно контракту кнопки Dropdown.

## Средство рендеринга компонентов Front

Фикстуры галереи React и Preact включают полный селектор и составную композицию. Размещение портала, геометрия, прокрутка, закрытие и фокус относятся к общему Dropdown и интеграции рендерера. Селектор не вводит отдельную среду выполнения рендерера.
