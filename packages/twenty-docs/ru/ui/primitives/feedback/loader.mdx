## Обзор

`Loader` отображает анимированную точку внутри небольшой капсулы с рамкой. Используйте его, когда выполняется операция и процент выполнения неизвестен. Для числового прогресса используйте [ProgressBar](/ru/ui/primitives/feedback/progress-bar).

## Использование

```tsx
import { Loader } from 'twenty-ui/primitives/feedback';
import { Text } from 'twenty-ui/primitives/typography';

type SaveFeedbackProps = { isSaving: boolean };

export const SaveFeedback = ({ isSaving }: SaveFeedbackProps) => (
  <Text
    render={<div />}
    role="status"
    style={{ display: 'flex', alignItems: 'center', gap: 8 }}
  >
    {isSaving && <Loader color="blue" aria-hidden="true" render={<span />} />}
    {isSaving ? 'Saving changes' : 'Changes saved'}
  </Text>
);
```

Разместите видимый текст состояния рядом с индикатором загрузки в обертке. Индикатор загрузки — это визуальный индикатор фиксированного размера, который не принимает дочерние элементы.

Приложение управляет состоянием загрузки. Не размонтируйте контейнер статуса, чтобы можно было объявлять обновления текста. По умолчанию индикатору загрузки не назначаются ни метка, ни роль живой области. Используйте `aria-hidden="true"`, когда окружающий текст или кнопка уже сообщают о загрузке.

## Нативная композиция и именование

Нативные пропсы, `className`, `style` и `ref` применяются к контейнеру div. `render` принимает элемент или функцию обратного вызова через композицию Base UI. Стили переопределяют цвета по умолчанию. `LoaderProps` экспортируется из семейства feedback.

Для автономного индикатора укажите явную роль состояния и доступное имя. Анимированная точка остаётся декоративной.

```tsx
import { Loader, type LoaderProps } from 'twenty-ui/primitives/feedback';

const loadingProps: LoaderProps = {
  role: 'status',
  'aria-label': 'Loading results',
  color: 'blue',
};

export const LoadingResults = () => (
  <Loader {...loadingProps} render={<span />} />
);
```

Используйте вместо этого `aria-labelledby`, когда видимый текст называет состояние. Оставляйте владельца живой области смонтированным, когда ему нужно объявлять об изменении текста. Приложение определяет, когда отображается обратная связь и что она сообщает.

## Цвет

Передайте цвет из палитры темы, чтобы задать и рамку, и точку. Без цвета загрузчик наследует цвет окружающей кнопки, если он доступен; в противном случае используется третичный цвет текста. Для действия кнопки предпочтительно использовать [состояние загрузки Button](/ru/ui/primitives/input/button#state-ownership), при котором индикатор остаётся внутри элемента управления.
