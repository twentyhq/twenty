## Обзор

`ProgressRing` придает [Progress](/ru/ui/primitives/feedback/progress) круговой вид. Он использует те же контракт пользовательского диапазона, null, форматирования, маркировки, нативного свойства, ref и render, что и корневой компонент. Необязательные дочерние элементы отображают предварительно отформатированное значение рядом с кольцом.

## Использование

Передайте исходное контролируемое значение и доступное имя. Используйте `aria-valuetext`, когда отформатированное значение объясняет прогресс понятнее, чем процент.

```tsx
import { ProgressRing } from 'twenty-ui/primitives/feedback';

export const ImportProgress = () => (
  <ProgressRing
    value={600}
    max={1000}
    aria-label="Importing records"
    aria-valuetext="600 of 1,000 records"
  >
    600 / 1,000
  </ProgressRing>
);
```

Используйте `aria-labelledby`, чтобы связать кольцо с существующей видимой меткой, или скомпонуйте `Progress.Label` как дочерний элемент. Предварительно отформатированные дочерние элементы не задают доступное имя кольца автоматически.

## Контролируемый прогресс и диапазоны

Приложение вычисляет `value` и форматирует отображаемое содержимое. Кольцо не получает данные, не продвигает прогресс и не вычисляет квоты. Значение `min` по умолчанию равно `0`, а `max` — `100`. Конечные значения ограничиваются диапазоном для семантических значений и геометрии дуги. Дуга заполняется в соответствии с нормализованным процентом, в том числе когда минимум не равен нулю.

<StoryEmbed storyId="ui-feedback-progressring-progressring--custom-range" title="Круговой прогресс в пользовательском диапазоне" height={90} />

Передайте `value={null}` для неопределенного прогресса. Кольцо не включает `aria-valuenow` и отображает неопределенную дугу. Неконечные значения также остаются неопределенными; они не становятся нулем или завершением. Отображаемое содержимое остается под управлением приложения.

Используйте `locale`, `format` и `getAriaValueText`, как описано в [Progress](/ru/ui/primitives/feedback/progress). Скомпонуйте `Progress.Value`, чтобы отобразить отформатированное значение корневого компонента.

Используйте [ProgressBar](/ru/ui/primitives/feedback/progress-bar) для горизонтального прогресса или [MetricRow](/ru/ui/components/data-display/metric-row) для метки и выровненного значения.

## Внешний вид и композиция

`size="md"` отображает кольцо размером 16px; `size="sm"` отображает кольцо размером 14px. Оба используют обводку 2px и заполняются по часовой стрелке, начиная сверху. `barColor` принимает цвета CSS, включая переменные темы. SVG является декоративным и скрыт от API доступности.

Изменения значения анимируются в течение 300ms. Настройки уменьшения движения отключают переход и вращение при неопределенном состоянии. Нативные атрибуты, `className`, `style` и `ref` применяются к внешнему элементу индикатора выполнения. `className` и `style` могут получать состояние прогресса. `render` может заменить корневой компонент, сохраняя его семантику.
