## Обзор

После установки вашего приложения в других рабочих областях вам нужно знать, когда оно перестаёт работать. Twenty записывает происходящее с вашим приложением на платформе и показывает это в двух местах:

* **Страница мониторинга** регистрации вашего приложения для вас как владельца приложения с агрегированными данными по всем установкам.
* **Журналы рабочей области** для администраторов каждой рабочей области, установившей ваше приложение, ограниченные их собственной рабочей областью.

```text
   your app runs in workspace A, B, C …
              │
              ▼
   platform events (function runs, installs, rate limits, route failures)
              │
      ┌───────┴────────────────────────┐
      ▼                                ▼
   Monitoring page (app owner)      Logs (each workspace admin)
   all installs, aggregated         one workspace, row by row
```

## Откройте страницу мониторинга

Перейдите в **Settings → Developers → Apps**, откройте своё приложение, затем нажмите **View monitoring** на вкладке **General**. Вам нужно разрешение **API keys & webhooks** в рабочей области, которой принадлежит регистрация приложения.

Выберите период в заголовке: последние 2 часа, 24 часа, 7 дней, 30 дней или 90 дней. Данные хранятся **90 дней**. Без права **Audit logs** отображаются только последние 2 часа.

## Что показывает страница

| Секция                                      | Что это показывает                                                                                                                      |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **Работоспособность**                       | Основные показатели за период и диаграмма ошибок во времени.                                                                            |
| **Лимиты скорости**                         | Отклонённые запросы API, отправленные вашим приложением, и задания триггеров, пропущенные из-за достижения лимита постановки в очередь. |
| **Кредитов использовано**                   | Потребление кредитов вашим приложением во времени. Отображается только на серверах с включённым биллингом.                              |
| **Наиболее частые ошибки и предупреждения** | Наиболее частые проблемы, сгруппированные по коду ошибки и функции, с количеством затронутых установок.                                 |
| **Установки, обновления и удаления**        | Запуски жизненного цикла во времени и количество неудачных запусков.                                                                    |
| **Версии**                                  | Запуски и сбои для каждой версии приложения, чтобы выявить неудачный выпуск.                                                            |
| **Функции**                                 | Запуски, сбои и длительность на 95-м процентиле для каждой логической функции.                                                          |

Подсчёты точны: учитывается каждый отклонённый запрос и каждое пропущенное задание, даже если в журналах ниже сохраняется только одна строка в минуту.

## Что записывается

Каждое из событий ниже учитывается на странице мониторинга. Каждое из них также записывает журналы приложения в рабочую область, где оно произошло, с указанием **source**, откуда оно поступило:

| Источник         | Когда записывается                                                                                                                                                                                                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LOGIC_FUNCTION` | Логическая функция записывает строку журнала или завершается сбоем при любом триггере. Запуски, которые ничего не записывают в журнал и завершаются успешно, учитываются на странице мониторинга, но не оставляют строк в журнале.                                                                                          |
| `INSTALL`        | Ваше приложение установлено с результатом хуков установки.                                                                                                                                                                                                                                                                  |
| `UPGRADE`        | Ваше приложение обновлено до новой версии.                                                                                                                                                                                                                                                                                  |
| `UNINSTALL`      | Ваше приложение удалено.                                                                                                                                                                                                                                                                                                    |
| `API_RATE_LIMIT` | Запрос вашего приложения к API отклонён из-за ограничения скорости.                                                                                                                                                                                                                                                         |
| `JOB_RATE_LIMIT` | Задания триггеров для ваших логических функций пропускаются из-за достижения лимита постановки заданий в очередь.                                                                                                                                                                                                           |
| `SERVER_ROUTE`   | Запрос к одному из ваших [HTTP-маршрутов](/ru/developers/extend/apps/tutorials/document-generator/http-routes) отклонён или завершается сбоем вне вашей функции, например из-за неверного метода, неудачной аутентификации или ошибки платформы. Ошибки, вызванные вашей функцией, записываются в журнал как `LOGIC_FUNCTION`. |

Сбои из-за лимита скорости и маршрутов сервера могут повторяться много раз в секунду, поэтому для каждой установки, функции и кода ошибки в журналах сохраняется **одна строка в минуту**. На странице мониторинга по-прежнему учитывается каждое вхождение.

## Журналы рабочей области

Администраторы рабочей области, установившей ваше приложение, видят те же события только для своей рабочей области в разделе **Settings → General → Logs**. Они могут фильтровать по источнику, например чтобы вывести только сбои `INSTALL` или лимиты скорости. Направляйте пользователей туда, когда они сообщают о проблеме: код ошибки и сообщение подскажут, где искать.

Для собственного сервера разработки команда `twenty app logs` передаёт журналы функций в терминал в реальном времени. См. [CLI](/ru/developers/extend/apps/operations/cli#watching-function-logs).

## Как интерпретировать сигналы

* **Ошибки резко возрастают сразу после выпуска**: сравните версии в таблице **Versions**, затем исправьте проблему и опубликуйте более новую версию. См. [Публикация](/ru/developers/extend/apps/operations/publishing).
* **К запросам API применяется ограничение скорости**: ваше приложение слишком часто вызывает API. Выполняйте чтение и запись пакетно и не вызывайте API в тесных циклах.
* **К заданиям применяется ограничение скорости**: триггеры событий базы данных или cron срабатывают быстрее, чем задания могут быть поставлены в очередь. Сузьте триггер, например с помощью `updatedFields` в триггере `databaseEvent`, или выполняйте работу за меньшее количество более крупных запусков. См. [Логические функции](/ru/developers/extend/apps/logic/logic-functions).
* **Сбои установки или обновления**: проверьте свои [хуки установки](/ru/developers/extend/apps/config/install-hooks). Сообщение об ошибке записывается вместе со сбоем.
* **Медленные функции**: высокая длительность на 95-м процентиле указывает на функцию, которую стоит профилировать или разделить.
