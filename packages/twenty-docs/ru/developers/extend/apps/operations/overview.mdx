**Операционный уровень** — это все, что вы делаете *над* своим приложением, а не *с ним*: выполнение команд CLI, запуск интеграционных тестов на реальном сервере Twenty, настройка CI, перевод его строк и поставка релизов — либо в виде tar-архива, разворачиваемого на одном сервере, либо как пакета npm, размещенного в маркетплейсе.

| Шаг                         | Команда                        |
| --------------------------- | ------------------------------ |
| Разработка                  | `twenty app dev`               |
| Тест                        | `yarn test`                    |
| Сборка                      | `twenty app build`             |
| Публикация на одном сервере | `twenty app publish --private` |
| Публикация в npm            | `twenty app publish`           |
