## Why build on Twenty

Most CRMs give developers an API and a few places to plug in. Twenty gives you the platform itself. Declare objects, server-side functions, React components and AI agents in plain TypeScript with the `twenty-sdk`, see each change sync to a local server as you save, and ship with the CLI.

- **Manage your workspace with code.** Objects, fields, views and page layouts live as TypeScript files in your repository, versioned and reviewed like any other change.
- **The same SDK as Twenty's own apps.** Slack, Linear and Granola are apps built with the `twenty-sdk`, so you build with exactly what Twenty's team uses.
- **Plug into the core, not a sidebar.** Your objects get the same tables and permissions as People and Companies. Your apps can bring conversations into Twenty's messages, write to record timelines, and expose functions to workflows and AI agents.
- **No ceiling.** The core is open source and self-hostable. When an extension point is missing, change Twenty itself or contribute it back.
- **Safe to experiment.** Apps run sandboxed and only touch the data their role allows, whether your team or an AI agent wrote the code.
