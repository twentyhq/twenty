Install `twenty` globally. Keep `twenty-sdk` as a dependency of each app for its definitions and runtime helpers.

```bash
npm install -g twenty
twenty --help
twenty auth login --url https://your-workspace.twenty.com --name dev
```

## App commands

| Command                           | Purpose                                                                        |
| --------------------------------- | ------------------------------------------------------------------------------ |
| `twenty app init my-app`          | Create source files, without installing dependencies or connecting to a server |
| `twenty app add`                  | Generate an object, field, logic function, or front component                  |
| `twenty app build`                | Build and report a complete app snapshot                                       |
| `twenty app typecheck`            | Check source with the app's installed TypeScript compiler                      |
| `twenty app generate-client`      | Regenerate the typed API client from the workspace schema                      |
| `twenty app plan`                 | Preview changes to an installed app                                            |
| `twenty app apply`                | Build, preview, upload, and sync once                                          |
| `twenty app dev`                  | Watch source and sync changes                                                  |
| `twenty app pull`                 | Write installed definitions back to source                                     |
| `twenty app translations extract` | Extract strings into translation catalogs                                      |
| `twenty app publish`              | Build and publish to npm                                                       |
| `twenty app publish --private`    | Build and publish to a Twenty server registry                                  |
| `twenty app install`              | Install the registered app package                                             |
| `twenty app uninstall`            | Uninstall the app                                                              |
| `twenty app exec`                 | Execute a deployed logic function                                              |
| `twenty app logs`                 | Watch new function logs                                                        |

Use `--remote <name>` to choose a configured remote. Use `--path <directory>` to select an app directory. Run a command with `--help` for its flags.

First-time development sync requires `twenty app apply --create` or `twenty app dev --create`. Use `--no-delete` to preserve remote entities missing from source. `--yes` permits object and field deletions without prompting.

## Scripts and tests

Set `TWENTY_API_URL` and `TWENTY_API_KEY` for non-interactive workspace access. Finite commands support `--json`, with `{ ok: true, data }` or `{ ok: false, error }`. Watch commands use `--format ndjson`.

```bash
twenty app build --json
twenty app apply --create --json
twenty app publish --private --json
```

Build output belongs to the CLI. Do not read `.twenty/output/manifest.json` or import internal build code; read `data.manifest` from `twenty app build --json`.

## Functions

```bash
twenty app exec --name create-new-post-card --payload '{"name":"Hello"}'
twenty app exec --universal-identifier <uuid>
twenty app exec --pre-install
twenty app exec --post-install
twenty app exec --uninstall-hook
twenty app logs --name create-new-post-card
```

Function execution requires browser login with `twenty auth login`. API keys cannot execute functions. Calling a hook through `app exec` does not install or uninstall the app.

## Remotes

```bash
twenty auth login --url http://localhost:2020 --name local
twenty remote list
twenty remote use local
twenty auth status
twenty remote remove local
```

For API-key login, use `twenty auth login --with-token --url <url> --name <name>` and provide the key on standard input. Credentials use the standalone CLI's configuration; the SDK's `config.test.json` is no longer used.

## Migrating from the SDK CLI

The SDK's `twenty` binary, `twenty-sdk/cli`, `twenty-sdk/build`, and `create-twenty-app` are deprecated; use `twenty app init`, then `yarn install` and `twenty auth login`.

Replace colon commands with the commands above. The standalone CLI does not provide `docker:*` or `dev:catalog-sync`; manage servers through Docker or the repository dev environment. Run `twenty doctor` to diagnose an older SDK binary shadowing the global CLI.
