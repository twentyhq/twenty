## Widgets disponibles

Twenty ofrece varios tipos de widgets para visualizar tus datos de CRM.

### <span style={{ display: 'inline-flex', alignItems: 'center', gap: '8px' }}><ChartIcon icon="chart-bar-popular" />Gráficos de barras</span>

Muestra los datos como barras horizontales o verticales.

<Frame>
<img src="/images/user-guide/dashboard/dashboard-widget-bar-chart.png" alt="Gráfico de barras" />
</Frame>

**Ideal para:**

* Comparar valores entre categorías
* Mostrar clasificaciones
* Hacer seguimiento de métricas por período de tiempo

**Ejemplos de uso:**

* Oportunidades por etapa
* Ingresos por representante de ventas
* Contactos agregados por mes

<Note>
**Límites de visualización**: Los gráficos de barras pueden mostrar un máximo de 100 barras y 50 grupos por barra cuando se usa Agrupar por. Si ves la advertencia "Datos no mostrados: máximo de X barras por gráfico", agrega filtros para acotar tus datos o cambia la agrupación (p. ej., agrupar por semana en lugar de por días).
</Note>

### <span style={{ display: 'inline-flex', alignItems: 'center', gap: '8px' }}><ChartIcon icon="sum" />Gráficos agregados</span>

Muestra valores clave individuales de forma destacada.

<Frame>
<img src="/images/user-guide/dashboard/dashboard-widget-aggregate-chart.png" alt="Gráfico agregado" />
</Frame>

**Ideal para:**

* Resaltar los KPI
* Mostrar totales o promedios
* Comprobaciones rápidas de estado

**Ejemplos de uso:**

* Valor total del embudo
* Número de oportunidades abiertas
* Tasa de conversión

**Opciones avanzadas:**

* **Proporción**: Para campos de tipo Select, calcula proporciones entre valores. Ve a **Datos en pantalla** → selecciona tu campo → activa la opción **Proporción**.
* **Prefijo y sufijo**: Agrega texto personalizado antes o después del número (p. ej., prefijo "$" o sufijo "%") para mejorar la legibilidad.

### <span style={{ display: 'inline-flex', alignItems: 'center', gap: '8px' }}><ChartIcon icon="frame" />iFrames</span>

Incorpora herramientas y contenido externos directamente en tu panel.

Para los widgets iframe añadidos en el espacio de trabajo, un miembro con permiso para administrar la seguridad puede configurar **Configuración → General → Seguridad → Acceso a medios de sitios web incrustados**. Añade el origen HTTPS exacto del sitio web, como `https://workspace.aircall.io`, y habilita el **Micrófono**, la **Cámara** o ambos. No se aceptan rutas ni comodines. Aprueba únicamente sitios web de confianza.

Las incrustaciones de medios proporcionadas por una aplicación instalada utilizan una aprobación independiente: la aplicación declara el sitio web en [`requestedIframeMediaPermissions`](/es/developers/extend/apps/config/application#embedded-website-media-access), y un miembro que puede administrar aplicaciones lo aprueba durante la instalación. Estas concesiones se aplican a los propios componentes front-end y widgets iframe de la aplicación. Las aprobaciones de seguridad del espacio de trabajo y las concesiones de otras aplicaciones no se aplican a los widgets definidos por la aplicación.

Vuelve a cargar las pestañas abiertas de Twenty después de cambiar estos permisos. La recarga finaliza las llamadas y grabaciones activas. Cada vez que un miembro selecciona **Activar micrófono**, **Activar cámara** o **Activar micrófono y cámara** en una incrustación, aparece una confirmación nativa del navegador que muestra el widget o la aplicación propietaria, el origen del sitio web y el acceso solicitado al micrófono o la cámara. Después de confirmar, aprueba el permiso de medios del navegador cuando se te solicite. Esta confirmación se aplica tanto a los widgets del espacio de trabajo como a las incrustaciones proporcionadas por la aplicación.

El indicador del encabezado muestra **Acceso a medios habilitado** mientras una incrustación tiene acceso, incluso cuando está oculta. Esto no significa que el sitio web esté grabando actualmente: Twenty no puede inspeccionar la actividad del micrófono o la cámara dentro de otro sitio web. Selecciona el indicador y elige **Deshabilitar** para descargar la incrustación y volver a cargarla con el acceso a medios bloqueado. Selecciona **Activar** de nuevo para restaurar el acceso.

#### Edición de registros

Los widgets de tabla y kanban del tablero son de solo lectura de forma predeterminada. Para permitir que los usuarios editen registros desde un widget:

1. Edita el tablero
2. Selecciona el widget
3. Activa **Permitir edición** en la configuración del widget

En las tablas, esto permite editar celdas. En los tableros kanban, permite editar tarjetas, moverlas entre columnas y crear registros. Los permisos de rol siguen aplicándose.
