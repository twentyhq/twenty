La **capa de operaciones** es todo lo que haces *a* tu aplicación en lugar de *con* ella: invocar comandos de CLI, ejecutar pruebas de integración contra un servidor Twenty real, configurar CI, traducir sus cadenas y publicar versiones, ya sea como un tarball implementado en un único servidor o como un paquete de npm listado en el marketplace.

| Paso                    | Comando                        |
| ----------------------- | ------------------------------ |
| Desarrollar             | `twenty app dev`               |
| Prueba                  | `yarn test`                    |
| Compilar                | `twenty app build`             |
| Publicar en un servidor | `twenty app publish --private` |
| Publicación en npm      | `twenty app publish`           |
