## Resumen

Los componentes combinan [primitivas](/es/ui/primitives/overview) en preajustes de diseño recurrentes y bloques de construcción de aplicaciones reutilizables. Al igual que las primitivas, reciben datos y callbacks de tu aplicación.

Use la importación de la familia correspondiente que se muestra a continuación. La entrada agregada `twenty-ui/components` también sigue estando disponible. El editor de código tiene su propio punto de entrada, `twenty-ui/components/code-editor`, porque requiere Monaco. Consulta [Primeros pasos](/es/ui/getting-started) para la instalación y la configuración del tema.

## Editor de Código

Importe desde `twenty-ui/components/code-editor`.

| Component                                            | Propósito                                                              |
| ---------------------------------------------------- | ---------------------------------------------------------------------- |
| [CodeEditor](/es/ui/components/code-editor/code-editor) | Edición de código con Monaco, un encabezado opcional y el tema Twenty. |

El enrutamiento, el formato de registros, los marcadores de posición de productos y el estado de la aplicación pertenecen a la aplicación anfitriona. Los componentes compartidos exponen props de datos, devolución de llamada y renderizado para esas integraciones.
