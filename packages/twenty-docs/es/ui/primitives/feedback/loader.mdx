## Resumen

`Loader` muestra un punto animado dentro de una pequeña cápsula con borde. Úsalo mientras una operación está en curso y se desconoce el porcentaje. Para el progreso numérico, usa [ProgressBar](/es/ui/primitives/feedback/progress-bar).

## "Uso"

```tsx
import { Loader } from 'twenty-ui/primitives/feedback';
import { Text } from 'twenty-ui/primitives/typography';

type SaveFeedbackProps = { isSaving: boolean };

export const SaveFeedback = ({ isSaving }: SaveFeedbackProps) => (
  <Text
    render={<div />}
    role="status"
    style={{ display: 'flex', alignItems: 'center', gap: 8 }}
  >
    {isSaving && <Loader color="blue" aria-hidden="true" render={<span />} />}
    {isSaving ? 'Saving changes' : 'Changes saved'}
  </Text>
);
```

Coloca texto de estado visible junto al cargador en un contenedor. El cargador es un indicador visual de tamaño fijo y no acepta elementos secundarios.

La aplicación controla el estado de carga. Mantén montado el contenedor de estado para que se puedan anunciar las actualizaciones de texto. El cargador no asigna ninguna etiqueta ni función de región dinámica de forma predeterminada. Usa `aria-hidden="true"` cuando el texto circundante o un botón ya proporciona comentarios sobre la carga.

## Composición y etiquetado nativos

Las props nativas, `className`, `style` y `ref` se aplican al div contenedor. `render` acepta un elemento o una devolución de llamada mediante la composición de Base UI. Los estilos anulan los colores predeterminados. `LoaderProps` se exporta desde la familia de comentarios.

Para un indicador independiente, proporciona una función de estado explícita y un nombre accesible. El punto animado sigue siendo decorativo.

```tsx
import { Loader, type LoaderProps } from 'twenty-ui/primitives/feedback';

const loadingProps: LoaderProps = {
  role: 'status',
  'aria-label': 'Loading results',
  color: 'blue',
};

export const LoadingResults = () => (
  <Loader {...loadingProps} render={<span />} />
);
```

Usa `aria-labelledby` en su lugar cuando el texto visible nombra el estado. Mantén montado un propietario de región dinámica cuando necesite anunciar texto cambiante. La aplicación controla cuándo aparecen los comentarios y qué dicen.

## Color

Pasa un color de la paleta del tema para establecer tanto el borde como el punto. Sin un color, el cargador hereda el color de un botón circundante cuando está disponible; de lo contrario, usa el color de texto terciario. Para una acción de botón, prefiere el [estado de carga de Button](/es/ui/primitives/input/button#state-ownership), que mantiene la respuesta dentro del control.
