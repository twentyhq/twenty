Use `Button` for an action. Supply its visible label as children, and give icon-only buttons an `aria-label`.

For recurring design defaults, use [MainButton](/ui/components/input/main-button)
or [LightButton](/ui/components/input/light-button) from `twenty-ui/components`.
Both share Button's native props, refs, state, and rendering behavior.

## State ownership

`Button` triggers an action and does not manage a selected value, so it has no controlled or uncontrolled selection mode. Its native `value` prop supplies form data, not selection state.

Your application owns `loading`, `disabled`, and `soon`, which default to `false`. Clicking a button does not change these props or automatically show loading while an asynchronous handler runs. Pass the current application state explicitly.

```tsx
import { useState } from 'react';
import { Button } from 'twenty-ui/primitives/input';

type SaveRecordProps = { onSave: () => Promise<void> };

export const SaveRecord = ({ onSave }: SaveRecordProps) => {
  const [loading, setLoading] = useState(false);
  const [hasError, setHasError] = useState(false);

  const handleSave = async () => {
    setLoading(true);
    setHasError(false);

    try {
      await onSave();
    } catch {
      setHasError(true);
    } finally {
      setLoading(false);
    }
  };

  return (
    <>
      <Button loading={loading} onClick={handleSave}>
        Save record
      </Button>
      {hasError && <p role="alert">Unable to save the record. Try again.</p>}
    </>
  );
};
```

The application starts and clears loading around the save operation. The button prevents activation while loading and becomes available again when the operation finishes, including after an error. `MainButton` and `LightButton` use the same state model.

## Appearance

```tsx
import { Button } from 'twenty-ui/primitives/input';
import { IconPlus } from 'twenty-ui/icon';

export const CreateRecord = () => (
  <Button variant="solid" color="accent" size="sm" startIcon={<IconPlus />}>
    Create record
  </Button>
);
```

Choose `solid`, `outline`, `soft`, or `ghost` independently of the `neutral`, `accent`, `danger`, or `success` color. Sizes are `sm` and `md`; the defaults are `outline`, `neutral`, and `md`. `fullWidth` fills the available width. `startIcon` and `endIcon` accept elements and are decorative. `elevated` adds a shadow and backdrop blur. Neutral outline buttons also gain a bordered surface with matching text and interaction colors. Other variants and semantic colors keep their existing palette. It defaults to `false` and does not change size or position. `hotkeys` displays keyboard hints on larger screens; bind the shortcuts in your application.

`disabled`, `loading`, and `soon` prevent activation. Loading keeps the label accessible and preserves the button's width while showing a spinner. Customize the upcoming-feature label with `soonLabel`.

## Links and forms

```tsx
import { Button } from 'twenty-ui/primitives/input';

export const DocumentationLink = () => (
  <Button href="https://twenty.com" target="_blank" rel="noreferrer">
    Read documentation
  </Button>
);
```

`href` renders an anchor with link semantics. The caller can supply its own `render` element or router link. Set `href` and preserve an anchor for navigation; without `href`, preserve a native button. Button derives its semantics without public `nativeButton` or `role` flags. Disabled links cannot activate.

Buttons default to `type="button"`. Set `type="submit"` or `type="reset"` explicitly for forms. Native props, event handlers, refs, and Base UI's `render` prop pass through to the root.

## Updating floating and color buttons

`FloatingButton`, `FloatingButtonGroup`, and `ColorPickerButton` are removed from
the public exports, including the package root and `twenty-ui/primitives/input`.
Update their imports when upgrading Twenty UI. Existing applications pinned to
an older published version keep that version's API until they upgrade.

| Removed export             | Replacement                                                                                                                                                  |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `FloatingButton`           | `Button elevated` from `twenty-ui/primitives/input`. Use children for the label, `startIcon` for a decorative icon, and `aria-label` for an accessible name. |
| `FloatingButtonGroup`      | [ButtonGroup](/ui/primitives/input/button-group) with explicit `Button` children. Use `framed` when the group needs a shared surface.                        |
| `ColorPickerButton`        | [IconButton](/ui/components/input/icon-button) from `twenty-ui/components` with `ColorSample` from `twenty-ui/primitives/data-display`.                      |
| `FloatingButtonProps`      | `ButtonProps` from `twenty-ui/primitives/input`.                                                                                                             |
| `FloatingButtonSize`       | `ButtonProps['size']`: change `small` to `sm` and `medium` to `md`.                                                                                          |
| `FloatingButtonPosition`   | Remove the position prop. `ButtonGroup` handles joined edges.                                                                                                |
| `FloatingButtonGroupProps` | `ButtonGroupProps` from `twenty-ui/primitives/input`.                                                                                                        |

Set `size="sm"` to preserve the former floating button's default size. Replace
`to` with `href` or your application's router link through `render`. Use
`elevated` for the floating appearance; the old `applyShadow`, `applyBlur`, and
synthetic `focus` props are removed. Keep positioning in your application and
use native keyboard focus or the appropriate `aria-pressed` or `aria-expanded`
state for the interaction.

For a color choice, keep selection in the application, provide a localized
accessible name, and expose the selected state explicitly:

```tsx
import { IconButton } from 'twenty-ui/components';
import { ColorSample } from 'twenty-ui/primitives/data-display';

type BlueColorOptionProps = {
  label: string;
  isSelected: boolean;
  onSelect: () => void;
};

export const BlueColorOption = ({
  label,
  isSelected,
  onSelect,
}: BlueColorOptionProps) => (
  <IconButton
    aria-label={label}
    aria-pressed={isSelected}
    variant={isSelected ? 'outline' : 'ghost'}
    size="md"
    onClick={onSelect}
  >
    <ColorSample colorName="blue" />
  </IconButton>
);
```
