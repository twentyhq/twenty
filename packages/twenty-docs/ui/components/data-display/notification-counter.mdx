`NotificationCounter` displays the supplied number without clamping it or hiding zero. Use the surrounding label to explain what the count means.

```tsx
import { NotificationCounter } from 'twenty-ui/components/data-display';
import { Button } from 'twenty-ui/primitives/input';

export const InboxButton = ({ count }: { count: number }) => (
  <Button endIcon={<NotificationCounter count={count} />}>
    Inbox ({count} unread)
  </Button>
);
```

`variant="secondary"` changes the badge appearance. The counter has no click handler or live-region behavior of its own.
