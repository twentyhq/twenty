`FloatingIconButton` composes [IconButton](/ui/components/input/icon-button) with a bordered surface, shadow, and backdrop blur. Positioning and visibility belong to the surrounding layout.

## Usage

```tsx
import { FloatingIconButton } from 'twenty-ui/components';
import { IconPlus } from 'twenty-ui/icon';

export const AddWidgetButton = () => (
  <FloatingIconButton aria-label="Add widget">
    <IconPlus />
  </FloatingIconButton>
);
```

Provide an `aria-label` describing the action and pass the icon as children. Icon content is decorative. The default size is `sm` (24px). Use `xs` for 20px or `md` for 32px. The default shape is square; use `shape="round"` for a circular control. Set `elevated={false}` or `blur={false}` to remove the shadow or backdrop blur independently. Variants and semantic colors follow IconButton.

## State and tooltips

The application owns `disabled`, `loading`, and any toggle state expressed with `aria-pressed`. Disabled and loading controls prevent activation. Native keyboard focus supplies the focus indicator.

```tsx
import { FloatingIconButton } from 'twenty-ui/components';
import { IconPlus } from 'twenty-ui/icon';

export const AddWidgetWithTooltip = () => (
  <FloatingIconButton
    aria-label="Add widget"
    tooltip="Add a widget above this section"
  >
    <IconPlus />
  </FloatingIconButton>
);
```

Tooltips appear on hover and keyboard focus. Disabled and loading buttons retain a hover anchor without adding a keyboard stop. Use `tooltipPlace`, `tooltipDelay`, and `tooltipOffset` to configure the tooltip.

## Composition

Native props, refs, and `className` pass through to the root. Use `href` for link semantics or `render` for a custom native button or anchor. The default button type is `button`; pass `type="submit"` explicitly to submit a form.

For grouped actions, compose [ButtonGroup](/ui/primitives/input/button-group) with [IconButton](/ui/components/input/icon-button). ButtonGroup owns adjoining corners, size, and color. Apply positioning and any shared floating surface to your layout.

## Updating existing controls

Import `FloatingIconButton` from `twenty-ui/components`. Pass the icon as children, use native `aria-label`, and replace `small` / `medium` with `sm` / `md`. The surface options are `elevated` and `blur`; native focus and `aria-pressed` replace synthetic focus and active flags.

`FloatingIconButtonGroup` is removed. Compose ButtonGroup with IconButton for grouped actions, and keep any shared floating surface in your layout.
