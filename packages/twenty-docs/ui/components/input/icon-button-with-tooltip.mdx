`IconButtonWithTooltip` combines [IconButton](/ui/components/input/icon-button) with a tooltip. It shares the component's appearance, native attributes, refs, loading, and rendering behavior.

## Usage

```tsx
import { IconButtonWithTooltip } from 'twenty-ui/components';
import { IconSearch } from 'twenty-ui/icon';

export const SearchRecordsButton = () => (
  <IconButtonWithTooltip
    aria-label="Search records"
    tooltipContent="Search records"
    variant="ghost"
    size="sm"
  >
    <IconSearch />
  </IconButtonWithTooltip>
);
```

The tooltip opens on hover or keyboard focus. Disabled and loading buttons retain hover tooltips so an action can explain why it is unavailable. `aria-label` names the action independently of the tooltip text.

## State ownership

The component manages tooltip visibility through hover and focus. Your application supplies `disabled` and `loading`, just as for IconButton. Neither state changes automatically after activation.

The default tooltip position is bottom, with a 1000ms delay and a 5px offset. Override these with `tooltipPlace`, `tooltipDelay`, and `tooltipOffset`. Links and custom root elements remain tooltip triggers.
