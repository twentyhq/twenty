## Overview

`EmojiPicker` combines a trigger, a searchable emoji grid, and a [Dropdown](/ui/components/navigation/dropdown). Use the single component for an ordinary picker. Compose `Root`, `Trigger`, and `Options` when the popup needs other content, such as quick reactions before the full grid.

## Usage

```tsx
import { EmojiPicker } from 'twenty-ui/components/input';
import { Button } from 'twenty-ui/primitives/input';

export const ReactionPicker = ({
  onReact,
}: {
  onReact: (emoji: string) => void;
}) => (
  <EmojiPicker
    emojibaseUrl="/emojibase"
    searchLabel="Search emojis"
    loadingLabel="Loading emojis"
    emptyLabel="No emoji found"
    onEmojiSelect={onReact}
    triggerProps={{ render: <Button>Add reaction</Button> }}
    contentProps={{ width: 296 }}
  />
);
```

To compose the grid inside an existing picker dropdown, wrap `EmojiPicker.Options` in `EmojiPicker.Root`:

```tsx
import { EmojiPicker } from 'twenty-ui/components/input';
import { Dropdown } from 'twenty-ui/components/navigation';
import { Button } from 'twenty-ui/primitives/input';

export const ComposedReactionPicker = ({
  onReact,
}: {
  onReact: (emoji: string) => void;
}) => (
  <Dropdown.Root type="picker">
    <EmojiPicker.Root emojibaseUrl="/emojibase" onEmojiSelect={onReact}>
      <EmojiPicker.Trigger render={<Button>Add reaction</Button>} />
      <Dropdown.Content width={296}>
        <EmojiPicker.Options
          searchLabel="Search emojis"
          loadingLabel="Loading emojis"
          emptyLabel="No emoji found"
        />
      </Dropdown.Content>
    </EmojiPicker.Root>
  </Dropdown.Root>
);
```

The usage examples expect your application to serve Emojibase data at `/emojibase`.

## Data and labels

`emojibaseUrl` is required. The picker loads both `${emojibaseUrl}/${locale}/data.json` and `${emojibaseUrl}/${locale}/messages.json` when its options open. Host those files from the Emojibase data package for each supported locale. The default locale is `en`; supplying translated interface labels does not change the emoji catalogue locale.

Provide localized `searchLabel`, `loadingLabel`, and `emptyLabel`. `searchLabel` names the search field and supplies its placeholder unless `searchPlaceholder` overrides it. Emoji names, categories, and search keywords come from the selected Emojibase locale.

## Selection and composition

`onEmojiSelect` receives the selected Unicode emoji string, and the popup closes. Your application owns any selected value, reaction counts, message identifiers, permissions, and persistence.

`EmojiPicker.Options` renders `Dropdown.Search`, a separator, and the emojis as `Dropdown.OptionItem` cells grouped by category. It must sit inside a `Dropdown.Content` of type `picker`. Emojis render in pages as the grid scrolls.

## Accessibility

Typing keeps focus in the search field. Arrow Down moves to the first emoji, arrow keys move through the grid and across categories, Enter selects the highlighted emoji, and Escape closes the popup. The highlighted emoji scrolls into view. Each emoji has an accessible name from the selected catalogue.
