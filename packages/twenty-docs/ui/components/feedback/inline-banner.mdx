`InlineBanner` composes [Banner](/ui/primitives/feedback/banner) with a rounded inline layout and a decorative information icon. It shares Banner's independent `status`, `variant`, `color`, `icon` and `action` contracts. Its default appearance is `soft` and its default status is `info`.

The `standard` layout fills the available width. Plain string children truncate, with keyboard focus, pointer hover or touch revealing the full string in a tooltip. Rich node children render directly, so embedded links and controls retain their own semantics. Compose explicit typography when rich content needs truncation.

```tsx
import { InlineBanner } from 'twenty-ui/components/feedback';
import { Button } from 'twenty-ui/primitives/input';

export const SyncBanner = ({ onRetry }: { onRetry: () => void }) => (
  <InlineBanner
    status="error"
    action={<Button size="sm" variant="outline" color="danger" onClick={onRetry}>Retry sync</Button>}
  >
    Contact sync could not finish.
  </InlineBanner>
);
```

Use `layout="compact"` for wrapping content, closer spacing and a maximum content width of 512px. It has no bottom margin. Layout is independent of `solid` or `soft` appearance. `embedded` removes the standard layout's bottom margin.

```tsx
import { InlineBanner } from 'twenty-ui/components/feedback';
import { Button } from 'twenty-ui/primitives/input';
import { IconInfoCircle } from 'twenty-ui/icon';

export const ConnectionBanner = () => (
  <InlineBanner
    layout="compact"
    status="warning"
    color="blue"
    icon={<IconInfoCircle aria-hidden="true" />}
    action={<Button size="sm" variant="outline" color="accent" href="/settings/accounts">Connection settings</Button>}
  >
    Connect your account to sync contacts.
  </InlineBanner>
);
```

The root target is a `div`. Native props, `className`, `style` and `ref` target that root; Base UI `render` can compose another element and receives resolved Banner state. `action` accepts any ReactNode, including multiple controls with their complete Button or link APIs. `icon={null}` removes the default icon.

The caller owns whether the banner is rendered and whether changes should be announced. Supply `role="status"` and `aria-live="polite"`, or an appropriate live-region wrapper, when needed. Status does not assign live-region semantics. Name action controls and mark decorative custom icons with `aria-hidden`.

## Migration

Replace `message` with `children`, `LeftIcon={Icon}` with `icon={<Icon />}`, and `button` configuration with an `action` node. Compose `Button` with the previous size, appearance and palette to preserve its presentation. Replace `variant="compact"` with `layout="compact"`; standard is now the default layout. Use `status="error"` for error meaning or `color="red"` for a palette override.
