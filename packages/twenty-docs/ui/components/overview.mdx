title: Components
sidebarTitle: Overview
description: Reusable app building blocks composed from Twenty UI primitives.
---

Components combine [primitives](/ui/primitives/overview) into reusable app building blocks, such as tables, boards, and pickers. Like primitives, they receive data and callbacks from your application.

Import these building blocks from `twenty-ui/components`.

| Component                                      | Purpose                                                      |
| ---------------------------------------------- | ------------------------------------------------------------ |
| [SectionHeader](/ui/components/section-header) | A heading with a supporting description and optional action. |
