`CommandBlock` displays each supplied command with a prompt marker. It does not execute commands or provide copying automatically. Pass a [Button](/ui/primitives/input/button) as `button` to supply an action.

```tsx
import { CommandBlock } from 'twenty-ui/components';
import { Button } from 'twenty-ui/primitives/input';

export const InstallCommand = ({ onCopy }: { onCopy: () => void }) => (
  <CommandBlock
    commands={['yarn add twenty-ui']}
    button={<Button onClick={onCopy}>Copy command</Button>}
  />
);
```

The component accepts only `commands` and `button`. Additional native attributes are not forwarded.
