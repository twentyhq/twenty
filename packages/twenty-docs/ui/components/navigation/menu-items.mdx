## Usage

`MenuItem` accepts a main `text` label, leading and trailing content, supporting text, shortcut hints, and submenu indicators. `focused` and `selected` change its appearance; the application owns actual focus and selection.

```tsx
import { MenuItem } from 'twenty-ui/components/navigation';
import { IconCopy } from 'twenty-ui/icon';

export const CopyRowPreview = () => (
  <MenuItem text="Copy record" LeftIcon={IconCopy} shortcut={['Mod', 'C']} />
);
```

The root is a div. `onClick` alone does not provide keyboard activation or menu semantics. Native attributes and refs are not exposed by this preset. Use `Dropdown.ActionItem` for accessible commands. Shortcut hints and `hasSubMenu` are visual; they do not register handlers or create a submenu. `isTooltipOpen` is currently accepted but unused.

## MenuItemAvatar

<StoryEmbed
  storyId="ui-components-navigation-menuitemavatar--display"
  title="Person row with an avatar"
  height={110}
/>

`MenuItemAvatar` places an [Avatar](/ui/primitives/data-display/avatar) before a text label. Its `avatar` accepts `name`, `src`, `colorSeed`, `size`, and `shape`. Omit it to render no avatar.

```tsx
import { MenuItemAvatar } from 'twenty-ui/components/navigation';

export const PersonRowPreview = () => (
  <MenuItemAvatar
    text="Ada Lovelace"
    avatar={{ name: 'Ada Lovelace', shape: 'circle' }}
  />
);
```

It shares MenuItem's pointer and keyboard limitations. For a selectable person, compose an Avatar inside `Dropdown.OptionItem` instead.

## MenuItemDraggable

<StoryEmbed
  storyId="ui-navigation-menu-menuitem-menuitemdraggable--display"
  title="Row with a drag grip"
  height={110}
/>

`MenuItemDraggable` renders a menu row that can show a drag grip. The application supplies drag behavior. `gripMode` defaults to `never`, which shows no grip; `always` shows the grip, and `onHover` swaps the leading content (`LeftComponent`, otherwise `LeftIcon`) for the grip while the row is hovered, so it shows nothing without leading content. `isDragDisabled` affects the appearance, not external drag handlers.

```tsx
import { MenuItemDraggable } from 'twenty-ui/components/navigation';

export const ReorderRowPreview = () => (
  <MenuItemDraggable text="Company name" gripMode="always" />
);
```

The root remains a div without keyboard drag behavior. `isTooltipOpen` and `isHoverDisabled` are currently accepted but unused. Provide an accessible reordering interface in the surrounding application.

## MenuItemSuggestion

<StoryEmbed
  storyId="ui-components-navigation-menuitemsuggestion--display"
  title="Suggested company with supporting text"
  height={110}
/>

`MenuItemSuggestion` presents a suggested value with an optional icon and supporting text. Without `onClick`, keep its `li` root inside a semantic list. `selected` changes its appearance without adding selection behavior.

```tsx
import { MenuItemSuggestion } from 'twenty-ui/components/navigation';
import { Text } from 'twenty-ui/primitives/typography';

export const SuggestedName = () => (
  <Text
    render={<ul />}
    style={{ margin: 0, padding: 0, listStyle: 'none', width: '100%' }}
  >
    <MenuItemSuggestion text="Acme" contextualText="Company" />
  </Text>
);
```

Supplying `onClick` gives the row button semantics, a tab stop, and Enter/Space activation. Place clickable rows in `<ul role="none">` because their `li` roots expose `button` instead of `listitem`. For a complete selection or action workflow, prefer [Dropdown.OptionItem](/ui/components/navigation/dropdown) or [ListItemButton](/ui/components/navigation/list-item-button).
