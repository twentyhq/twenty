Applications own appearance preferences, preview content, persistence, and system-theme resolution. Compose an exclusive choice with [RadioGroup](/ui/primitives/input/radio-group) and [Radio](/ui/primitives/input/radio).

```tsx
import { useState } from 'react';
import { Radio, RadioGroup } from 'twenty-ui/primitives/input';

type Appearance = 'Light' | 'Dark' | 'System';

export const AppearanceChoice = () => {
  const [scheme, setScheme] = useState<Appearance>('System');

  return (
    <RadioGroup aria-label="Appearance" value={scheme} onValueChange={setScheme}>
      <Radio variant="card" value="Light">Light</Radio>
      <Radio variant="card" value="Dark">Dark</Radio>
      <Radio variant="card" value="System">Use system setting</Radio>
    </RadioGroup>
  );
};
```

RadioGroup owns exclusive selection, focus, and arrow-key navigation. Labels provide accessible names. Pass `disabled` to the group or an individual radio when a choice is unavailable. Decorative previews belong inside each radio and should use `aria-hidden`.

Resolve the application's system preference before passing `light` or `dark` to [ThemeProvider](/ui/theming). Saving the preference and applying it remain application responsibilities.
