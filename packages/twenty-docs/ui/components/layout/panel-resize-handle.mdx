`PanelResizeHandle` is a focusable separator that manages bounded panel sizes, drag cancellation and optional activation. It composes [ResizeHandle](/ui/primitives/layout/resize-handle). The application owns the panel content, layout and saved size.

## Usage

Place the handle with `placement="edge"` inside a panel with `position: relative` and visible overflow so the full edge remains reachable. Set `edge` to its physical edge: `left`, `right`, `top` or `bottom`. Give the separator a specific accessible name and use `aria-controls` to identify the panel.

```tsx
import { useId, useState } from 'react';
import { PanelResizeHandle } from 'twenty-ui/components/layout';
import { Card } from 'twenty-ui/primitives/surfaces';
import { Text } from 'twenty-ui/primitives/typography';

export const ResizableNotes = () => {
  const panelId = useId();
  const [width, setWidth] = useState(240);
  const [savedWidth, setSavedWidth] = useState(240);

  return (
    <Card.Root
      id={panelId}
      style={{ position: 'relative', overflow: 'visible', width, height: 180 }}
    >
      <Text>Record notes</Text>
      <PanelResizeHandle
        edge="right"
        size={savedWidth}
        onSizePreview={setWidth}
        onSizeCommitted={setSavedWidth}
        minSize={160}
        maxSize={400}
        aria-label="Resize notes width"
        aria-controls={panelId}
      />
    </Card.Root>
  );
};
```

`size` is the required committed size. `onSizePreview` reports live sizes while dragging and keyboard resizing so the application can update its layout. `onSizeCommitted` reports successful drags and keyboard changes so the application can save the new size and update `size`.

## Edges and gaps

A right edge increases the size when moving right, and a bottom edge increases it when moving down. Left and top edges reverse those movements. These are physical directions and remain the same in right-to-left content.

Use `placement="gap"` between elements in a flex layout. `gapSize` sets the space between them. The gap remains interactive without a visible grip. Set `showGrip={false}` to hide the grip on an edge while keeping its resizing and focus behavior.

## Bounds, zoom and cancellation

Both pointer and keyboard resizing stay within the required `minSize` and `maxSize` bounds. Pointer movement starts a drag after five physical pixels. `scale` accepts a positive zoom factor or a function returning one; it is sampled at the start of the gesture and converts pointer movement to layout pixels.

Escape, pointer cancellation, lost pointer capture and unmounting the separator cancel an active drag; disabling it cancels the drag on its next pointer event. `onSizePreview` restores the starting size and `onSizeCommitted` does not run. `onResizeEnd` reports `{ cancelled, size }`, using the restored size after cancellation. Use `onResizeStart` and `onResizeEnd` for temporary application state associated with dragging.

## Keyboard and activation

Arrow keys move the selected edge by `step`, which defaults to `10`. Home selects `minSize`; End selects `maxSize`. Each size change commits immediately. Keys pressed with Alt, Control or Meta are ignored so application and browser shortcuts keep working. The separator orientation describes the dividing edge, so width resizing uses a vertical separator.

Pointer presses do not move focus, so an input keeps its focus while the user resizes the panel around it. Keyboard users reach the separator with Tab.

Supply `onActivate` to receive an activation request from a click without dragging, Enter or Space. A drag that moves away and returns to its start remains a drag. The application decides whether to hide the panel and where to restore focus. `disabled` prevents resizing and activation and removes the separator from the tab order.

Native props, styles and refs reach the separator. A custom `render` element must [forward the supplied props and ref](/ui/primitives/overview#custom-components) to retain focus, pointer capture and keyboard handling.
