`Info` displays a message with a blue or danger accent. Supply `buttonTitle` with `onClick` for an action, or with `href` for a link. When both are supplied, `href` takes precedence.

```tsx
import { Info } from 'twenty-ui/components';

export const ConnectionInfo = ({ onConnect }: { onConnect: () => void }) => (
  <Info
    text="Connect your account to sync contacts."
    buttonTitle="Connect account"
    onClick={onConnect}
  />
);
```

Use `accent="danger"` for an error. `render` customizes the link action when `href` is supplied. The message has no automatic dismissal or announcement behavior.
