## At a glance

| Plan  | Key Features |
|------|--------------|
| **Free (Self-Hosted)** | All Pro features, community support |
| **Pro (Cloud)** | Everything apart from the Premium features (SSO, row-level permissions and more), standard support |
| **Organization (Cloud)** | All from Pro + the Premium features (SSO, row-level permissions and more), priority support |
| **Organization (Self-Hosted)** | All from Pro + the Premium features (SSO, row-level permissions and more), Twenty team support, not required to publish your custom code as open-source before distributing |

## Quick answers

**Where do I manage billing?**
Go to **Settings → Billing** to view your plan, update payment methods, and access invoices.

**Can I use Twenty for free?**
Yes! Self-host Twenty and get all Pro features at no cost.

**How do I upgrade?**
Go to **Settings → Billing** and click **Switch to Organization** or **Switch to Yearly**.

For more questions, see the [Billing FAQ](/user-guide/billing/how-tos/billing-faq).
