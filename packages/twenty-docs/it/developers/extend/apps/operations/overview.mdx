## Cosa copre lo strato delle operazioni

Il **livello operativo** è tutto ciò che fai *alla* tua app piuttosto che *con* essa: eseguire comandi CLI, eseguire test di integrazione su un server Twenty reale, configurare la CI, tradurre le sue stringhe e distribuire le release — sia come tarball distribuito su un singolo server, sia come pacchetto npm elencato nel marketplace.

| Passaggio             | Comando                        |
| --------------------- | ------------------------------ |
| Sviluppo              | `twenty app dev`               |
| Test                  | `yarn test`                    |
| Compilazione          | `twenty app build`             |
| Pubblica su un server | `twenty app publish --private` |
| Pubblica su npm       | `twenty app publish`           |
