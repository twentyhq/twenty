## Panoramica

`Loader` mostra un punto animato all'interno di una piccola capsula con bordo. Utilizzalo mentre è in corso un'operazione e la percentuale è sconosciuta. Per il progresso numerico, usa [ProgressBar](/it/ui/primitives/feedback/progress-bar).

## Utilizzo

```tsx
import { Loader } from 'twenty-ui/primitives/feedback';
import { Text } from 'twenty-ui/primitives/typography';

type SaveFeedbackProps = { isSaving: boolean };

export const SaveFeedback = ({ isSaving }: SaveFeedbackProps) => (
  <Text
    render={<div />}
    role="status"
    style={{ display: 'flex', alignItems: 'center', gap: 8 }}
  >
    {isSaving && <Loader color="blue" aria-hidden="true" render={<span />} />}
    {isSaving ? 'Saving changes' : 'Changes saved'}
  </Text>
);
```

Inserisci il testo di stato visibile accanto al loader in un wrapper. Il loader è un indicatore visivo a dimensione fissa e non accetta elementi figli.

L'applicazione gestisce lo stato di caricamento. Mantieni montato il contenitore dello stato affinché gli aggiornamenti del testo possano essere annunciati. Per impostazione predefinita, il loader non assegna alcuna etichetta né alcun ruolo di area live. Usa `aria-hidden="true"` quando il testo circostante o un pulsante fornisce già un feedback di caricamento.

## Composizione ed etichettatura native

Le proprietà native, `className`, `style` e `ref` sono destinate al div contenitore. `render` accetta un elemento o un callback tramite la composizione di Base UI. Gli stili sovrascrivono i colori predefiniti. `LoaderProps` viene esportato dalla famiglia di feedback.

Per un indicatore autonomo, fornisci un ruolo di stato esplicito e un nome accessibile. Il punto animato rimane decorativo.

```tsx
import { Loader, type LoaderProps } from 'twenty-ui/primitives/feedback';

const loadingProps: LoaderProps = {
  role: 'status',
  'aria-label': 'Loading results',
  color: 'blue',
};

export const LoadingResults = () => (
  <Loader {...loadingProps} render={<span />} />
);
```

Usa invece `aria-labelledby` quando il testo visibile denomina lo stato. Mantieni montato un proprietario dell'area live quando deve annunciare testo variabile. L'applicazione determina quando viene visualizzato il feedback e cosa comunica.

## Colore

Passa un colore della palette del tema per impostare sia il bordo sia il punto. Senza un colore, il loader eredita il colore di un pulsante circostante quando disponibile; altrimenti utilizza il colore del testo terziario. Per un'azione di pulsante, preferisci lo [stato di caricamento di Button](/it/ui/primitives/input/button#state-ownership), che mantiene il feedback all'interno del controllo.
