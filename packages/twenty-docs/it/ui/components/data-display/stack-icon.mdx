## Panoramica

Passa l'icona principale tramite lo slot del nodo `icon` e l'elemento sovrapposto tramite `stackedIcon`. Il contenitore è largo e alto 16 px; l'elemento sovrapposto è posizionato in modo assoluto a 8 px da sinistra e 7 px dall'alto, quindi fuoriesce dall'angolo inferiore destro. Un avatar quadrato di 12 px è la dimensione prevista per il logo di un'applicazione. Entrambi i nodi sono decorativi, quindi mantieni un'etichetta visibile accanto all'icona.

Lascia spazio per la fuoriuscita dell'elemento sovrapposto quando posizioni i contenuti adiacenti. L'esempio utilizza uno spazio di 12 px tra il contenitore dell'icona e la relativa etichetta.

## Utilizzo

```tsx
import { StackIcon } from 'twenty-ui/components/data-display';
import { IconBuildingSkyscraper } from 'twenty-ui/icon';
import { Avatar } from 'twenty-ui/primitives/data-display';
import { Text } from 'twenty-ui/primitives/typography';

export const CompanyFieldLabel = () => (
  <Text style={{ display: 'flex', alignItems: 'center', gap: 12 }}>
    <StackIcon
      icon={<IconBuildingSkyscraper size={16} />}
      stackedIcon={
        <Avatar size="xs" shape="square" variant="outline" name="Stripe" />
      }
    />
    <Text>Companies</Text>
  </Text>
);
```

Gli attributi nativi, gli eventi, `className`, `style` e `ref` si applicano al div esterno. `render` sostituisce tale destinazione tramite la composizione di Base UI, preservando entrambi i nodi delle icone.
