## Panoramica

Visualizza un personaggio assistente a partire da una forma del corpo, un viso, un colore della palette e una dimensione. Il componente visualizza i valori forniti; la selezione e la persistenza sono gestite dall'applicazione.

## Utilizzo

```tsx
import { AssistantAvatar } from 'twenty-ui/components/data-display';
import { Text } from 'twenty-ui/primitives/typography';

export const AssistantLabel = () => (
  <Text style={{ display: 'flex', alignItems: 'center', gap: 8 }}>
    <AssistantAvatar shape="circle" face="default" color="blue" size={24} />
    <Text>Workspace assistant</Text>
  </Text>
);
```

## Opzioni visive

Scegli le forme indipendentemente dalle espressioni e dai colori.

| Proprietà    | Valori                                                                                     | Predefinito   |
| ------------ | ------------------------------------------------------------------------------------------ | ------------- |
| `shape`      | `circle`, `cookie`, `cloud`, `clover`, `flower`, `burst`, `pill`, `arch`, `gem`, `hexagon` | `circle`      |
| `face`       | `default`, `happy`, `wink`, `surprised`, `sleepy`, `love`                                  | `predefinito` |
| `colore`     | `blue`, `sky`, `turquoise`, `green`, `yellow`, `orange`, `red`, `pink`, `purple`, `gray`   | `blu`         |
| `dimensione` | `14`, `16`, `20`, `24`, `40` pixel                                                         | `24`          |

Il corpo e il viso utilizzano i token del tema della palette selezionata e seguono il tema chiaro o scuro circostante. Imposta `size` per un personaggio quadrato. Gli attributi nativi, gli eventi, `className`, `style` e `ref` sono applicati allo span esterno; gli stili espliciti sovrascrivono le relative dimensioni e i valori predefiniti della palette.

```tsx
import { AssistantAvatar } from 'twenty-ui/components/data-display';

export const CustomAssistant = () => (
  <AssistantAvatar
    shape="cloud"
    face="happy"
    color="sky"
    size={40}
    aria-label="Workspace assistant"
  />
);
```

## Accessibilità

Il personaggio è decorativo quando non ha un nome accessibile, come nell'esempio di utilizzo con etichetta. Per un personaggio autonomo, fornisci `aria-label` o `aria-labelledby`; l'elemento radice espone quindi il ruolo immagine. Il corpo e il viso restano nascosti alla tecnologia assistiva affinché il personaggio venga annunciato una sola volta.

Imposta esplicitamente `aria-hidden` quando devi sovrascrivere l'impostazione predefinita basata sul nome, ad esempio per nascondere un personaggio con nome accanto a testo visibile equivalente.

Inserisci il personaggio all'interno di un pulsante o link con nome quando accompagna un'azione. L'applicazione gestisce il controllo, la relativa etichetta e il relativo comportamento.
