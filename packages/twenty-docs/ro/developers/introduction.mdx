## De ce să construim pe douăzeci

Majoritatea CRM-urilor oferă dezvoltatorilor un API și câteva locuri în care să se conecteze. Douăzeci de ani vă oferă platforma în sine. Obiecte declare, funcţii de server, componente React şi agenţi AI în simplul TypeScript cu `twenty-sdk`, vezi fiecare schimbare de sincronizare cu un server local pe care îl salvezi și livrează cu CLI.

* **Gestionați spațiul de lucru cu cod.** Obiecte, câmpuri, vizualizări și machete de pagini live ca fișiere TypeScript în depozit, versionate și revizuite ca orice altă modificare.
* \*\*Același SDK ca și aplicațiile lui Twenty. \* Slack, Linear şi Granola sunt aplicaţii construite cu `twenty-sdk`, astfel încât să construiţi cu exact ceea ce foloseşte echipa lui Twenty.
* **Conectați nucleul, nu sidebar.** Obiectele dvs. primesc aceleași mese și permisiuni ca persoanele și companiile. Aplicațiile tale pot aduce conversații în mesajele lui Twenty, pot scrie să înregistreze cronologii, și pot expune funcții fluxurilor de lucru și agenților AI.
* **Niciun plafon.** Nucleul este open source și auto-hostabil. Când lipseşte un punct de prelungire, schimbaţi douăzeci în sine sau contribuiţi-l înapoi.
* **Pentru a experimenta în siguranță.** Aplicațiile rulează sandboxed și ating doar datele pe care le permit rolul lor, indiferent dacă echipa ta sau un agent AI a scris codul.
