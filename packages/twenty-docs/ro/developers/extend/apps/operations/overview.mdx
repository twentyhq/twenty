**Stratul de operațiuni** este tot ceea ce faci *asupra* aplicației tale, mai degrabă decât *cu* ea: invocarea comenzilor CLI, rularea testelor de integrare pe un server Twenty real, configurarea CI, traducerea șirurilor sale și lansarea versiunilor — fie ca un tarball implementat pe un singur server, fie ca un pachet npm listat în marketplace.

| Pas                    | Comandă                        |
| ---------------------- | ------------------------------ |
| Dezvoltare             | `twenty app dev`               |
| Test                   | `yarn test`                    |
| Build                  | `twenty app build`             |
| Publicare pe un server | `twenty app publish --private` |
| Publică pe npm         | `twenty app publish`           |
