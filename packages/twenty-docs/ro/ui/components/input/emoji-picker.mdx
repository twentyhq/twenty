## Prezentare generală

`EmojiPicker` oferă căutare de emoji, răsfoirea categoriilor și selectare de la tastatură. Aplicația dvs. furnizează etichetele, locația datelor emoji și gestionarul de selectare.

## Utilizare

```tsx
import { useState } from 'react';
import { EmojiPicker } from 'twenty-ui/components/input';
import { Text } from 'twenty-ui/primitives/typography';
import { themeCssVariables } from 'twenty-ui/theme';
import { isDefined } from 'twenty-ui/utilities';

export const EmojiPickerExample = () => {
  const [emoji, setEmoji] = useState<string | undefined>();

  return (
    <Text
      style={{
        display: 'flex',
        flexDirection: 'column',
        gap: themeCssVariables.spacing[2],
        width: 296,
      }}
    >
      <EmojiPicker
        emojibaseUrl="/emojibase"
        searchLabel="Search emojis"
        loadingLabel="Loading emojis"
        emptyLabel="No emoji found"
        onEmojiSelect={setEmoji}
      />
      <Text role="status">
        {isDefined(emoji) ? `Selected emoji: ${emoji}` : 'Choose an emoji'}
      </Text>
    </Text>
  );
};
```

Previzualizarea folosește un mic catalog de fixture-uri. Exemplul de utilizare se așteaptă ca aplicația dvs. să servească datele Emojibase la `/emojibase`.

## Date și etichete

`emojibaseUrl` este obligatoriu. Selectorul încarcă atât `${emojibaseUrl}/${locale}/data.json`, cât și `${emojibaseUrl}/${locale}/messages.json`. Găzduiți aceste fișiere din pachetul de date Emojibase pentru fiecare setare regională acceptată. Setarea regională implicită este `en`; furnizarea de etichete traduse pentru interfață nu modifică setarea regională a catalogului de emoji.

Furnizați `searchLabel`, `loadingLabel` și `emptyLabel` localizate. `searchLabel` denumește câmpul de căutare și îi furnizează textul substituent, cu excepția cazului în care `searchPlaceholder` îl suprascrie. Numele emoji-urilor, categoriile și etichetele de căutare provin din setarea regională Emojibase selectată.

## Selectare și compunere

`onEmojiSelect` primește șirul Unicode al emoji-ului selectat. Selectorul își păstrează intern căutarea și emoji-ul activ. Aplicația dvs. gestionează orice valoare selectată, numărul de reacții, identificatorii mesajelor, permisiunile, persistența și vizibilitatea ferestrei pop-up. Compuneți-l în interiorul [Dropdown](/ro/ui/components/navigation/dropdown) atunci când are nevoie de o fereastră pop-up.

Selectorul folosește opt coloane și o înălțime de 280px. Setați lățimea containerului său astfel încât să se potrivească grilei. Atributele native div, handler-ele, stilurile, numele claselor și referințele vizează containerul său exterior.

## Accesibilitate

Câmpul de introducere pentru căutare are numele accesibil furnizat. Focalizați-l cu Tab sau setați `autoFocus` la deschiderea unei ferestre pop-up. Tastele săgeată navighează prin grila de emoji-uri, iar Enter selectează emoji-ul activ. Fiecare emoji are un nume accesibil din catalogul selectat. `autoFocus` are valoarea implicită `false`.
