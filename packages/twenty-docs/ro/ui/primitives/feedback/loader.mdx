## Prezentare generală

`Loader` afișează un punct animat într-o capsulă mică cu contur. Folosiți-l în timp ce o operațiune este în desfășurare și procentajul este necunoscut. Pentru progres numeric, utilizați [ProgressBar](/ro/ui/primitives/feedback/progress-bar).

## Utilizare

```tsx
import { Loader } from 'twenty-ui/primitives/feedback';
import { Text } from 'twenty-ui/primitives/typography';

type SaveFeedbackProps = { isSaving: boolean };

export const SaveFeedback = ({ isSaving }: SaveFeedbackProps) => (
  <Text
    render={<div />}
    role="status"
    style={{ display: 'flex', alignItems: 'center', gap: 8 }}
  >
    {isSaving && <Loader color="blue" aria-hidden="true" render={<span />} />}
    {isSaving ? 'Saving changes' : 'Changes saved'}
  </Text>
);
```

Plasați textul de stare vizibil lângă indicatorul de încărcare într-un înveliș. Indicatorul de încărcare este un indicator vizual cu dimensiune fixă și nu acceptă elemente copil.

Aplicația gestionează starea de încărcare. Mențineți containerul de stare montat, astfel încât actualizările textului să poată fi anunțate. Încărcătorul nu atribuie implicit nicio etichetă sau niciun rol de regiune live. Folosește `aria-hidden="true"` atunci când textul din jur sau un buton oferă deja feedback privind încărcarea.

## Compunere și etichetare native

Proprietățile native, `className`, `style` și `ref` vizează div-ul container. `render` acceptă un element sau un callback prin compunerea Base UI. Stilurile suprascriu culorile implicite. `LoaderProps` este exportat din familia de feedback.

Pentru un indicator independent, oferă un rol de stare explicit și un nume accesibil. Punctul animat rămâne decorativ.

```tsx
import { Loader, type LoaderProps } from 'twenty-ui/primitives/feedback';

const loadingProps: LoaderProps = {
  role: 'status',
  'aria-label': 'Loading results',
  color: 'blue',
};

export const LoadingResults = () => (
  <Loader {...loadingProps} render={<span />} />
);
```

Folosește în schimb `aria-labelledby` atunci când textul vizibil denumește starea. Păstrează montat un proprietar al unei regiuni live atunci când trebuie să anunțe text în schimbare. Aplicația decide când apare feedbackul și ce spune acesta.

## Culoare

Transmiteți o culoare din paleta temei pentru a seta atât conturul, cât și punctul. Fără o culoare, încărcătorul moștenește culoarea unui buton din jur, dacă este disponibilă; în caz contrar, folosește culoarea terțiară a textului. Pentru o acțiune de buton, preferați [starea de încărcare a Button](/ro/ui/primitives/input/button#state-ownership), care păstrează feedbackul în interiorul controlului.
