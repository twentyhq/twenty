## Prezentare generală

Folosiți `Autocomplete` pentru sugestii asociate unui câmp de introducere a textului. Câmpul de introducere își păstrează cursorul și focalizarea tastaturii în timp ce tastele săgeată evidențiază sugestiile. Folosiți [Select](/ro/ui/primitives/input/select) atunci când utilizatorul trebuie să aleagă o valoare dintr-o listă fixă. [Dropdown](/ro/ui/components/navigation/dropdown) rămâne componenta de nivel superior pentru meniuri și selectoare.

## Utilizare

Transmiteți `items` la `Root` și redați-le prin `List`, astfel încât filtrarea să actualizeze sugestiile vizibile. `autoHighlight="always"` evidențiază primul rezultat de fiecare dată când se deschide lista.

```tsx
import { Autocomplete } from 'twenty-ui/primitives/input';

const FRUITS = ['Apple', 'Banana', 'Cherry'];

export const FruitInput = () => (
  <Autocomplete.Root items={FRUITS} autoHighlight="always">
    <Autocomplete.InputGroup>
      <Autocomplete.Input aria-label="Fruit" placeholder="Search fruits" />
    </Autocomplete.InputGroup>
    <Autocomplete.Portal>
      <Autocomplete.Positioner>
        <Autocomplete.Popup>
          <Autocomplete.Empty>No fruits found</Autocomplete.Empty>
          <Autocomplete.List>
            {(fruit: string) => (
              <Autocomplete.Item key={fruit} value={fruit}>
                {fruit}
              </Autocomplete.Item>
            )}
          </Autocomplete.List>
        </Autocomplete.Popup>
      </Autocomplete.Positioner>
    </Autocomplete.Portal>
  </Autocomplete.Root>
);
```

`value` și `onValueChange` controlează textul câmpului de intrare. Utilizați `defaultValue` pentru o valoare inițială necontrolată. Starea de deschidere este independentă: utilizați `open` și `onOpenChange` sau `defaultOpen`. `Item.onClick` gestionează atât selectarea cu indicatorul, cât și apăsarea Enter din câmpul de intrare.

`mode="list"` filtrează fără a modifica textul intrării la evidențiere. `mode="both"` furnizează, de asemenea, completare în linie. `mode="inline"` păstrează toate elementele și furnizează completare în linie; `mode="none"` păstrează toate elementele fără completare în linie. `readOnly` împiedică completarea în linie să modifice intrarea.

## Anatomie

Păstrați părțile asociate în interiorul unui `Autocomplete.Root` montat. Compuneți separat destinația portalului, învelișul de poziționare și conținutul. `InputGroup` grupează opțional intrarea cu controalele adiacente și ancorează fereastra pop-up la acel grup.

```text
Autocomplete.Root
├── Autocomplete.InputGroup (optional)
│   ├── Autocomplete.Input
│   ├── Autocomplete.Clear (optional)
│   └── Autocomplete.Trigger (optional)
│       └── Autocomplete.Icon (optional)
├── Autocomplete.Portal
│   ├── Autocomplete.Backdrop (optional)
│   └── Autocomplete.Positioner
│       └── Autocomplete.Popup
│           ├── Autocomplete.Arrow (optional)
│           ├── Autocomplete.Empty
│           └── Autocomplete.List
│               ├── Autocomplete.Item
│               ├── Autocomplete.Group (optional)
│               │   ├── Autocomplete.GroupLabel
│               │   └── Autocomplete.Collection
│               │       └── Autocomplete.Item
│               ├── Autocomplete.Row (optional, with Root.grid)
│               │   └── Autocomplete.Item
│               └── Autocomplete.Separator (optional)
├── Autocomplete.Status (optional)
└── Autocomplete.Value (optional)
```

| Parte componentă | Scop și țintă nativă                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------------- |
| `Root`           | Gestionează valoarea intrării, filtrarea, evidențierile și starea de deschidere. Nu redă niciun element. |
| `Valoare`        | Citește textul intrării prin elemente copil sau o funcție de randare. Nu redă niciun element.            |
| `InputGroup`     | Grupează intrarea și controalele adiacente. Vizează un div.                                              |
| `Intrare`        | Redă câmpul de intrare al casetei combinate și păstrează focalizarea tastaturii. Vizează o intrare.      |
| `Declanșator`    | Deschide sau închide sugestiile. Vizează un buton.                                                       |
| `Icon`           | Conține un indicator de declanșare. Vizează un span.                                                     |
| `Șterge`         | Golește valoarea intrării. Vizează un buton.                                                             |
| `Portal`         | Alege destinația și politica de montare. Vizează div-ul portalului său.                                  |
| `Backdrop`       | Furnizează o suprapunere opțională sub fereastra pop-up. Vizează un div.                                 |
| `Positioner`     | Gestionează ancora, alinierea, decalajele și gestionarea coliziunilor. Vizează div-ul său.               |
| `Popup`          | Redă conținutul sugestiilor și comportamentul opțional de focalizare. Vizează div-ul său.                |
| `Arrow`          | Furnizează o săgeată poziționată opțională în `Popup`. Vizează un div.                                   |
| `Listă`          | Redă elementele filtrate. Vizează un div cu rolul listbox sau grid.                                      |
| `Item`           | Redă o sugestie și gestionează selectarea cu indicatorul sau tastatura. Vizează un div.                  |
| `Grup`           | Grupează elementele asociate. Vizează un div.                                                            |
| `GroupLabel`     | Etichetează grupul părinte. Vizează un div.                                                              |
| `Row`            | Grupează un rând de elemente când `Root.grid` este activat. Vizează un div.                              |
| `Collection`     | Redă elementele filtrate printr-un element copil de tip funcție. Nu redă niciun element.                 |
| `Separator`      | Separă vizual elementele sau grupurile. Vizează un div.                                                  |
| `Gol`            | Anunță când nu sunt disponibile elemente corespunzătoare. Vizează un div.                                |
| `Status`         | Anunță modificări precum starea încărcării asincrone. Vizează un div.                                    |

Părțile redate păstrează atributele native, gestionarele, referințele, `className` și `style` bazate pe stare, precum și compunerea `render` de element/funcție din API-ul Base UI instalat. Proprietățile native și referințele vizează propriul element al părții. Componentele personalizate trebuie să redirecționeze proprietățile și referințele furnizate. Proprietățile părților publice și tipurile de stare sunt exportate din `twenty-ui/primitives/input`, împreună cu acțiunile Root și tipurile de detalii ale evenimentelor de modificare/evidențiere.

`Autocomplete.useFilter()` furnizează potriviri `contains`, `startsWith` și `endsWith` adaptate la setările regionale. `Autocomplete.useFilteredItems\<TItem>()` citește colecția filtrată intern din Root. Tratați acest rezultat ca fiind doar în citire.

## Elemente obiect și grupate

Elementele pot fi șiruri sau obiecte arbitrare. Utilizați `itemToStringValue` pentru a furniza textul utilizat pentru filtrare, completare și trimiterea formularului. Obiectele cu forma `{ value, label }` își folosesc automat eticheta. Redați aceeași valoare de element furnizată prin Root; nu este necesară nicio formă de element specifică Twenty sau proprietate pentru egalitatea selecției. Autocomplete gestionează intrarea de text, nu o valoare de obiect selectat separată.

Pentru date grupate, transmiteți grupuri cu o matrice `items`. Root păstrează tipul elementului pentru `itemToStringValue` și `onItemHighlighted`. Redați elementele copil filtrate ale fiecărui grup prin `Group` și `Collection`:

```tsx
import { Autocomplete } from 'twenty-ui/primitives/input';
import { Text } from 'twenty-ui/primitives/typography';

type City = { id: number; name: string; country: string };
type CityGroup = { label: string; items: City[] };

const CITY_GROUPS: CityGroup[] = [
  {
    label: 'Europe',
    items: [
      { id: 1, name: 'Paris', country: 'France' },
      { id: 2, name: 'Lisbon', country: 'Portugal' },
    ],
  },
];

export const GroupedCityInput = () => (
  <Text
    style={{ display: 'grid', alignContent: 'start', gap: 8, width: '100%' }}
  >
    <label htmlFor="grouped-city">
      <Text render={<span />}>City</Text>
    </label>
    <Autocomplete.Root
      items={CITY_GROUPS}
      itemToStringValue={(city) => city.name}
      autoHighlight="always"
    >
      <Autocomplete.Input id="grouped-city" placeholder="Search cities" />
      <Autocomplete.Portal>
        <Autocomplete.Positioner>
          <Autocomplete.Popup>
            <Autocomplete.Empty>No matching cities</Autocomplete.Empty>
            <Autocomplete.List>
              {(group: CityGroup) => (
                <Autocomplete.Group key={group.label} items={group.items}>
                  <Autocomplete.GroupLabel>
                    {group.label}
                  </Autocomplete.GroupLabel>
                  <Autocomplete.Collection>
                    {(city: City) => (
                      <Autocomplete.Item
                        key={city.id}
                        value={city}
                        description={city.country}
                      >
                        {city.name}
                      </Autocomplete.Item>
                    )}
                  </Autocomplete.Collection>
                </Autocomplete.Group>
              )}
            </Autocomplete.List>
          </Autocomplete.Popup>
        </Autocomplete.Positioner>
      </Autocomplete.Portal>
    </Autocomplete.Root>
  </Text>
);
```

`Item.startIcon`, `Item.endIcon` și `Item.description` furnizează conținut suplimentar. Compuneți `Trigger` și `Clear` cu [Button](/ro/ui/primitives/input/button) din Twenty UI prin `render`. `Icon` poate conține o pictogramă din `twenty-ui/icon`. Păstrați `Status` și `Empty` montate în timp ce actualizați elementele lor copil, astfel încât cititoarele de ecran să poată anunța modificările.

## Filtrare externă și sugestii de la server

Utilizați `filteredItems` când aplicația dvs. gestionează filtrarea. Aceasta trebuie să păstreze structura plată sau grupată a `items`. `filter` acceptă o funcție de potrivire personalizată; `filter={null}` dezactivează filtrarea internă pentru rezultatele deja filtrate de un server.

```tsx
import { useState } from 'react';
import { Autocomplete } from 'twenty-ui/primitives/input';

const CITIES = ['Paris', 'London', 'Lisbon'];

export const CityPrefixInput = () => {
  const [value, setValue] = useState('');
  const { startsWith } = Autocomplete.useFilter();
  const filteredItems = CITIES.filter((city) => startsWith(city, value));

  return (
    <Autocomplete.Root
      items={CITIES}
      filteredItems={filteredItems}
      value={value}
      onValueChange={setValue}
      autoHighlight="always"
    >
      <Autocomplete.Input aria-label="City prefix" />
      <Autocomplete.Portal>
        <Autocomplete.Positioner>
          <Autocomplete.Popup>
            <Autocomplete.Empty>No matching cities</Autocomplete.Empty>
            <Autocomplete.List>
              {(city: string) => (
                <Autocomplete.Item key={city} value={city}>
                  {city}
                </Autocomplete.Item>
              )}
            </Autocomplete.List>
          </Autocomplete.Popup>
        </Autocomplete.Positioner>
      </Autocomplete.Portal>
    </Autocomplete.Root>
  );
};
```

Păstrați Root montat când rezultatele sosesc asincron. Controlați `open` independent, astfel încât un răspuns să poată deschide sugestiile cât timp intrarea rămâne focalizată. Un `Status` montat poate anunța încărcarea; actualizați `Empty` când răspunsul finalizat nu are rezultate. Componenta părinte gestionează debounce-ul, anularea cererilor și protecția împotriva răspunsurilor învechite.

`onValueChange` și `onOpenChange` primesc detaliile evenimentului din amonte, inclusiv `reason`, `event` nativ, `trigger`, `cancel()` și `allowPropagation()`. Apelanții controlați decid ce actualizări solicitate să confirme. De exemplu, ignorați modificarea valorii `escape-key` pentru a păstra o interogare a serverului sau ignorați deschiderea `input-change` până când sosesc rezultatele. `onItemHighlighted` primește elementul original tipizat și motivul evidențierii sale. Anularea păstrează semantica Base UI instalată; nu înlocuiește politica aplicației privind starea controlată.

## Compunerea intrării și formulare native

`Input` acceptă `size="sm"` sau `size="md"` și utilizează aceleași stiluri ca [Input](/ro/ui/primitives/input/input). Compuneți-l cu o intrare existentă utilizând `render`. Controlul compus își gestionează apoi propriul aspect: `Input` nu adaugă stiluri Input și ignoră `size`, dar transmite în continuare `className`, atributele native, gestionarii de evenimente, ref și atributele de stare. Transmite-le elementului de input propriu-zis. Redă `Input` din Twenty UI pentru a păstra aspectul standard.

`InputGroup` oferă aspect și o ancoră fără a adăuga borduri câmpului de intrare. Poate conține cipuri sau poate reda un înveliș existent. Folosește [InputGroup](/ro/ui/primitives/input/input-group) prin intermediul prop-ului său `render` atunci când întregul grup are nevoie de stilizarea inputului, așa cum se întâmplă în scenariul sugestiilor de obiecte grupate. Un `Input` fără `render` în interiorul său își elimină propria bordură. Oferiți câmpului de intrare o etichetă accesibilă sau compuneți-l cu [Field](/ro/ui/primitives/input/field).

Root păstrează comportamentul din amonte pentru `name`, `form`, `disabled`, `readOnly` și formularele native. Atributele native și referința lui Input vizează intrarea sa. `submitOnItemClick` activează trimiterea formularului la selectarea unei sugestii; comportamentul implicit nu trimite formularul.

Input păstrează gestionarea IME nativă a Base UI, inclusiv evenimentele de compunere și protecția sa de confirmare prin tastatură.

Versiunea Base UI instalată păstrează o interogare necontrolată la resetarea formularului nativ. Pentru o interogare controlată, gestionați `onReset` al formularului și restaurați valoarea inițială a aplicației.

## Poziționare, destinația portalului și închidere

`Positioner` are implicit `side="bottom"`, `align="start"` și `sideOffset={8}`. Păstrează contractul de ancorare și poziționare Base UI instalat, inclusiv ancore de element/referință/funcție/virtuale, decalaje funcționale, `positionMethod`, `collisionBoundary`, `collisionPadding`, `collisionAvoidance`, `arrowPadding`, `sticky` și `disableAnchorTracking`. Configurați-le pe Positioner. DirectionProvider controlează poziționarea logică și direcția DOM.

`Popup` utilizează lățimea ancorei ca lățime minimă. Setați-i `width` pentru a furniza o lățime fixă a conținutului. Proprietățile sale native, stilurile, compunerea de randare și referința vizează elementul de conținut independent de Positioner și Portal. `initialFocus` și `finalFocus` ale Popup păstrează opțiunile de focalizare din amonte. Implicit, sugestiile păstrează focalizarea în intrare.

Configurați `container` și `keepMounted` pe `Portal`. Omiterea containerului utilizează cea mai apropiată destinație ThemeProvider cu scop delimitat, apoi portalul părinte Base UI sau corpul documentului. Un `null` explicit așteaptă fără a reda până când este furnizat un container. Destinațiile de tip element, ShadowRoot și referință sunt transmise către Base UI. O referință nerezolvată păstrează alternativa portal părinte/corp a Base UI.

Destinația implicită cu scop delimitat își păstrează tokenurile CSS și schema de culori. O destinație explicită moștenește CSS din domeniul său DOM real, deci plasați-o în domeniul temei dorite sau furnizați acele stiluri acolo. Contextul React și direcția rămân disponibile în portaluri. Țintele ShadowRoot au nevoie de CSS-ul bibliotecii și de stilurile temei în acel arbore shadow.

Tastele săgeată modifică elementul evidențiat în timp ce intrarea păstrează focalizarea. Enter îl selectează; Escape și interacțiunea din exterior solicită închiderea folosind semantica din amonte. O apăsare în exterior poate activa controlul de destinație. Selectoarele de nivel superior pot gestiona o politică de activare diferită în adaptorul lor. Apelați `event.preventBaseUIHandler()` în `onKeyDown` al Input pentru a omite gestionarul încorporat pentru o tastă pe care o gestionați dvs. Utilizați și `event.preventDefault()` când suprimați acțiunea nativă a browserului.

`Root.inline` cu `open` redă sugestiile fără ansamblul ferestrei pop-up. Elementele în linie își păstrează callbackurile de selecție `onClick`, dar componenta din amonte instalată completează automat intrarea numai când Popup-ul său este prezent. Gestionați `Item.onClick` când selecția în linie trebuie să actualizeze textul dvs. controlat. `Root.grid` și `Row` acceptă navigarea în grilă. Aceste moduri păstrează API-urile de colecție și randare din amonte.

## Migrare

Încadrați Popup cu `Autocomplete.Positioner` și `Autocomplete.Portal`. Positioner necesită contextul Portal; sugestiile în linie omit întregul ansamblu al ferestrei pop-up. Mutați proprietățile de poziționare, ancoră și coliziune din Popup în Positioner. Mutați configurația `container` și de montare în Portal. Păstrați lățimea, stilurile conținutului, proprietățile native, gestionarele și referințele pe Popup. Utilizați un element copil `Arrow` explicit pentru o săgeată.

În componentele front, păstrați politica existentă a portalului cu scop delimitat. Acest API nu extinde destinațiile portalului rendererului sau capacitățile de geometrie, derulare și închidere; aceste capacități ale rendererului au responsabilitate separată. Adaptoarele de selectoare pentru producție își păstrează fluxurile de activare deliberate.
