---
title: Configurações do Espaço de Trabalho
description: Personalize o nome e a marca do seu espaço de trabalho.
---

Sua imagem do espaço de trabalho, nome e opções de exclusão são acessíveis em **Configurações → Geral**.

## Foto do Espaço de Trabalho

* **Carregar Logotipo**: Adicione um logotipo personalizado para o espaço de trabalho
* **Formatos suportados**: Arquivos PNG, JPEG e GIF com menos de 10MB
* **Remover**: Delete o logotipo atual do espaço de trabalho

## Nome do Espaço de Trabalho

* **Nome**: Altere o nome de exibição do seu espaço de trabalho
* Este nome aparece para todos os membros do espaço de trabalho

## Zona de Perigo

<Warning>
Excluir seu espaço de trabalho remove permanentemente todos os dados e revoga imediatamente o acesso de todos os membros — esta ação não pode ser desfeita.
</Warning>

Para excluir seu espaço de trabalho:

1. Clique no botão **Apagar Área de Trabalho**
2. Confirme a exclusão quando solicitado

**Nota**: Apenas administradores de espaço de trabalho podem excluir espaços de trabalho.
